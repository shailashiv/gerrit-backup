[SW-0] gaudi3: perform sku reconfiguation before slave fuse init

Currently, in fuse emulation flow, master die performs slave
fuse emulation init and then perform sku assignment based on fuse values
from emulation (ie. SPI flash). As sku check is done in slave fuse init
flow, this patch moves assignment of sku before slave fuse emulation
init.
