[SW-120178] fwupd: add reset device

Add reset device support for fwupd protocol. This is needed for reset
which is being sent to eROM recovery (with no agent involved).
Without this patch, eROM will ignore the HL_UPD_RST_DEV command and no
reset will be either responded, or performed.
