[SW-78052] gaudi3: update pcie control check in rom recovery

In gaudi3, pcie control bit in efuse has different meaning for
Master and Slave die.

On Die 0 (Master Die):
•	Value of ‘0’ – PCIe is Enabled
•	Value of ‘1’ – PCIe is Disabled
On Die 1 (Slave Die):
•	Value of ‘0’ – PCIe is Disabled
•	Value of ‘1’ – PCIe is Enabled

This patch modifies pcie control check based on die id.
