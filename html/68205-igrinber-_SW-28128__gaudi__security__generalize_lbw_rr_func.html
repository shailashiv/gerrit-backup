Commit Message

[SW-28128] gaudi: security: generalize lbw rr func

Generalize the LBW RRs configuration function, so it can be reused later
for DMA_IF and the SOB RRs closure.
This is done by extracting the data into a new data structure array and
keeping only the behavior inside the function.
The data can be accessed by using the new enum describing the data type.
