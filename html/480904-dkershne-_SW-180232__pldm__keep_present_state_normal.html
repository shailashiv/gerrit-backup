Commit Message

[SW-180232] pldm: keep present state normal

With the addition of persisting the meta state of effecters, the
asic reset effecter was setting the present state to reset. This
caused the code during restore to issue another reset request,
so we would just constantly reset device. Change the pending_state
to reset, but leave the present_state as normal.
