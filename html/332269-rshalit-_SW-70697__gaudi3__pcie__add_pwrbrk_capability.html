[SW-70697] gaudi3: pcie: add pwrbrk capability

In order to support power break over PCIe,
PCIe capabilities should contain pwrbrk capability,
otherwise - host will fail to deliver pwrbrk capability,
and requesting power break entry from host over PCIe
will fail.

Also note that this capability is reflected in lspci,
and should show in string that this feature is supported:

$ sudo lspci -d 1da3: -vv
.....
DevCap2: Completion Timeout: Range ABCD, TimeoutDis+, NROPrPrP-, LTR-
 10BitTagComp+, 10BitTagReq-, OBFF Not Supported, ExtFmt-, EETLPPrefix-
 EmergencyPowerReduction Form Factor Dev Specific,
....
