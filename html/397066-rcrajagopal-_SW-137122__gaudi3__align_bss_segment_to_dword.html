Commit Message

[SW-137122] gaudi3: align bss segment to dword

The issue is bss segment size is not aligned to dword.
Because of this, start up code is skipping initialization
of unaligned address. Here one of the static variable got
corrupted and lead to unknown behaviour.

So we are making sure bss segment size must be aligned
to dword and startup code initialize the whole bss segment
properly.
