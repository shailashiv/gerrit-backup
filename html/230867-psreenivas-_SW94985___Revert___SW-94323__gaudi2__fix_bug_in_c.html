Commit Message

[SW94985]: Revert "[SW-94323] gaudi2: fix bug in clearing recovery flag."

This reverts commit 62ef2e7c2395b7ad96fd872ac3f5e5d2ca8770f8.
Since the recovery flag is cleared in erom_init if the firmware update
fails, the arcboot rom will try to load ppboot instead of executing the
erom recovery. Therefore the recovery flag should be cleared only after
the successful firmware update i.e, in zephyr agent and hl-fw-loader.
