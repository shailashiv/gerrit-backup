Commit Message

[SW-50180] gaudi: fix pcie phy fw ext_ld_done loop

Commit
3c60806 ("[SW-13500] gaudi: fix instability in pci lanes")
while fixing the lanes instability introduced a logical bug - instead
of waiting for all PHYs to finish, checked that there is still a PHY
that has not finished.
So in case we've got that portion of code when all the PHYs have
finished it could result in an infinite loop - FW stuck.
Additionally the bug can result in link establishment problem as it
permits H/W bug W/A execution before PHYs have finished loading the FW.
