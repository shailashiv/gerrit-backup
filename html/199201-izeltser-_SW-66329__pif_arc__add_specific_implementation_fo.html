Commit Message

[SW-66329] pif_arc: add specific implementation for dbg mode check

hl_is_debug_mode() function deciding on the debug mode by reading the
strap register. Since pif arc is not allowed to read this register,
a specific implementation is required for the pif arc.
For the moment the implementation is empty and not debug mode is
supported by the pif arc. in case some debug mode will required in
the future, some alternative method should be implmented to signal
the pif are about the required mode.
