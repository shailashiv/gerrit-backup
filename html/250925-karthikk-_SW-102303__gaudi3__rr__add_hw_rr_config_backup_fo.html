Commit Message

[SW-102303] gaudi3: rr: add hw rr config backup for pcie

In gaudi3, efuse bit 16 in the security dword offset 0x3A, is to be
used to provide a backup rr config which blocks all the address
ranges in rom, in case the hw fails to do so.

BIT 16 legend:
0 : Config rr in ROM.
1 : HW configures the rr.

The rr apis are renamed for better readability.
