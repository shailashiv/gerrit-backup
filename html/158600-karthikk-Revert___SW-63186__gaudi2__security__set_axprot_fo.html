Commit Message

Revert "[SW-63186] gaudi2: security: set axprot for rot"

As per alignment with LKD, MSTR_IF's OVRD register should not be used
to set to "USER level".

This is because sub-blocks which should be secure won’t be able to work,
as MSTR_IF's OVRD bit takes precedence over the engine's internal PROT
configuration

This reverts commit f70c80894e584cec0894ac2d8086f1ce3add5e94.
