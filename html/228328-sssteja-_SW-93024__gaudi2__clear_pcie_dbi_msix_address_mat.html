Commit Message

[SW-93024] gaudi2: clear pcie dbi msix address match registers

PCIE_DBI_MSIX_ADDRESS_MATCH_LOW/HIGH_OFF registers are configured in
arc-mgmt based on a LKD cpucp command to direct the MSIX interrupts to
HBW address space as a workaround for exisitng issues with LBW based
MSIX.

This patch clears the above registers in the ppboot to ensure the MSIX
are not enabled by default until FW receives a cpucp command from LKD.
