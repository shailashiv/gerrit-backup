Commit Message

[SW-50880] ppboot: greco_arc: move axi drain to early init

This is preparatory patch for running PCIe initialization code on
ARC0 for secureboot flow and allow ARC1 to continue with preboot
execution. In order to achieve that, the axi drain init which
is done after init of ARC0 in hl_plat_init needs to be moved to
early init function and should be done before ARC0 init. In later patch,
we will move to init of ARC0 to early init as well.
