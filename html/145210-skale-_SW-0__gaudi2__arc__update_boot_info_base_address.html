[SW-0] gaudi2: arc: update boot info base address

Currently for secureboot flow, bootinfo base is set to scratchpad SRAM
which causes failures to read bootinfo in zephyr and uboot as they
expect bootinfo to be present at 0x10000 offset of ARC0 ICCM.
This patch update bootinfo base to ARC0 ICCM offset 0x10000.
