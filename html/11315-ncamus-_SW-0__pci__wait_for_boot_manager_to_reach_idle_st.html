Commit Message

[SW-0] pci: wait for boot manager to reach idle state

Boot Manager after wakening CPU from primary image starts executing PCIe
image (depends on pcie_enable strap).
Boot Manager execute straight from SPI flash.
Waiting for it to reach idle state insures there is no contention on SPI
bus which will result on boot hang due to curropted data read from
flash.
