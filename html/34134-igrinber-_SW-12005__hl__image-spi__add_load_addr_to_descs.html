Commit Message

[SW-12005] hl: image-spi: add load addr to descs

The image desriptors did not have the image load address encoded.
This results in hard coding of the next image load address into the
previous image - meaning each image must know the next image load
address during its compilation.
This situation is not very good and not generic.
Encode the images load addresses as per latest spec in the end of the
image descriptor structure.
