Commit Message

[SW-28697] module_lkd: prepare for comms addition

Add determination of the protocol used by LKD and split the code to
legacy and "yet to be implemented parts".
This is to prepare for a state when FW has implemented the protocol
while LKD is still not.
Once both sides talk the same language, the legacy part can be removed.
