Commit Message

[SW-110085] arc: introduce wevt command

The wevt instruction is similar to sleep, but with several differences
that make it much more like the ARM's wfe intruction.
For example, it can be called from user mode (not only from kernel mode)
and it also allows the core CPU wake up on a wire event (like ARM's
wfe). In Greco/Gaudi2 the wake up event is supported through the
WAKE_UP_EVENT register in PSOC_ARCx_CFG.
Since no longer used, remove Gaudi2 sleep() macro.
