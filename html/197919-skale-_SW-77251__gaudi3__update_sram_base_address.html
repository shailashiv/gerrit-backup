[SW-77251] gaudi3: update sram base address

For recovery firmware update operations, SRAM memory
is used for communication and fit copy from host/i2c.
In gaudi3, SRAM memory can be configured to run
in various mode. This patch add changes to set
SRAM address assuming SRAM is configured in mode 0 with
size of 48MB for given die.
