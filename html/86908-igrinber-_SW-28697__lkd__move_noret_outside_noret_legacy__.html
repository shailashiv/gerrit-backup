Commit Message

[SW-28697] lkd: move noret outside noret_legacy()

The implementation of the LKD module "no return" commands is about to
stay the same for legacy and the new protocol.
As a preparation for the new LKD protocol addition and "no return"
functionality implementation reuse, move the "no return" commands
implementation to separate functions.
