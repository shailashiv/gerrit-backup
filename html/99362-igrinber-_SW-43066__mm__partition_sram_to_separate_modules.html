Commit Message

[SW-43066] mm: partition sram to separate modules

All modules implementation is using the same memory location for images
and other purposes. It is only a matter of time until they clash into
each other. Moreover, there is also a possible security implication by
using different modules that look at the same memory area.
To remove all the threats together, partition the SRAM and provide
different memory locations for different modules.
This effectively also removes the FIT_IMG_BASE macro which was used as
the base for images and stuff.
