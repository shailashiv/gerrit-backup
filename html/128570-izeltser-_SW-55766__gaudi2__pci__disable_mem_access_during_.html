Commit Message

[SW-55766] gaudi2: pci: disable mem access during iatu init

Experience with gaudi shows that completely blocking pci access
during iATU init can cause issues with the host, and it's against
the pci spec.
So to be on the safe side, only the memory access is disabled
during the iATU initialization.
