Commit Message

[SW-0] gaudi3: remove usage of tpm validation flag

Currently, TPM implementation in ROM extends ppboot PCR based on
tpm validation flag which is cleared on cold reset and fw update.
Due to new requirement to clear PCR memory before extending PCR, TPM
needs to be reset via external reset control and needs to be reset on
every reset. This patch removes check of tpm validation flag in TPM ROM
implementation which means TPM will extend ppboot PCR unconditionally.
ROM will still update the indication of tpm validation in cold flops
for debug purpose.

ROM assumes TPM reset is perform by CPLD before any reset.
