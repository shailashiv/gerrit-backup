Makefile: release: use target specific tag pointer

We have a generic release tag pointer for various jenkins build
jobs needs and it is called 'latest-embedded-release'.
Since we would like to differentiate between the targets, switch to
use target specific tag as a latest release pointer.
Also, slightly rename it, so the new tag name is:
<target>-latest-emb-release
