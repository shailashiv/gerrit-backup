Commit Message

[SW-46517] greco: modify sw all reset mask

Currently, whenever hard reset is issued after LKD insmod,
ARC1 is not able to access SRAM to run preboot and the bootflow
of FW gets stuck. This issue is been debugged, till then as a
workaround PSOC and ARC's are also reset as part of hard reset.

This patch will be reverted once all reset issues related to
secureboot are resolved.
