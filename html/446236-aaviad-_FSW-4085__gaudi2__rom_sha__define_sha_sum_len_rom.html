[FSW-4085] gaudi2: rom sha: define sha_sum_len_rom

Prepare to remove sha256 we need to remove
all uses of sha256
replace using SHA256_SUM_LEN and create new define
SHA_SUM_LEN_ROM for reading sec key hash in ROM

the reason for the special define is that
if security keys hash location is ROM then only the first
256 bits are compared against the hash calculated.
Since there are only 256 bits available in PSOC registers
to store keys hash
