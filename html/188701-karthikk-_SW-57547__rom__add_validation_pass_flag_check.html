Commit Message

[SW-57547] rom: add validation pass flag check

As per the new design, signature validation is done on image
descriptor manifest and sha validation is done on ppboot/preboot
images. Hence the validation pass check needs to be done at
both places.

This would skip re-processing of an already verified image.

This patch consists of validation pass based logic update.
