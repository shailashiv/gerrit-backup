Commit Message

[SW-70899] gaudi2: arc: reset CPU_PLL

This change resets CPU_PLL as part of prstn reset.
Reset value of PLL_L_PRSTN_RST_CFG is 0xFFFFFFFD.
Bit 1 which corresponds to CPU_PLL should also need
to be resetted since now ARCs are also getting resetted
as part of Warm/PRSTn reset
Without this fix, protection bits configuration is not
getting reset even when fake security is disabled followed
by prstn reset which results in 0xBABA0BAD while accessing
registers in CPU_PLL block
