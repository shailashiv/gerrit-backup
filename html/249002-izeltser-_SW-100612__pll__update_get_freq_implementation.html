Commit Message

[SW-100612] pll: update get freq implementation

The implementation of pll get freq function for gaudi2 gaudi3 and
greco is identical, the only difference is register offsets within
the PLL block. To avoid code duplication, the implementation of
pll get freq for those devices is moved to common code, and pll
device struct is created to handle the register offsets.

The obsolete implementation for legacy devices (goya, gaudi) is moved
to device specific code.

+{
+	u32 nr, nf, od, div_sel, factor, offset;
+	u64 out_freq = SYS_REF_CLOCK;
+
+	offset = div * sizeof(u32);
+	div_sel = regmap_readl(pll_base + HL_PLL_DIV_SEL + offset);
+
+	if (div_sel == HL_PLL_PLL_CLK || div_sel == HL_PLL_DIV_PLL) {
+		nr = regmap_readl(pll_base + HL_PLL_NR) + 1;
+		nf = regmap_readl(pll_base + HL_PLL_NF) + 1;
+		od = regmap_readl(pll_base + HL_PLL_OD) + 1;
+		out_freq = (SYS_REF_CLOCK * nf) / (nr * od);
+	}
+
+	if (div_sel == HL_PLL_DIV_REF || div_sel == HL_PLL_DIV_PLL) {
+		factor = regmap_readl(pll_base + HL_PLL_DIV_FACTOR + offset);
+		out_freq /= factor + 1;
+	}
+
+	return out_freq;
