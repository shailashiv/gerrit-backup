Commit Message

[SW-45909] fwupd: fix map/run error cases

In case of an illegal MAP or RUN command, FWUPD module returns error
validation status, but continues and shifts the state. This in turn
permits a host/BMC to ignore the error and get the MAP/RUN commands
keep working.
Fix this by disabling state shift in case of validation error.
