Commit Message

[SW-89972] gaudi3: recovery: enable i2c in hardware mode

As part of rom recovery, ROM will enable I2C slave in HW mode to
facilitate OOB flash programming. This patch add support to enable
I2C slave in HW mode provided security is disabled and TWI interface
is enabled.

In rom recovery, inband/OOB flash programming will be only allowed if
security is disabled. On production system the POR recovery is EROM and it
is not expected to execute ROM recovery. In any case ROM recovery is executed
we have option to switch ON RMA mode and allow usage of fake fuse by which
required fuse settings can be done.
