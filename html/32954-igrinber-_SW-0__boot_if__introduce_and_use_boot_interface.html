Commit Message

[SW-0] boot_if: introduce and use boot interface

This is the boot interface with host which simplifies the usage of the
boot progress status, boot command response, boot error, host command
(msg) registers.
All the above registers are used to communicate with the host.
This also reduces the use of the regmap_{read,write}l() inline functions
which might raise the code size when used extensively.

+enum kmd_msg cpu_boot_cmd_get(void)

+}
+
+void cpu_boot_sts_set(u32 val)
+{
+	regmap_writel(val, mmPSOC_GLOBAL_CONF_CPU_BOOT_STATUS);
+}
+
+/* We support only ERR0 for now */
+void cpu_boot_err_clrset(u32 mask, bool set)
+{
+	u32 val = regmap_readl(mmCPU_BOOT_ERR0) & ~mask;
+
+	if (set)
+		val |= mask;
+
+	regmap_writel(val, mmCPU_BOOT_ERR0);
+}
+
+void cpu_boot_rsp_set(enum cpu_msg_status sts)
+{
+	regmap_writel(sts, mmCPU_CMD_STATUS_TO_HOST);
+}
