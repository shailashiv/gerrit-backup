Commit Message

[FSW-2704] fs1: read switch manifest from cold flops

In case cold reset flops are set for FLOPS_UPD_PENDING
that means new firmware has been updated in manifest1.
In this case bootrom will try to boot manifest1 first
and treat manifest0 as secondary.
