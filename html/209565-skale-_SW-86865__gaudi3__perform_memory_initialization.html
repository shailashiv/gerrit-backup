Commit Message

[SW-86865] gaudi3: perform memory initialization

In order to avoid memory exception while copying content in memory,
it is recommended to initialize memory before copying the content.
This patch adds initializing memory before copying image to
destination memory.

 {
 	uint32_t arc_dst = (uint32_t)arcboot_rom_get_arc_addr(dst);
+	int init_len = len;
+
+	/* Skip memory init for ARC1 ICCM and DCCM as its already initialized */
+	if (!((dst >= HL_ARC1_ICCM_FULL_BASE) &&
+	    (dst + len <= HL_ARC1_ICCM_FULL_BASE + ARC1_MEM_SIZE))) {
+
+		/*
+		 * Align length to 16 bytes for memory initialization.
+		 * max length check is already done in fit property verification. If
+		 * image is passed with memory maximum length, then length will
+		 * be already 16 bytes aligned.
+		 */

+			init_len += (MEM_INIT_SIZE_ALIGN - (init_len % MEM_INIT_SIZE_ALIGN));
+
