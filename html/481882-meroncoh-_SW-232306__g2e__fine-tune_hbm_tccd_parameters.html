Commit Message

[SW-232306] g2e: fine-tune hbm tccd parameters

In order to limit the HBM BW to 1400 GB/s, there is to update the
HBM tCCD parameters as well (i.e., tCCDL, tCCDS, tCCDR).
(tCCD = Column-to-Column Delay).
In addition there is to update the HBM DRAMTIMING8 config register.
These updates should take place only if it is a bis-e-compliant device.
