[SW-115022] hl225b: rma mode: dont enable debug

On HL225B cards, no debug features are allowed.
Enabling RMA on HL225B card, should not disable security

BIT(25) of efuse indicates if the card is BIS complaint or not
If this bit is set, entering RMA debug mode is not allowed
