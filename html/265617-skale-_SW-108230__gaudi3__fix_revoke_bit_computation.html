Commit Message

[SW-108230] gaudi3: fix revoke bit computation

Allowed revoke bit values are 0, 1, 3, 7, and 15. In current code
when fuse bit is set to 0x10, ROM computes it to 0x0 which will
allow all keys to work. This patch adds a fix.
