Commit Message

[SW-0] boot_if: rename and comment cmd clr func

The cpu_boot_cmd_clr() function's use must be reduced to only the cases
when it is absolutely necessary as the cmd/message register should be
written by LKD solely.
The only one case when this register should written by ARM is when LKD
performs the hard reset, as the reasons for performing hard reset might
render PCI not to be reliable and thus LKD clear of the register might
not propagate.
Change the function name to reflect the purpose and add a comment
describing the use.
