Commit Message

[JSW-705]  hls2-bmc: don't search gpu specs

hls2 and ami post script is serching and copying common headers
and dev specific headers in order to build habanalabs utils
such as fw-loader.
For GPU project some common headers are duplicated in
order to start from a clean slate, and avoid dragging Gaudi defines.
This duplication creates an issue for the script searching for headers.
Since JGS devices will never work with HLS2 as well as AMI,
build should not look for GPU headers.
This patch adds a directive to avoid serching specs/gpu folder
for headers.
