Commit Message

[SW-229990] scripts: serdes: update rack config

SkyRiver3 includes 2 host nodes, each one connects to 4 nodes and each
node contains 4 OAMs. In total there are 32 OAMs.
They are all connected among each other by SerDes switches.
i.e. 16 OAMs per host -> 16 module ids. (4 bits)

Whitebox rack contains 16 nodes. On each such node there is a host
and 4 OAMs. In total there are 64 OAMs in a rack.
i.e. 4 OAMs per host -> 4 module ids. (2 bits)

This patch updates the serdes configuration accordingly.
