[FSW-402] fs1: init: add cfg base to cfg reg

with this patch, added support to add cfg base
to global regmap read/write api, and added
correction in die id read. removed die id replace
logic in regmap read/write, because of
cfg_addr_mnpl register is enabled by default.
irrespective of any die id in register offset
request will reach to same die by default.
