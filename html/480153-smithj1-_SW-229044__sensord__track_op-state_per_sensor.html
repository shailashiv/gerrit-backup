Commit Message

[SW-229044] sensord: track op-state per sensor

For state sensors, track the operational state per composite sensor
rather than a single state for the overall state sensor.  This is
needed because it is the composite sensors that can be individually
enabled/disabled, not the overall state sensor.

This increases the memory needed to track state by 16 bytes per
sensor.  In preboot this adds 928 bytes total.  In mgmt the
sensor state is allocated dynamically out of the HBM memory pool.
