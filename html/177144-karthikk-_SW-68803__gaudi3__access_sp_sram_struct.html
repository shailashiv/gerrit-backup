Commit Message

[SW-68803] gaudi3: access sp sram struct

Currently security data from fuse that can be re-used in
boot rom and other repos further down in the boot flow are
stored in the initial region of the sp sram memory in order
to enable faster access to the data.

But this is stored and read using hardcoded offsets which
leave us prone to memory holes and a ledger to maintain
the data offsets that need to be used to read/write and
avoid overwriting of the data.

This is avoided by accessing the sp sram as a structured
layout, hence referencing the member for read/write.
