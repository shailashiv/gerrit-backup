Commit Message

[FSW-334] fs1: pci: fix bar size setting

Bar size is set by writing a mask to the shadow register, not the actual
DBI register. the shadow register defines which bits can't be written by
the host, and that is how the host determines the size during
enumeration.
At this stage only Bar0 is resized to 1GB, the other BARs are remain
with default size.
