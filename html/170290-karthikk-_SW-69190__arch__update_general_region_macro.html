Commit Message

[SW-69190] arch: update general region macro

Currently there are 2 macros used to define base of general region
HL_SDRAM_BASE (Gen region base in arc viewpoint), HL_SRAM_BASE (Gen
region base in 64 bit).

In the existing platforms, the address space for memories in general
region were not strictly in GEN_BASE + offset format.

Updating the macros to address it as general region base instead of
SRAM, SDRAM for better readability. The offsets are adjusted to
the correct GEN_BASE to follow the GENBASE + offset format.
