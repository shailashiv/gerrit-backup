Commit Message

[FSW-14884] gt: refactor gt boot init to state machine

This redesign replaces the hardcoded GT boot sequence with a data-driven
state machine using a step table (gt_boot_sequence).
Each step specifies a command and an optional wait condition,
improving maintainability and extensibility.

- All GT boot actions are now implemented as static inline helpers and
dispatched via gt_boot_execute_cmd().
- Added gt_boot_run_sequence() to run the sequence,
handling command execution and state waits.
- Improves clarity, reduces code duplication, and makes the boot flow
easier to modify or extend.
