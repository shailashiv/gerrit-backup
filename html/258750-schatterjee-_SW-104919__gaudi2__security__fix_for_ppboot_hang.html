[SW-104919] gaudi2: security: fix for ppboot hang

This patch fixes hang issue seen in ppboot when real
security is enabled. The hang is observed to be in
arcboot_rom's memcmp() function called from rsa_verify().
The root cause of this issue is not found yet. But it is
observed if https://gerrit.habana-labs.com/#/c/254030/ is
reverted issue is not reproduced. Alternatively doing the
modification done in this patch also solves the issue
while it keeps the changes done in that patch. So this is
pushed to unblock enablement of real security.
