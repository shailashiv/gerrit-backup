Commit Message

[SW-22029] recovery: add LBW 4B termination support

As per hardware team recommendation, LBW 4B termination support
should be added in arcboot as part of recovery flow based on the
BIT(25) of syscfg fuse. This patch add changes to enable above
mentioned mechanism as part of recovery flow. Once enabled, any LBW
transactions which are larger than 4B will be terminated.

LBW 4B termination is enabled by setting BIT(1) of
PCIE_WRAP_SPECIAL_GLBL_SPARE_0 register. Also the fused syscfg efuse
value should have LBW 4B termination enabled.
