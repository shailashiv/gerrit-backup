Commit Message

[SW-46517] preboot: greco: remove led on support

Currently due to GPIO2 is unset as part of led ON function,
it causes problem in running secureboot flow after reset as
arcboot ROM checks this GPIO2 and execute recovery flow if
its unset. Till this issue is fixed, disable LED on support
from preboot.
