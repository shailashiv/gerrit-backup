Commit Message

[SW-0] preboot: gaudi2: clear flr reset

If FLR interrupt is received while FLR is handled by FW, FW issues
FLR reset by setting pcie2psoc bit FSM_CTRL register. However this
bit is not self clear. This patch adds support to clear pcie2psoc bit
as part of preboot init sequence.

+static void clr_flr_reset(void)
+{
+	u32 val;
+
+	/*
+	 * If FLR reset is issued by FW, the reset
+	 * needs to be cleared by FW as the bit is not
+	 * self clear.
+	 */
+	val = regmap_readl(mmPCIE_WRAP_FLR_FSM_CTRL);
+	val &= ~(PCIE_WRAP_FLR_FSM_CTRL_FSM_PCIE2PSOC_RST_SET_MASK);
+	regmap_writel(val, mmPCIE_WRAP_FLR_FSM_CTRL);
+}
+
+void preboot_reset_init(void)
+{
+	clr_flr_reset();
+}
