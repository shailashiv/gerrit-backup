Revert "Revert "[SW-57800]: tpm: add pcr verification""

This reverts commit 530600f6e22c684e29f136990ab55659ddc88197.

Testing shows that removing this patch causes issues with pci
link establishment after prstn.
Speculation is, since this shortens the ppboot execution time,
preboot is running sooner and somehow inteferes with the pci
link.
