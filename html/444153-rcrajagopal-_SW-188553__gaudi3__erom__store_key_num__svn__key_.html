[SW-188553] gaudi3: erom: store key num, svn, key revocation

Store the loading firmware key number and svn into fw info.

To avoid the below condition, store the key revocation & min svn
value (present in efuse) to fw info, before the corresponding validation.

1. flash the firmware signed with key1 and key0 is not revoked.
2. Now, if we read the fw info, it will say none of the key is revoked.
3. revoke key0 using key_revocation.itb.
4. flash the firmware signed with key0 and it will fail at key validation.
5. Now also fw info say none of the key is revoked
