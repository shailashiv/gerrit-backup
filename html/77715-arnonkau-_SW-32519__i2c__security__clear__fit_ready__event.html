Commit Message

[SW-32519] i2c: security: clear "fit ready" event

When a fw loader imitate the LKD and send a "fit ready" command
to the preboot.
Preboot goes into a loop and loose its i2c connectivity.
That happen only when the fit image is corrupted.

Use a flag that differentiate between a checked FIT and a verified FIT.
Allows ignoring an uncleared FIT_RDY, and by that prevent unnecessary
i2c disable-enable loop.
