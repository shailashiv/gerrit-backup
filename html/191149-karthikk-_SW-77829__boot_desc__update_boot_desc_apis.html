Commit Message

[SW-77829] boot_desc: update boot desc apis

As we skip the re-processing of the boot descriptors based
on validation pass flag, the source of data should be a
source that would retain its value over reset cycles (except
cold reset).

Hence all the pointer accesses are replaced with data from
boot info which is stored in sp sram.

We now get the desc size and count from boot info, rather
than usage of pointers.

Return value checks have also been added for boot info api calls.
