Commit Message

[SW-81745] boot_desc: update logic for erom desc

Update boot descriptor logic for erom. Erom would support
erom_tpm, erom_recovery and erom_pcie image.

Update:
1) Erom image descriptor structure not stored in a rom variable,
instead referred from iccm, similar to spi fw image descriptor
processing.

0-128KB is reserved for execution of eROM images (1 of the 3) .
128KB-192KB is reserved to load the boot info read from SP SRAM .
Hence 192KB offset is used for eROM image descriptor DMA.
