Commit Message

[SW-0] pci: sync earlier with BTL PCIe image

Patch 5bd5c00 [SW-0] pcie: add log of image id (2019-05-23 - Noam Camus)
Is causing a race condition on the UART between PCIe image and the
Preboot.
Solution is to sync with PCIe image before any usage of UART.

This is possible since:
In GOYA the PRSTn is connected to rst_n via CPLD. So this check is
irrelevant (once we reach pre-boot, prstn is always de-asserted)
For GAUDI, we can move the check to an earlier stage since the pre-boot
does not control the PCIe- all is done via the BTL instructions.
