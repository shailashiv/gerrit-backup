Commit Message

[SW-56687] ppboot: size check for ppboot binary

Enabled size check for ppboot binary in gaudi2 arc
Gaudi2 arc Ppboot build will fail if binary size is greater than 16KB

We cannot allow large foot print of ppboot as it will increase timing
for arcboot to copy from flash to SRAM and by that will japrodize
PCIe link establishment due to breaking 20mS time limit of PRSTn.
