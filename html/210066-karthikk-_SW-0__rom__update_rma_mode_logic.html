Commit Message

[SW-0] rom: update rma mode logic

As per the updated gaudi3 security specification, in case of
rma mode, fake fuse from flash is required to be used instead of
actual fuse. This is to provide complete flexibility to the system
team to debug the rma occurrence .

It is agreed with security architect that the fake fuse contents
in spi need not be validated.
