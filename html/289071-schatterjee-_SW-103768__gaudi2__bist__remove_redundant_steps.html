Commit Message

[SW-103768] gaudi2: bist: remove redundant steps

Incase BIRA fails, BISR and BIST are performed for
a ring after BIRA in sequence. So id_select and ring_select
steps do not need to be done for all the operations.
This patch modifies common wrapper to call id_select and
ring_select functions only for BIRA.
