[SW-26273] fwupd: prepare error sending state

Sending a FIT as part of status response implies sending
via SLOW MODE. The best way to execute it was by adding an operation
to the module run handler. Explicitly handling an error FIT response
sending. Due to lack of free command's enumeration. a combination of
flags will replace it as the condition to invoke the error handling.
Two conditions are needed:
1. Informed by the error's inform function that an error occurred
2. A request to send a status response

As mentioned, the status response sending procedure, can be triggered, by
a request, but will be delayed for after turning into SLOW MODE.

NOTE: Do to partial implementation at this stage the flag will not be
set to true. That will be supported at later patches
