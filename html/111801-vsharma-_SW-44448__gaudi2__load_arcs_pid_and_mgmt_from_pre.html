[SW-44448] gaudi2: load arcs pid and mgmt from preboot

This patch adds support to load and run arc pid and arc mgmt images
received from gaudi2-boot-fit.itb via host/lkd.
Images are copied to respective iccm/dccm area via memcpy io block from
sp sram.
