Commit Message

[SW-46313] security: enable sram sf access

Enable read access to SRAM and SPI address ranges when a special FIT is
transferred via ELBI interface to open/close access.
While the SPI access is open, no SPI transaction from preboot is allowed
and any SPI transaction is ignored and result with an error message.
SRAM and SF access is not allowed in case that HBM init have failed.
