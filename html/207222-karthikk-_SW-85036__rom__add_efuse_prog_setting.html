[SW-85036] rom: add efuse prog setting

In gaudi3 as a part of PSOC_EFUSE, a new field PROG_ADDRESS is added
which specifies the write range to efuse. This field is explicitly
set to the default value in soconline as the boot manager can
possibly change this.

This change is recommended by the psoc design team.
