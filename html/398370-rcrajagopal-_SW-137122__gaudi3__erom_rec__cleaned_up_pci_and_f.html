[SW-137122] gaudi3: erom rec: cleaned up pci and flr handling

In erom, we always bringup pcie link through ARC1 only. Here
we won't run PIF ARC and it can't handle FLR RST. so we should
not enable flr handling in PIF ARC.
By default HW will handle the FLR.

Since PIF ARC not running, is_pci_initialized should check
smlh, rdlh registers. Moved pci dev specific functions to
device specific files.
