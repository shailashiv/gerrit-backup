Commit Message

[SW-36138] gaudi2: wd de-assertion

At PRSTn CPLD asserts GPIO62 and starts WD timer.
Before ppboot is loaded it checks GPIO2 to determine
if recovery code to be executed. In normal flow GPIO2 is
de-asserted, so PPBOOT, PREBOOT normal flow get executed.
PREBOOT is supposed to de-asserts the GPIO62 pin to avoid
expiry of WD timer. Failing to do so would result in expiry
of WD timer which asserts GPIO2 and triggers PRSTn. So in the
boot cycle, flow goes to recovery mode.

This patch adds the de-assertion of GPIO62(i.e. port "GPIO3",
pin 14). This de-assertion is done at the end of preboot when
all initializations are done successfully.
