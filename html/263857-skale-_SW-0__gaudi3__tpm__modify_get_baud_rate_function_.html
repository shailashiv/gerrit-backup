[SW-0] gaudi3: tpm: modify get baud rate function for pldm

Currently hl_spi_baudr_get function is common for onix and pldm
and separate for ASIC where its determine by retrieve pll frequency
for SPI. In order to keep common code for asic and pldm this patch
add similar hl_spi_baudr_get for asic and pldm and add separate
function for onix.

Note that TPM is not tested on PLDM.
