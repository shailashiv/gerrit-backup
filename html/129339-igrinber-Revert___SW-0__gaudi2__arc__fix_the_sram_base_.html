Revert "[SW-0] gaudi2: arc: fix the sram base"

The documentation is misleading stating the region is SRAM, while in
fact it is not pure SRAM, but includes also a reserved area which is not
populated with SRAM. Thus the actual SRAM array starts at offset of 16MB
from the SRAM region start.
And thus the correct base for actual SRAM array start is
SRAM region base (0x10000000) + reserved area size (16MB) = 0x11000000.
Revert the fix as it is wrong and add a comment explaining the correct
SRAM base.

This reverts commit dfc6fee7d19f9f861decaf503345ac836695ff0d.
