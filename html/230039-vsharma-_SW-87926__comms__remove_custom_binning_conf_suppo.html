Commit Message

[SW-87926] comms: remove custom binning conf support

This patch remove support for sending binning conf
to preboot from lkd via comms. This was used to test custom
binning options during power-on or sival tests.
New infra to set custom binning via debugfs is added,
in which lkd will send custom binning masks by
echo 1 | sudo tee /sys/kernel/debug/habanalabs/hl0/fw_binning_set
which will be stored in bootinfo and will apply after next
hard reset.
