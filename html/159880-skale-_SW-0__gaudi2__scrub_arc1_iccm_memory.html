Commit Message

[SW-0] gaudi2: scrub arc1 iccm memory

In order to avoid any ECC exception observed on ARC memories, it is
recommended to scrub both ICCM and DCCM memories. Since ARC0 memories
scrubbing is already done and ARC1 DCCM is scrubbed as part of ROM,
this patch add changes to scrub ARC1 ICCM memory conditionally on
cold reset.
