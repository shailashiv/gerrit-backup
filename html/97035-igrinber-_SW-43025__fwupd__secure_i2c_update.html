Commit Message

[SW-43025] fwupd: secure i2c update

When an image is sent by I2C we do the same actions in terms of security
as if it was from PCIe, thus the I2C image gets exposed to the PCIe.
As part of the separation, introduce another state field which is
oriented to prevent this exposure of the image.
