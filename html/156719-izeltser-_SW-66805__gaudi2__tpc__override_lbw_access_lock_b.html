Commit Message

[SW-66805] gaudi2: tpc: override lbw access lock bit

After FW is accessing the TPC configuration space invalid_lock_access
irq is observed. The cause for this violation is that ARM uses the
same AxUSER default value both for LBW and HBW. HBW access AxUSER[10]
is MMU BP while for LBW this is Lock indication.

Workaround:
Use CPU master IF to override LBW access-
1. Configure Value of 0x0 to CPU_MSTR_IF.LB_LOCK
2. Configure value of 0xFFFF_FBFF to CPU_MSTR_IF.LB_OVRD
