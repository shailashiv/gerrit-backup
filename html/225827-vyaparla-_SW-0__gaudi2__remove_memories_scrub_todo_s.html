[SW-0] gaudi2: remove memories scrub todo's

This patch removed TODO comments of scrubbing VDEC, TPC and
XBAR memories. Scrubbing of XBAR memories are not required
since there is no partial write allowed to XBAR memories.
VDEC scrubbing is done as part of SW-88333. TPC unit reset
will init all of TPC memories.
