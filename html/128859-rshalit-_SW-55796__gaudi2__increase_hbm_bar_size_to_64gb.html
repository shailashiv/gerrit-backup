Commit Message

[SW-55796] gaudi2: increase hbm bar size to 64gb

BAR size for HBM is set to 64GB instead of default 32GB.
This is required for host for access of all available
space, so that host won't need to shift small BAR window
for every access which is outside the window.
Therefore, this method is more efficient and more secured.
