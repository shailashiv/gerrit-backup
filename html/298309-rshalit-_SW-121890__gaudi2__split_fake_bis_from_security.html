Commit Message

[SW-121890] gaudi2: split fake bis from security

In hl_sec_efuse there is bis_compliant field, for indication
if device is bis compliant.
But in order to allow using fake bis independently from
faked security, we use scratchpad register mmCOLD_RST_DATA
bit fake_bis_compliant as indication if faked bis is
enabled.

This patch modifies preboot_is_bis_compliant_mode logic
as following:
1. If it is a real security (as indicated by efuse), then
efuse content (specifically bis_compliant field) defines
if bis compliant indication is enabled.
2. Otherwise, scratchpad register mmCOLD_RST_DATA, fake_bis_compliant
bit indication defines if bis compliant indication is enabled.
