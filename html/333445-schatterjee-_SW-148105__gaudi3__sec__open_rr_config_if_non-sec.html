[SW-148105] gaudi3: sec: open rr config if non-secured

So far in ppboot (gaudi3) RR protections for lbw,
hbw config space are opened for PLDM target.

This patch modifies the implementation to open only if
security is not enabled in efuse.
Same is done for both pldm and asic targets.
