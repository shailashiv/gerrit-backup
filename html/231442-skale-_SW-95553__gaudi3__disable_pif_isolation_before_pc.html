Commit Message

[SW-95553] gaudi3: disable pif isolation before pcie configuration

By default, the PIF isolation is enabled for slave die, that means
any access to PCIe domain register will result into hang. This patch
add changes to disable PIF isolation if pcie_ctrl fuse value is enabled.

Note that the PIF isolation is by default disabled on master die,
however it disabled for both dies based on die_id for safer side.
