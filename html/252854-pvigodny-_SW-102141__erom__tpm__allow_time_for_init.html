Commit Message

[SW-102141] erom: tpm: allow time for init

When waiting for TPM initialization, we poll until successfully
reading TPM_ACCESS_VALID from SPI or timing out after 2000 MS.

However, if the device is not initialized the first SPI reads might
themselves time out. This fix changes the behavior in such case to keep
trying to read the status from SPI within the 2000-MS timeout period
instead of failing initialization.
