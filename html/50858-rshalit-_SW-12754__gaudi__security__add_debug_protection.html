Commit Message

[SW-12754] gaudi: security: add debug protection

Add debug protection by using nPRESETDBG bit in
mmCPU_CA53_CFG_ARM_RST_CONTROL register in order to
disable debug and jtag functionality. Disabling
debug functionality is done only when dip switch
for debug is in disabled state.
