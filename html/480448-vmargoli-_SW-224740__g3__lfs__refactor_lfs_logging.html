[SW-224740] g3: lfs: refactor lfs logging

Refactor LFS logging to simplify and eliminate
some possible problems
Now root folder of LFS partition will contain
only 2 files: log.txt and log_backup.txt
All components (preboot, arcmgmt) will write their
logs to log.txt. When it reach max. size (configurable),
it will be copied to log_backup.txt and recreated.
