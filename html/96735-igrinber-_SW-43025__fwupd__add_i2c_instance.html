Commit Message

[SW-43025] fwupd: add i2c instance

Since the requirement to close the PCI interface on demand, we need to
separate the interface backend storage, so the I2C interface will
continue to work regularly.
We add another runtime instance of the FWUPD module, so it can live
along with PCI instance as an independent one.
This also requires the I2C indirect module to route the FW_UPD
configuration accesses to the new API instead of just register write.
