Commit Message

[SW-34091] gaudi: add timeouts in while loops

Preboot needs to reach command monitor loop without getting
stuck in indifinite while loops to bring up i2c slave module.
To achieve this there are two places this patch adds timeouts.
-Wait for BTL sync which waits for boot manager execution
 to finish. Timeout of half second.
-Wait for PCIe phy external load complete. This wait is
 required for applying synopsys WA and should happen in
 300 us. Overall timeout of 576us.
