[FSW-2704] fs1: add valid manifest index

In cases where manifest and ppboot validation passes, bootrom
will store valid manifest index in cold reset flops.
This bit value is only valid if validation_pass flag is set.
0 - SPI Manifest 0 is valid
1- SPI Manifest 1 is valid
