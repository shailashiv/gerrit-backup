Commit Message

[SW-57783] pci: remove memory access protection during iatu init

Testing shows that some hosts misbehave when the device pulls down
the mem_en bit right after the host sets it up.
Since now we are protecting each region of the iatu during
initialization, we can remove the memory protection by the mem_en
bit of the configuration space.
