Commit Message

[SW-25060] greco: add sp polling registers

To avoid interrupt storm from LKD to host, GIC irq controller
and ARC SW irq will only be available for privileged entity.
LKD has to use scratchpad registers to generate host irqs.
To provide these register offsets to LKD, added them to dynamic
cpu register struct.
