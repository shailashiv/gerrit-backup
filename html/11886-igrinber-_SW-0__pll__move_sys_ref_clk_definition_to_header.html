[SW-0] pll: move sys ref clk definition to header

Currently, all habanalabs devices use the same SoC reference clock.
Although, this might seem like a "not so good" design, move the
frequency define to the common header.
This way we can use it for calculations in generic files.
As an example, switch bypass cycles calculation to use it.
