Commit Message

[SW-20154] change the key storage function in psoc_security

PSOC SECURITY has specific entries to store the key
hashes, for user debugging. In gaudi2, it has been
decided to store just the 256 bits of the key (despite
the hash being 384 bits). This is as per recommendation
from Security architecture.
