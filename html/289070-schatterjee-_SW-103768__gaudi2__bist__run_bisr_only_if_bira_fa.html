Commit Message

[SW-103768] gaudi2: bist: run bisr only if bira fails

This patch adds logic to skip running soft repair if BIRA
is ok for that ring. This is to avoid false positives
observed on few devices where for certain ring(s) bira passed
but bist failed. Running BISR on a ring may potentially override
hard repair/BIHR data and that would result in BIST failure
after BISR. This patch modifies the flow to run BISR and subsequently
BIST only if BIRA fails for a ring.
