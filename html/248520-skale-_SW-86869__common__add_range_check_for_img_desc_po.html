Commit Message

[SW-86869] common: add range check for img desc pointer

Once manifest image is downloaded ROM performs sanity check of each
image downloaded as part of manifest. In order to get start address
of each image, rom adds base addr with the address from array received
as part manifest header. Currently ROM directly access that image addr
by adding the offset which might point to some other address outside
the manifest range. This patch performs range check for each image
descriptor base address to be within manifest downloaded area.
