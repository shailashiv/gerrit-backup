Commit Message

[SW-114487] gaudi2: boot_info: modify address

This patch modifies device macros for boot_info base
from current ARC0 ICCM to SPSRAM(offset 20KB).

This is a done to avoid DMI access to ARC ICCM.
But as SPSRAM content is cleared during several resets(e.g.
hard_reset, prstn) a persistent copy to be maintained in ARC1 ICCM
to preserve any update in boot_info.
