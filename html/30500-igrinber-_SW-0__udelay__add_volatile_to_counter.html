[SW-0] udelay: add volatile to counter

We have observed a different behavior of the new compiler.
It removed the udelay function code, and only return directive left.
This apparently happened because the compiler thought the function has
no effect, which is true regarding the data, but not the execution time.
Add volatile to the counter variable to prevent such a compiler
behavior.
Later we might want to change the function to use timers and thus also
raise its precision.
