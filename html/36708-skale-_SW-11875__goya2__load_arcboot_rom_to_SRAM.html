[SW-11875] goya2: load arcboot_rom to SRAM

Currently arcboot_rom for onix platform is loaded in scratchpad SRAM.
Since we are loading preboot in scratchpad SRAM, change arcboot_rom to
load to SRAM.

Note that SRAM is comparably slow to ROM in execution but it should not
be an issue as we're not bringing up via code and loading of arcboot_rom
at SRAM locations is for debug purpose only.
