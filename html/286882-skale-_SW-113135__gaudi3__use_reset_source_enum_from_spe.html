Commit Message

[SW-113135] gaudi3: use reset source enum from specs

Currently, ppboot and preboot has different enums defined for
reset source. One is defined with values incremented with bit shifts
and other defined as bit numbers. Since the value read from BTM FIFOs
reflects bit numbers, this patch removes reset source enum defined in
ppboot and use it from specs file.
