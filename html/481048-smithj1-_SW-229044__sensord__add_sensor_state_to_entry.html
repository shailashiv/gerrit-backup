Commit Message

[SW-229044] sensord: add sensor state to entry

Include a pointer to the sensor state within the sensor entry struct.
This will give all sensord handlers access to the current state,
allowing handlers to adjust processing based on current operational
state.

This adds 4 bytes per sensor.  In total this adds about 200 bytes to
preboot and 1400 bytes to mgmt DCCM. The alternative would be to pass
the sensor state as a new parameter to hundreds of sensord handlers
across preboot/mgmt/agents.
