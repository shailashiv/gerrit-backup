[SW-0] goya2: uart: add uart padsel conf

UART pad select configuration added for preboot
and ppboot goya2 asic platform.

Following are the pad/pinmux settings for uart,

GPIO_08 (UART 0 RXD, ALT FUNC1)
GPIO_09 (UART 0 TXD, ALT FUNC2)

These settings are already done in BTL code. So
these are not required in flow where BTL is run.

Only in non-BTL flows(e.g. JTAG, secure boot) these
settings are required.
