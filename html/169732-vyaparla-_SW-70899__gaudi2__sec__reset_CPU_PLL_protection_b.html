Commit Message

[SW-70899] gaudi2: sec: reset CPU_PLL protection bits configuration

This change resets CPU_PLL protection bits configuration if
security is not enabled.
When fake security is enabled, all the protection bits configuration
registers are configured. Disabling fake security followed by a reboot
issues a PRSTn reset.
As part of PRSTn reset, CPU_PLL is not getting reset due to which
the protection bits configuration registers programmed as part of
security init are not getting reset even if security is disabled
