Commit Message

[SW-50880] ppboot: greco: arc: remove delay from halt n reset

For performing PCIe initialization on ARC0, halt and reset for
ARC0 needs to be performed before udelay init as part of early plat
init function. Upon doing experiement without using delay, ARC responds
very quickly to halt request without entering wait loop. This patch
removes udelay from halt and reset function of ARC and increase
number of retry.
