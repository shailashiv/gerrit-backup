Commit Message

[SW-20154] Makefile: expand include path for version info

VERSION_STR is extracted from preboot.h file, using a
simple sed script. If the preboot.h file has any other
header inclusion, it will result in an error of "file
not found" since the include path is just limited
to current working directory. To prevent this, expand
the include path to include other folders too.
