[FSW-11114] fs1: add export functions

Functions which are identified to reuse in other
modules like ppboot, preboot are added to
boot_rom.txt file. Boot ROM make file will extract
this symbols from bootrom.elf to export.elf.
export.elf will be used if any other module need
to call the function which part of exports, to
reuse same code from bootrom.
