Commit Message

[SW-103986] fit: img load: halt arc0 only on need

When loading an image, halt ARC0 only if the image loaded is intended
to run on ARC.

If we are loading an image on ARM, we can let ARC0 continue trying to
establish PCI connection.

Issue the following warning message:
    "Warning: ARC0 busy with PCI init, halting anyway"
In case ARC0 needs to be halted but it is still busy with PCI
initialization.
