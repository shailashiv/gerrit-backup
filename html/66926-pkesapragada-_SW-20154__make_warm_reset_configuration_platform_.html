[SW-20154] make warm reset configuration platform specific

Configuration of PRSTN to reset the ARCs/PSOC during
warm reset is platform specific. Because, in Gaudi2,
it involves programming the PSOC RESET registers, which
are different than Goya2. Hence move them to platform
specific code
