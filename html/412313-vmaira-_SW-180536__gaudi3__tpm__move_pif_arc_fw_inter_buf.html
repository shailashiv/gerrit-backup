Commit Message

[SW-180536] gaudi3: tpm: move pif arc fw inter buffer

During cold boot PIF ARC firmware is copied from SPI
flash to ARC1 ICCM, and later copied to the PIF CCMs.
This overwites the manifest image that is copied to
ARC1 ICCM by bootrom.

For Gaudi3, we extend the PCR of the manifest hash
alone, instead of separately extending PCRs for
individual ppboot and preboot images. In order to
prevent the manifest image overwrite during PIF ARC
firmware copy, the buffer used to copy PIF ARC
firmware is moved from ICCM base by 64K offset.
