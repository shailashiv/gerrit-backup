Commit Message

[SW-62976] gaudi2: adjust fit response offset

Gauid2's FW, sends a wrong memory offset as part of the FWL protocol's
return status command.An accompany FIT response, may be sent back to the
FWL. It is accessed by sending the offset in SRAM to the FWL as part
of the status command.

Currently the preboot send wrong offset address to the FWL while
responding with the proto status command.

The same occurs with the FWD_MAP response.
