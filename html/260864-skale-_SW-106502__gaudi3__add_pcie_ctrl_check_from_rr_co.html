[SW-106502] gaudi3: add pcie ctrl check from rr config

security_rr_close_pcie_config function to close range register
is called from both dies based on RR fuse bit as part of security
init. This patch adds pcie_ctrl fuse check for configuring RR
for slave die which allows RR configuration on slave die only
if pci_ctrl bit is set to 1.
