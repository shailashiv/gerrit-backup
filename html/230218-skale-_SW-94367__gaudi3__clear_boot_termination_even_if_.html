Commit Message

[SW-94367] gaudi3: clear boot termination even if link is up

Currenlty, clearing of boot terimnation is performed as part
of PCIe link up routine. However there is possibility if
boot termination is enabled somewhere in flow or as part of reset
sequence. To avoid such scenario, this patch adds clearing
of boot termination even if PCIe link is detected in ROM recovery
flow.
