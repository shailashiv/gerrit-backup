Commit Message

[SW-12005] boot_desc: use descriptor load addr

Now that the descriptor has its image load address inside, we can start
using it.
Replace usage of the hard coded load address and use the one provided by
the image descriptor.
Since previousely the differences between Goya2 ARC and ARM were handled
in compile time (the PREBOOT_TEXT_BASE was defined per architecture),
and now we read the address in runtime, we split the handling of it
among architecture/platform specific files.

Note: the split duplicates some code, but makes this work in runtime on
      all platforms.

TODO: introduce architecture specific paths, so we will not need to
      duplicate the code among platforms.
