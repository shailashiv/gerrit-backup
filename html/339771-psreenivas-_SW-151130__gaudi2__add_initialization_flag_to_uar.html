Commit Message

[SW-151130] gaudi2: add initialization flag to uart module

The prints in arc0 will impact pcie link up timings
the uart module is common for arc0 and arc1 and trying
to print from both the arcs can have sync issues.
This patch adds initialized flag in uart which is
default set to false and will be set to true as
part of device_init_uart. The device_init_uart
init is done only for arc1. Hence all the prints
from arc0 will be ignored.
