Commit Message

[SW-67660] gaudi2_arc: load preboot from offset

With the new flash layout (below), preboot images are located at
8th and 10th sectors to accommodate 128KB preboot binaries.
But primary and secondary image offsets in image pointers can't be
changed as ARC boot rom checks for ppboot at primary/secondary offset +
64KB.

This patch modifies ppboot_flash_image_offset to fetch from the new
preboot binary location in flash.

New layout:
Sector  image
0	EROM_BIN
1	SECURITY_BIN
2	Unused
3	PPBOOT_BIN_1
4	Unused
5	PPBOOT_BIN_2
6	Image pointers ARM
7	UENV (reservd for any internal testing procedure)
8-9	PREBOOT_BIN_1 (128KB)
10-11	PREBOOT_BIN_2 (128KB)
