Commit Message

[SW-31046] greco: scl low i2c slave in debug mode

Before power-up Soc BMC assert HOST_GPIO to LOW level.
Preboot fw monitors HOST_GPIO as follows:
LOW level- Greco in debug mode. Fw will wait till
HOST_GPIO is asserted to HIGH.
HIGH level- FW will read and write to modules and
monitor HOST_GPIO level.

When user done reading/writing from Soc, he must assert
HOST_GPIO to high level. For greco host_gpio is GPIO[44].
