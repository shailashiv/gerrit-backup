Commit Message

[SW-99461] gaudi3: replace boot info usage in boot flow

Currently boot info is a part of boot descriptor init. In order
to make a backup in case boot info api should not be used(determined
using boot_info_skip efuse flag), the code needs to be restructured
in the following way:

1) Boot info infra should be used only after fake fuse is initialized.
2) Mandatory descriptor data that was earlier read using boot info data
should be backed up in a persistent memory.
3) In case of a need to skip the boot info in rom, the boot flow to
ppboot should still continue using rom variables.
