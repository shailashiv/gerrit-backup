Commit Message

[SW-0] erom: remove pcie_init dead code

PCIe init in erom code is done as part of secondary main
in arc0, in function pcie_config().
PCIe enabling in EROM is not the same as PCIe enable in
preboot, as it only enables GEN1 and not GEN3 PCIe.
This patch removes other related pcie init functions,
which are not required nor being called, and may only
confuse when reading the code.
