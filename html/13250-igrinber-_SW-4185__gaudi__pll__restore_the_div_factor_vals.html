Commit Message

[SW-4185] gaudi: pll: restore the div_factor vals

The IF and MESH PLL divider output 1 factors are still using the -1
values for specifying the clock selector value to reference clock
output.
Since commit 6a29399 ([SW-0] pll: extend the hl_pll_cfg structure),
we have the special field for specifying the clock selector values,
so there is no need for "special" value in div_factor field.
Restore the IF and MESH div_factors to their designed values.
