Commit Message

[SW-49810] ras: ignore reset reason after reboot

Reset reason is transferred from preboot to Linux by SPSRAM so that the
BMC is able to read the watchdog error if exists which caused the reset.
The problem is the same reset cause stored in SPSRAM is transferred back
to preboot which sends it back to Linux, indicating the same reset
reason again and again.

Fixed by overriding reset reason on SPSRAM when preboot loads. Any reset
cause indication needs to come from either the driver or HW.
