[SW-0] ppboot: set privileged mode to start of ppboot

Currently, ARCs are set to privileged mode as part of ppboot security
init function. However till that point ARCs mode is changed to user
mode due to reset and it tries to access registers which are set to
privilege/secure mode and not been reset as part of reset. For example
CPU_PLL registers are marked as privileged and ppboot access it as part of
udelay init where ARCs are still in user mode. To resolve this issue,
set ARCs to privilege mode at very start of ppboot.
