Commit Message

[SW-0] gaudi3: add polling macro for writes inflight

Since there is no coherency between write and reads in HL devices,
and early write response is enabled, we should be very careful
and make sure there are no writes inflight that might affect a register
we about to read or some functionality we about to execute.
A macro is added for waiting until there are no more writes inflight.
The macro identifies the CPU on which it is executing, and polling on
the relevant register.
