Commit Message

[SW-67082] gaudi2: read fake security from cold reset flops

This change add support to read fake security from cold
reset flops2 register which will be set by ARC mgmt when
CPUCP_PACKET_FAKE_SECURITY_SET is received. This change
is to read fake security in ppboot to change pci device
id to secure id when fake security is set. Reading boot
info in ppboot is costly, which may cause link up issue
