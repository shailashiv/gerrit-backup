Commit Message

[FSW-2704] fs1: image prefetch for ppboot

This patch adds flow to prefetch ppboot image
before manifest validation. This api will try
primary manifest first and if failed will try
secondary manifest for ppboot image. To make
this api non-blocking only first dma chunk is
initialized.
