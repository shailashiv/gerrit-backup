Commit Message

[SW-86869] common: modify logic for computing min fw version

Current logic allows to load minimum firmware version 0 and 1 if
0th bit of firmware version is burned in efuse. firmware version 0 is
pre-production version and should not be allowed to load if 0th bit
is burned (ie minimum firmware version 1) in efuse. This patch updates
logic to allow only minimum firmware version 1 if 0th bit is burned.
This also means the allowed production minimum version range is
from 1 to 128.
