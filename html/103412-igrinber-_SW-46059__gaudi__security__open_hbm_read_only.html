Commit Message

[SW-46059] gaudi: security: open hbm read only

Once we finish the HBM initialization, we open the whole HBM range to
PCIe for validation.
Unfortunately, the open was done for both: read and write.
The validation scenario requires only read operation, not write.
Fix this by opening for read operations only.
