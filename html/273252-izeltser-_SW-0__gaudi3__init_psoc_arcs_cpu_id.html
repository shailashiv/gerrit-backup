Commit Message

[SW-0] gaudi3: init psoc arcs cpu id

In order for the FW to be able to get the CPU ID on which the code is
executing, this ID must be written before the CPU reset is released.
Since ARC1 is the first to run (by HW), its ID will be the default (0).
For the other CPUs a relative ID is set. So the code can easily
normalize the cpu ID by adding '1' to whatever is read from the
IDENTITY register.
