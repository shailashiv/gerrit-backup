Commit Message

[SW-17915] ppboot: module_pci: remove pcie_en reg

Remove usage of mmPREBOOT_PCIE_EN register.
Instead, before PCIe enable, we first check the
reset cause (SW_ALL_RESET, watchdog, cold reset, etc.),
and decide accordingly if PCIe should be initialized or not.
Note that in this patch we still only imitate the previous behaviour
(with mmPREBOOT_PCIE_EN and the MAGIC words), but instead of using
PCIE_EN register, we decide if PCIe should be initialized or not
according to reset cause.
