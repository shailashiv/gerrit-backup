Commit Message

[SW-55214] ppboot: gaudi2: enable axi drain

AXI drain is being enabled early in the boot sequence, so if the
code is accessing a block that is still held in reset state (like
pci blocks during prstn) the transaction will be handled and not
cause a device hanging.
