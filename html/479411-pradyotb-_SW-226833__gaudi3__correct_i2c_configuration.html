[SW-226833] gaudi3: correct i2c configuration

Configure i2c configuration to the following:
i2c0: 400Khz
i2c1: 270Khz
i2c2: 100Khz
This change is required because by default,
i2c clocks are misconfigured to run at 270Khz.
We are keeping i2c1 at 270 for consistency.
Also we are using the FAST configuration
for configuring 270KHz because FAST is for
speeds <=400 KHz
