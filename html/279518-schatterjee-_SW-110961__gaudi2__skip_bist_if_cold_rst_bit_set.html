Commit Message

[SW-110961] gaudi2: skip bist if cold rst bit set

This patch adds support to skip sram bist for 48MB sram
if cold rst bit (bist_skip_enable) is set.

FW issues hard reset after running bist. So to avoid rerun
of bist operation preboot sets bist_skip_enable bit in COLD
RESET register. Preboot checks this bit and ignores running
bist if it is set.
