[SW-82717] rom: add rr config for unsecure systems

As in gaudi3, the complete LBW and HBW space will be blocked by
default by the HW, we would be unable to access any address
in the LBW/HBW space in recovery, even for unsecure systems(sec_en
efuse bit is 0).

During PO phase it is helpful to have a means to update firmware
using fw loader application's unsecured methodology. As this is
done when sec_en is 0, it does not pose security risk.
