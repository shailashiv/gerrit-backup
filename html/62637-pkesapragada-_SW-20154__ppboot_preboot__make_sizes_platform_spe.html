Commit Message

[SW-20154] ppboot/preboot: make sizes platform specific

PPBOOT and PREBOOT binary sizes can be platform specific.
For example, Goya had a requirement of having a small
PPBoot size, so as to reduce the copy latency in BTL
without jeopardising the pcie link bringup time. Hence
move these defines to platform specific headers.
