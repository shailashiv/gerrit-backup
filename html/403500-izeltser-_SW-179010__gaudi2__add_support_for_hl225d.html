Commit Message

[SW-179010] gaudi2: add support for hl225d

To support gaudi2 HL225D variant, and continue supporting HL225C
variant, the device revision ID is set according to the variant
programmed in efuse.
In addition, for security code, both those variants are considered
bis compliant.
