 [SW-11875] goya2: ppboot: Change preboot load address

Currently, preboot load address is set to ICCM to run preboot.
Since ICCM needs to be freed up for running zephyr OS, this patch
add changes to change load address of preboot from ICCM to scratchpad SRAM
at offset of 0x1000.
