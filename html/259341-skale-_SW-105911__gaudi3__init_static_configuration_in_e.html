[SW-105911] gaudi3: init static configuration in every boot

Some of the variables in hl_fw_boot_ptrs_ctx structure has fixed
values and were assigned based on arc1_persist_dccm_init_done flag.
Since this structure will be persistent or non-persistent based on
boot info skip flag, this patch performs assignment unconditionally.
