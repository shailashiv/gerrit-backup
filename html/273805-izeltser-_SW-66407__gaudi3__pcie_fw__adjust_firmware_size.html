[SW-66407] gaudi3: pcie_fw: adjust firmware size

Pcie Phy fw binary image size is adjusted according to the content
of the provided image.
The provided hex file is actually has 64Kb of data, but the end of
the file is filled with zeroes, and there is no need to waste flash
access time for that.
