[SW-20154] common/pcie: change sris/flr functions

PCIe configuration code like pcie_config, snps
workaround etc involves registers that
are specific to Goya2 like the SRIS mode bit,
FLR handling. Since the same SNPS workaroud
is needed for Gaudi2, most of the pcie related
code is left common. Only the SRIS query,
FLR handling is implemented as a platform specific
function
