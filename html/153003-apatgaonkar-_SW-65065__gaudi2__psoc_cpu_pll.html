Commit Message

[SW-65065] gaudi2: psoc cpu pll

In case of agent running on arm, accesses to cpu_lbw
are slow if psoc_cpu pll div1 is not configured.
Currently in secureboot flow FSM only configures
Div0 which causes communication between agent and
host to be very slow and mismatched. This patch
adds separate function to configure psoc cpu pll
only in case of secureboot flow.
