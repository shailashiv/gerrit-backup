Commit Message

[SW-125999] gaudi2: add support for merging old boot info

The boot info finalize do not merge the existing boot info
and this results in losing the older boot info data. This
patch adds support for merging the existing boot info and
also it copies the bootinfo data from preserved memory
during init and copies the data to preserved memory before
loading agent.
