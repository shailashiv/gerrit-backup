Commit Message

[SW-224519] common: fix aip util formula

The problem was that when querying the utilization.aip (via hl-smi -Q),
the utilization of several cards returned garbage values (representing
negative numbers). However, when running hl-smi (w/o parameters), all
the utilization values were valid. It turned out that in the former
case,the power drawn from the secondary PSU wasn't updated
periodically, while in the latter case it was.
A fix for this was merged into v1.21.0 RC1 - updating the power drawn
from the secondary PSU, each time we call the utilization function.
This commit refactor the code, such that the update will be done as
part of calling the power consumption function. Each time we call it,
we update the power drawn from the main PSU and the secondary PSU (if
it exists - in Gaudi 2 PCIe card, for example, it doesn't).
