[SW-93113] hl: pll: avoid unintentional integer overflow during multiply

This patch fixes an issue pointed by synopsis static analysis tool by
type casting one of the multiply arguments to u64 to avoid any potential
integer overflow errors.

"47778 Unintentional integer overflow
The expression's value may not be what the programmer intended, because
the expression is evaluated using a narrow (i.e. few bits) integer type.

In hl_pll_get_freq: An integer overflow occurs, with the result
converted to a wider integer type (CWE-190)"
