Commit Message

[SW-29740] gaudi: security: introduce lbw rrs enum

Since we are now using the RRs numbers in more than 1 place (e.g.
preboot_secure_lbw() and preboot_security_dbi_lock(), we should be using
the same RR number w/o the need to update both places.
Introduce the gaudi_sec_lbw_rrs enum to reference the RRs by name.
This also lets other RRs benefit from the enum.
Additionally, the RRs numbers are effectively changed to be configuous.
