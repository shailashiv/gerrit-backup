Commit Message

[SW-64613] gaudi2: sec: remove unconditional rr config

This change avoids unconditional rr configuration in
ppboot. This was added initially to avoid reading fake
security boot info in ppboot but now fake security info
is read from cold reset flops. This change adds a security
check while configuring range registers in ppboot and
removes opening up of rr's in preboot when security is
not enabled
