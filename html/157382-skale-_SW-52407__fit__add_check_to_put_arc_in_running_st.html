Commit Message

[SW-52407] fit: add check to put arc in running state

Currently as part of greco and gaudi2 preboot_start_image
function, ARCs and ARM are put into running state. However
in some of scenarios, fit image received doesn't contain
arc images and still arcs are put to running state or jumped
to ICCM location assuming images from fit for ARCs are already
copied. This patch add change to conditionally set ARCs in
running state if ARC images are received as part of FIT.
