Commit Message

[SW-224112] g3:reset: use host reset path

The arcmgmt reset function hl_dev_reset() uses the reset
API callback function:

.hl_dev_trigger_reset()

to reset the device.  This reset path is missing several
steps that are necessary for consistent FW reset behavior.

Update hl_dev_reset() to use the FW defined reset steps.
