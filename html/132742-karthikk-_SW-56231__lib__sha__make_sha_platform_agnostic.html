Commit Message

[SW-56231] lib: sha: make sha platform agnostic

Currently /lib/ directory in preboot supports only sha256 as hash
algorithm. Gaudi2 needs to support sha384 has algorithm as a part
of security. This patch makes the common code in /lib/ platform
agnostic such that gaudi2 supports sha384 while the other platforms
(gaudi, greco) still use sha256. This way sha specific code in the
common /lib/ directory can be extended to support any sha variant for
future platforms.
