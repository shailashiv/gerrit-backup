Commit Message

[SW-120977] erom: remove bis chk call

Recently a patch was added in which reads bis
indication from efuse.
But efuse init was not called as part of device init
in eROM, which resulted in eROM hang.

Also, eROM is actually being erased from BIS compliant device,
so calling it from eROM is a dead code.
Hence, this API call is removed, and also efuse, and security
module are removed from linkage, as these modules are not used
anyway in eROM.
