[SW-20810] sha256: use builtin bswap32

Use GCC builtin bswap32 routine instead of swapping macro. This is done
in order to reduce the image footprint when introducing strict-align GCC
flag which changes the ASM code generated by the swapping macro.

The builtin bswap32 forces the GCC to use REV instruction in ARM instead
of using the byte shifting as written in macro.

Before the introduction of strict-align flag, the implication on
footprint is minimal at best since the GCC optimization replaces the
byte shifting code with REV instruction. This optimization stops when
using the strict-align flag.

Since the data "fed" to bswap32 is 32bit aligned, it is safe to use.
