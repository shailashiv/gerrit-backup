Commit Message

[SW-227154] g3: increase graceful reset timeout

The graceful reset notifies the LKD that a reset is
eminent, waits for a bit to allow the LKD time to get
ready, and then resets the FW.

It has been determined that if the NIC HW is configured,
the current 2 second timeout is not sufficient.

The recommended timeout is 5 seconds. Since this was
measured with a current configuration, increase the timeout
to 7 seconds to support this and future configs.
