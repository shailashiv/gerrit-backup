Commit Message

[SW-36011] boot_info: add flush api in boot info

Add capability to flush boot info into SP SRAM
during preboot runtime (not only when loading
u-boot), this is required in case the device gets
reset before loading u-boot, which can result in
loss of the SP SRAM info.
