Commit Message

[SW-27979] i2c indirect: add wdata context

Needed for implementation of opcodes which support WDATA.

So far, the only supported opcode is opcode 12 (fw loader) which is
simple and unique in the way it was implemented. The whole area in which
the data was written was "writable" (no "read only" secion) and the
offset in WDATA was used in a opcode specific way.

Newly implemented opcodes will have to be handled differently, first
it's implementation needs to consider "read only" areas, in which data
may not be written by WDATA (data ignored or raise an error in status).
Secondly WDATA's offset field must be considered.

In order to prepare for new opcode, this commit creates WDATA context
(similar to RDATA context).
