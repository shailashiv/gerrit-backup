Commit Message

[SW-0] ppboot: gaudi2: arc: update dccm base

Currently, dccm base is set 0x2706402C (ARC1 DCCM) which is used
for ppboot BSS, stack and data sections. As part of compilation,
data section start is aligned to 8 bytes starting from 0x27064030
instead of 0x2706402C as it. This causes data section to shift by
4 bytes. This patch updates DCCM base to 8 byte aligned address.
