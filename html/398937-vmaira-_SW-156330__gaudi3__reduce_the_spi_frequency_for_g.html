Commit Message

[SW-156330] gaudi3: reduce the spi frequency for gaudi3 tpm

SPI baudrate get function is modified to allow configuration
of different baudrates for different SPI controllers. This
will be used to reduce the SPI frequency for TPM access
on gaudi3 asic. On Gaudi3 asic connection to TPM passes
through CPLD. Therefore, TPM communication is found to be
functional only below freqencies less than 12.5MHz.
