Commit Message

[SW-0] image: fix preboot string print

Until 3 weeks ago, the ppboot printed the following string
"Preboot loadaddr:". Patch number a4a9506 refactored the code
to use the function 'name' parameter for the print, which caused
it to show as "PREBOOT loadaddr:". this confused some CI jobs like
the Coral CI.
This patch restores the print to it's previous form by adjusting
the preboot image name passed to ppboot_cp_image().
