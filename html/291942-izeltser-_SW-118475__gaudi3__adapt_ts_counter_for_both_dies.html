Commit Message

[SW-118475] gaudi3: adapt ts counter for both dies

Timestamp counter code has a nice generic implementation where only
the base address of the block is required.
So far only Die0 psoc_timestamp counter was used. For the bootloader
app that will be added in the following patch, Die1 timestamp counter
will also be used by the instance that will execute on Die1 Arc1 CPU.
To Support that, the base address of the TS counter is provided
according to the location of the app execution.
