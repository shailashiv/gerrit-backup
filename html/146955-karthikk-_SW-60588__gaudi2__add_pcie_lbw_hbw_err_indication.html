Commit Message

[SW-60588] gaudi2: add pcie lbw/hbw err indication

As a part of pcie RR razwi occurrence validation part, the scratchpad
is updated when the indication is set. But as the security
configuration locks the indication register, it cannot be cleared by
validation, from outside the firmware. Hence this patch clears the
indication inside firmware.

This patch will be reverted post Gaudi2-PO validation activity.
