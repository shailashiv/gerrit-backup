Commit Message

[SW-86869] gaudi3: validate and override revokation bits

Currently, as part of fuse override function only key 4 revokation
bit is cleared. This patch add changes to validate revoke bits
value read from fuse (valid fuse values: 0, 1, 3, 7, 15) and override
if not in expected fuse values.

 	/* KEY index 4 must not be revoked */
 	arcboot_rom_global.config_fuse &= ~EFUSE_SYSCFG_REVOKE_KEY_4;
+
+	/*
+	 * Validate key revokation bits. Expected values from fuse are
+	 * 0, 1, 3, 7, 15. If any other values are read from fuse override
+	 * them accordingly.
+	 */
+	key_revoke = arcboot_rom_global.config_fuse & EFUSE_SYSCFG_REVOKE_KEY_MASK;
+	if (key_revoke == 2)
+		arcboot_rom_global.config_fuse |=  EFUSE_SYSCFG_REVOKE_KEY_0_1;
+	else if ((key_revoke < 7) && (key_revoke > 3))
+		arcboot_rom_global.config_fuse |=  EFUSE_SYSCFG_REVOKE_KEY_0_1_2;
+	else if ((key_revoke < 15) && (key_revoke > 7))
+		arcboot_rom_global.config_fuse |=  EFUSE_SYSCFG_REVOKE_KEY_0_1_2_3;
 }
