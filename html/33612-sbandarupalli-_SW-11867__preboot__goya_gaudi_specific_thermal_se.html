[SW-11867] preboot: goya/gaudi specific thermal sensors programming

this patch adds the implementation required to get goya/gaudi on-chip
thermal sensors readings from pre-boot using i2c interfaces

As part of the SLIM flash layout changes it is decided to service
I2C slave requests from pre-boot and hence ASIC temperature sensors
readings should be supported from preboot.
