Commit Message

[SW-24746] preboot: set interrupt mask to default

Currently while running I2C slave in debug mode, it is observed
that the I2C slave interrupt mask is set to 0 in uboot shutdown sequence
which causes SCL low issue and reads from I2C slave debud mode doesn't
work at preboot level after LKD rmmod. As part of the hard reset,
PSOC block is not reset.

This patch add changes to set I2C slave interrupt mask to default value
as part of I2C slave init sequence. The setting of interrupt mask is
done platform specific as the mask values are different for different
platforms.
