Commit Message

[SW-12754] gaudi: security: condition pci sec dis

The preboot_security_pci_disable() function undos the settings done by
BTL to protect the device. It should be called in case the security is
disabled on the device.
While there was still work in progress on implementing full security
functionality, we kept the preboot_security_pci_disable() call
unconditional, so we would not accidentally brick a device.
Now, that the security settings are developed and overwrite the BTL
settings, we can safely move the preboot_security_pci_disable() disable
call to run in case the device security is disabled.
