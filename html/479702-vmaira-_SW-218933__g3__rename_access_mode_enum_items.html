[SW-218933] g3: rename access mode enum items

The mem_access_mode enum is currently defined in multiple apps —
preboot_rtos, preboot, and zephyr-plugins. To eliminate code duplication,
it will be moved to the specs folder.

This patch renames the existing enum items to avoid conflicts and ensure
CI passes when the enum is added to the specs folder in a subsequent patch
