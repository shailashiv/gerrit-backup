Commit Message

[SW-15774] build: refactor zephyr package and scripts

As part of separating the targets build procedures,
a fundamental change in the related files have to be do.

Previous commits lay down the basics make files to create the different
targets although those new make files are not automatically triggered.
Due to the nature of the buildroot concepts, the products will be
created in different location.
In order to keep backward compatibility, the zephyr target should be
kept.
The need to keep the zephyr build and deal with the inherit change of
directory, the zephyr makefile and the support scripts should be changed
as part of the same commit.

For backward compatibility the zephyr target is kept. Consolidate the
individual packages, as list of dependencies. Calling the zephyr target
will trigger the dependencies, making the targets
zephyr-{dirclean,rebuild,...} available.

The additional new targets:
pid, mgmt, event, preboot,
agent-fwl, agent-serdes, agent-pcie, agent-hbm

Example:
make pid-dirclean
make pid-rebuild

make zephyr-dirclean # trigger all depended -dirclean rule
make zephyr-rebuild  # trigger all dependencies
