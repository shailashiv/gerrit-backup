[SW-113135] ppboot: change sequence for sram extension

Currently changing SRAM extension address for ARC1 required for onix
platform is done after preboot delay routine. Starting gaudi3, ppboot
make use of SRAM for bootinfo operations in ppboot, so this patch change
extension setting sequence accordingly.
