Commit Message

[SW-77251] gaudi3: verify hash with public key properties

ROM stores hash of public key properties ie. hash computed
on 784 bytes of public key. The public key received as part of
fit is complete public key dtb of 3144 bytes. This patch add
changes to extract key properties from public key dtb and compute
hash on 784 bytes of key properties to compare with
stored ROM hash.
