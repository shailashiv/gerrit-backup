Commit Message

[SW-143472] gaudi2: erom: set recovery flag in init

Due to a bug in arcboot rom in force recovery the
recovery flag is not set. This patch adds support
to set the flag in init and resets the flag before
reset. The recovery flag is used by the firmware
loader agent to allow only the fits with load type
as flash in recovery flow i.e, only firmware update
is allowed in recovery flow. The recovery flag is
cleared post successful firmware update.
