[SW-51626] gaudi: execute pci pll wa only when required

As a result of the warm reboot investigation [SW-47213] a pci pll
workaround was implemented in order to fulfill 2 demands:
1. pci pll div0 <= div2 during pci phy fw upgrade
2. pci pll div0 = ~200Mhz for communication with the BMC.

This workaround is required only during warm reboot and cold start,
because only then the pci phy fw is being upgraded.
performing this workaround at all times might be problematic
since pci pll div2 is configured to a clock above it's specification,
which can cause issues if a hot reset is being excuted at the same
time.

This patch performs the pci pll workaround only when it's really
needed (cold start / warm reboot).
