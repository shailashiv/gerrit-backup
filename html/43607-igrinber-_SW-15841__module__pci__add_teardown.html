Commit Message

[SW-15841] module: pci: add teardown

When we move on to boot or execute another S/W agent, the FLR handling
must be handed over to H/W, so in case of an FLR event, it will not be
missed and link will not break.
Add PCI module teardown function which calls a device specific API and
implement it for Gaudi.
