[SW-43475] greco: arc: move preboot load address to start of sram

This patch changes preboot start address to start of sram, instead of
16KB offset, which was previously left by mistake for ppboot.
Ppboot loads in fw sram, so sram can directly start from 0 offset.

Also it is seem that while starting fro 16K offset, max 48K is getting
copied into sram from spi flash using dma, since preboot size can be
greater then 48K, it causes mismatch in copied data.
When starting from 0th offset, more then 48K is also getting copied
fine.
