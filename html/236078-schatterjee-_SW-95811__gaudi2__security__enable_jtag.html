Commit Message

[SW-95811] gaudi2: security: enable jtag

If JTAG_DISABLE (BIT12, offset 58) in efuse is '1' then
ARCBOOT disables JTAG. But the requirement is to
ignore efuse indication of 'JTAG DISABLE' if CPLD RMA enabled.

Following are few scenarios to be handled (in both regular
and recovery flows)

1.rma disable - security enable - JTAG disable
2.rma disable - security disable - JTAG enable
3.rma enable - security disable/enable - JTAG enable

Change done in common security function to handle both normal
and erom recovery flows.

security_enable_jtag_if() is used from arcboot rom.
