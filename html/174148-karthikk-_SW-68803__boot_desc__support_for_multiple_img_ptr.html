[SW-68803] boot desc: support for multiple img ptr

For security concerns, erom image pointers are stored at sector 0
of SPI flash while FW image pointers (ppboot, preboot etc) are to
be stored at sector 6 of SPI flash. But the code to initialize
and read these descriptors is common. Hence the common code is
updated for this requirement.

Design Decisions:
1) Existing fw does dma of image pointers from SPI FLASH -> SP SRAM
and referenced in SP SRAM. This is updated to dma from SPI FLASH ->
ARC1 ICCM . ICCM is an intermediate memory and the data is then
stored onto DCCM/SP SRAM depending upon the EROM/SPI image pointer.

After the DMA to ARC1 ICCM:
->  SPI boot pointers are processed and stored onto SP SRAM. This is
for re-using the same in further boot stages.

-> EROM boot pointers are processed and stored onto ARC1 DCCM. This
would isolate the access of EROM boot pointers to arcboot rom alone
as boot rom is the only component that uses the same.

2) Use cold reset flops to read fw_upd status and switch image ptr
idx based on its value. This eliminates the need for a separate
image pointer for switch image. This logic is a carry over from
ppboot.
