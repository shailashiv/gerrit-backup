Commit Message

[SW-98822] gaudi2: common: improve rst src seq

A SoC bug was discovered, The bug will not be fixed in H9 (and not in H6).

Sharpen the reset pulse signal, making sure the signal gets its right
shape. Marginal detecting error.

Regardless the fact that GPIOs are not getting reset during any reset
operation, excluding the cold reset; The IOMUX gets reset and if the
pin was configured, prior to reset, to a mode function different than
function 0, its mode returns to default during reset.
Done by making sure the pulse set low for ~1us, raised for ~5us, and
set low again after that.

NOTE: udelay can be used only after it was initialized. Initialized by
      udelay_init.
