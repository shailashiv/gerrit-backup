[FSW-7256] fs1: define initiator context

Initiator master interface RR page base address
is required to access all RR config registers,
and axuser base is required to access lb_sai
register. These two register areas required
while configuring RR set for any address space
which requires read/write access.
This patch adds support to declare and define
a context with required base addresses.
