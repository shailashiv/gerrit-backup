Commit Message

[FSW-418] fs1: bootrom: add tpm bootrom globals

This patch adds variables to bootrom globals and
support functions.

tpm_exec_stage identifies the TPM execution
stage and represents the current state of the
TPM finite state machine.

tpm_extend_done indicates that the TPM extend
operation was completed in previous resets and
does not need to be repeated.

tpm_next_pcr_index identifies the next PCR to
extend in the TPM.This will be used to keep
track of which PCR extends are already complete

tpm_spi provides info on TPM SPI parameters
