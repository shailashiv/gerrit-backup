Commit Message

[SW-99614] gaudi2: security: remove long rr code

Neither Ppboot, nor Preboot is using long RRs, so the long RR code patch
is actually a dead code which cannot be removed by garbage collection as
it is a part of a function that is in use and thus is just a dead code.
Remove long RR support and thus remove the dead code path.
