Commit Message

[SW-145263] h6: sec: dont use cold reset flop bits

To align fake security close to real security, it is decided to use
sec_en only from CPUCP packet.

After fake security is enabled, required fuse contents are programmed
using internal or release itbs. All FW components use efuse bits that
are read from SPI flash when fake security is enabled

fake_sig_validation_en and fake_bis_compliant are removed from cold reset
flop register. The efuse bit values are read from SPI flash
