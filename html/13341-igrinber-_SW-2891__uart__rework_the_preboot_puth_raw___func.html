[SW-2891] uart: rework the preboot_puth_raw() func

The printing of integers does not work while running in scratch pad
SRAM. This is due to the fact that it has only aligned to 32 bit
accesses.
To W/A the problem, rewrite the preboot_puth_raw() function to not use
the preboot_uint2hexstring() function, but instead use the new
preboot_putc_raw() function.
This also fixes the padding functionality of the preboot_puth_raw()
function.
