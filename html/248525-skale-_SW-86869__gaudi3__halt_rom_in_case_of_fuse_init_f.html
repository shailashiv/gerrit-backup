Commit Message

[SW-86869] gaudi3: halt rom in case of fuse init failure

In previous platforms, whenever fuse init failed the default value of 0
was assigned to syscfg fuse value which essentially means disabling all
security. This also mean that boot flow would have continued with images
signed with revoked keys on secured system. Since there is no correct
default value of syscfg fuse, this patch halt rom execution in case of
fuse init failure. This was recommended as part of secured code review
and also aligns the implementation with HW FSM.
