[SW-79695] gaudi3: force pre production fuse bits

Efuse bits that are classified as pre-production bits in the security
specification needs to be forced to a fixed value in rom in
production. Hence all the pre-production fuse bits are tied to the
EOM bit.

This is to make sure that no pre-production features are enabled/used
in post-production systems.

Preproduction bits and settings:
1) Key 0(pre-production key) is always revoked.
2) Key 4(last valid key index) is always valid.
3) Signature validation is enabled.
4) JTAG Interface is disabled.
5) TWI Interface is disabled.
6) Fuse location is efuse.
7) Security is enabled.
