Commit Message

[SW-164197] g3: set flash protected size to 256kb

In some flash devices the minimal protection granularity is 256kb.
For that reason the protected area is set to 256kb.
Until now the baremetal project was setting the protection for the whole
flash, that is not the desired configuration.
