Commit Message

[SW-183143] gaudi2: check sys_halt_r instead halt_run_ack

ARC never updates the status register for "0" value on arc_run_ack
and arc_halt_ack signals till next reset.

So, after halt or run requested we should check sys_halt_r instead of
halt_ack or run_ack bit.
