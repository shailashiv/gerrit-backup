Commit Message

[SW-161727] gaudi3: enable mbist code in ppboot

This patch enables sram mbist code in ppboot,
however skips mbist execution for die-0 SRAM to
avoid memcpy engine timeout error.

In PPboot, after sram mbist for die-0 sram is performed,
memcpy engine is used to scrub entire (48 MB) die-0 sram.
This leads to memcpy engine timeout and system hangs.
However, memcpy engine is able to scrub same sram memory
when mbist execution is skipped. Discussion with
architecture team ongoing.

TODO: Enable MBIST execution in PPboot.
