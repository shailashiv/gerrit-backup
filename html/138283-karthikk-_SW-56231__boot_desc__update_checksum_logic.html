[SW-56231] boot_desc: update checksum logic

Based on the firmware descriptor version we choose the checksum
field. For version <3 sha256 field is considered as valid checksum
algorithm, and for version >=3 sha384 field is considered as valid
checksum algorithm.

Please check https://gerrit.habana-labs.com/#/c/138267/ for detailed
background.
