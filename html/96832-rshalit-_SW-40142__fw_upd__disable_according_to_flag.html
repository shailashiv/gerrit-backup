Commit Message

[SW-40142] fw_upd: disable according to flag

Until now the fit closure command was used just to set
pcie instance state disable flag. This patch is doing
the actual disabling of interface by checking this flag
in module_fwupd_check routine and doing nothing if
this flag is set. This mechanism is a security
requirement.
