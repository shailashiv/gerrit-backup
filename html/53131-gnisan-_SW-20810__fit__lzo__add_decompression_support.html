[SW-20810] fit: lzo: add decompression support

Add LZO decompression support for FIT images.

Agents wrapped with FIT are loaded to the device via a slow
interface (I2C).
Without compression, loading a simple agent take 140s while
the same compressed agent transferred in 25s.

LZO is not enabled for Goya2
