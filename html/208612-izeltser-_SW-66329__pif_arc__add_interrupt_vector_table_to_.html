Commit Message

[SW-66329] pif_arc: add interrupt vector table to iccm

ARC CPU is using predefined address offsets from the IVT base address
(reset vector in our case) for fetching vectors of the exceptions
handling routines.
The code startup location upon CPU reset is also taken from
"reset exception" vector.

In order to support proper startup sequence from reset, and basic
safe exception handling, the interrupt vector table is added to
the beginning of the ICCM memory.
Default exception handling routine is added, this routine is just
reporting the exception to the error register, and halting the CPU.
