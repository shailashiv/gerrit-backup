Commit Message

[FSW-7134] boot_desc: use dev spec descriptor parsing

For FS1 the descriptor structure will change significantly, so the
common parsing code of the descriptor used for G2/G3 can't be used
for FS1. As a preparation for the new descriptor structure, the
code parsing the descriptor is moved to device specific code, and in the
following patch the implementation for FS1 will be added.
