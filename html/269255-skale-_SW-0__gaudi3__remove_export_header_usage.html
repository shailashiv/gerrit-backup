[SW-0] gaudi3: remove export header usage

Currently, ROM includes arcboot export header for
enum and structure reference which was done to aviod duplication
of enum and structure definition in export header and rom internal
header file. However any change in export header file impacts
alignment of functions in ROM code which will cause issues for using
them in other FW component. This patch removes ROM code dependency
on export header file by adding required enum and structure in internal
header files.
