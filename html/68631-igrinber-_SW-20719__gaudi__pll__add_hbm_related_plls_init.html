Commit Message

[SW-20719] gaudi: pll: add hbm related plls init

Add NIC and HBM PLLs initialization, so we can run the HBM init code
which requires those PLLs to be initialized.
The NIC PLLs are set to their regular frequency - 833 MHz.
The HBM PLLs are set to 800MHz - the safe frequency for all device
types.
