Commit Message

[SW-140559] gaudi2: boot_info: copy from perst mem

This patch adds support to copy boot_info from
persistent boot_info memory to current boot_info memory
in ppboot.

Earlier this step was done in early preboot main().
But as boot_info is required even before preboot main
by driver(s), so this is added in ppboot.
