Commit Message

[SW-0] cpu_if: make status/err regs pseudo ro

Since the status and error registers are not protected from host attacks
and LKD relies on the them, we need to make them read-only.
Unfortunately, we do not have a h/w mechanism available to protect these
registers.
Instead, implement a pseudo read-only mechanism which will write these
registers each main loop iteration.
