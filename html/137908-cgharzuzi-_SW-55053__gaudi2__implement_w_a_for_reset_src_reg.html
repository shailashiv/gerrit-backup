Commit Message

[SW-55053] gaudi2: implement w/a for reset src reg

Due to a HW bug in Gaudi2 mmPSOC_GLOBAL_CONF_RST_SRC
register (cannot be cleared), detecting the reset
source is problematic when more than 1 bit in register
is set.

As a W/A, all resets handled by FW will be mirrored
in a shadow register that is reserved after reset,

The rest of the reset events that are not handled
by FW will be handled by CPLD and visible to FW
using a GPIO drived by CPLD.

+	uint32_t val;
