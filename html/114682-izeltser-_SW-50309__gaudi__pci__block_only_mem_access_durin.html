Commit Message

[SW-50309] gaudi: pci: block only mem access during iatu init

During iATU initialization we are disabling pci access to eliminate
any interfering in the process.
Blocking configuration space access is against the spec and in fact
causing hosts to crash in some scenrios like VM loading.
Therefore, from now on only memory access is disabled during iATU
initialization.
