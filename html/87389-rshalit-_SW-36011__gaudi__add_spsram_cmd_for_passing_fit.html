[SW-36011] gaudi: add spsram cmd for passing fit

Add SPSRAM command so that a fit can be passed
from fw-loader using Scratch pad SRAM.
This is required as part of passing nic enable info
in a fit using a secured transport layer (ELBI) from
host to FW preboot.
