Commit Message

[SW-0] rma: rma info flash boundary update

Currently the boundary condition to check for
flash read request is with reference to the
block size of sector 0. But rma info can also
be read from sector 1.

As the rma info block sizes of both sector 0
and sector 1 is same, the update does not have
a functionality impact.
