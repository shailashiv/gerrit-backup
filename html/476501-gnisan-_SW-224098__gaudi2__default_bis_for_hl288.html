Commit Message

[SW-224098] gaudi2: default bis for hl288

Since supermicro servers do not refresh PCI rev on host reboot, there is
a problem with using fake security/bis as rev stays 1 instead of 4.

In order to solve this, we set BIS (and rev 4) by default for HL-288
card (as it is a China only card).
This does not apply to fake bis/security so we may still have the
flexibly to test different scenarios.
