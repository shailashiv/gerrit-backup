[FSW-8694] fs1: handle slave spi fuse

Added slave die support to wait for spi fuse
values from master die, slave will wait for
trigger over scratch_pad_2 register from master.
As slave die doesnt have access to SPI flash
memory, master is responsible to read and
distribute spi fuse values to all slave die's.

+{
+	uint64_t start;
+	uint32_t val;
+
+	start = boot_rom_get_ts_us();
+	while (1) {
+		val = regmap_readl(IO0_H0_PSOC_GLOBAL_CONF(mmGLOBAL_CONF_SCRATCHPAD_2));
+		if (val == FFUSE_WRITE_IND_MAGIC)
+			break;
+
+		if (boot_rom_timeout_expired(start, SPI_FUSE_EMULATION_DATA_UDELAY)) {

+		}
+	}
