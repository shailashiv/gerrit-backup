[SW-95911] gaudi2: bist: remove engine sram bists

sram bist to be run after PLLs are configured to functional clock.
PLL configurations are to be done in preboot. So bist for engine sram
bist will be moved to preboot after pll configurations are done.
This patch removes those sram bist from ppboot. Only sram bist for 48MB
SRAM is kept. Preboot runs from this 48MB SRAM, so bist on this memory
should be run before. SRAM PLLs to be configured in a separate patch.
