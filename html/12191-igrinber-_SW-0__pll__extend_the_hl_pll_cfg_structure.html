Commit Message

[SW-0] pll: extend the hl_pll_cfg structure

Add div_sel[] array for storing the clock selectors configuration.
This separates the clock selector values from the divider factor
values.
This is needed as a preparation for extending the clock selector
configuration values with a kind of "do not touch" value (which is
different from regular bypass).
The "do not touch" value is needed for proper implementation of the
IF/MESH W/A in Gaudi and is also improves the configuration
flexibility for future cases.
