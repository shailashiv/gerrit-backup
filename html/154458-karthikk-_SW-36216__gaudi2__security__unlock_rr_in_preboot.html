Commit Message

[SW-36216] gaudi2: security: unlock rr in preboot

To reduce processing in ppboot pre-linkup, pcie rrs are blocked
unconditionally in ppboot, and based on the security enable
criteria, it opens up these rrs in case secuirty is disabled and
continues other rr configurations in case security is enabled.

The strategy is a carry over from gaudi1.
