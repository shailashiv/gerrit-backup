Commit Message

[SW-27979] i2c indirect: add rdata and status op

This review adds a basic RDATA support along with an opcode which uses
it.

RDATA frame is being read by the master after a WDATA with read commnad
was issued. The master is expected to wait for TRANSMIT state in the
request status before issuing the RDATA command.

The added status command is important as it the only way for the master
to know which opcodes are supported. Hence status op must always be
supported.

+/*
+ * Handle request port read request. Return the RDATA header, followed by the
+ * payload.
+ */
+u8 i2csi_req_handle_rdata(u8 cmd, u32 read_seq)
+{
+	register int idx = cmd + read_seq - HL_INDIRECT_REQ_RDATA_DATA;
+
+	/* Header */
+	if (idx < HL_I2CI_REQ_RDATA_LEN)
+		return i2csi_req.rd.hdr.data[idx];
+
+	/* Payload */
+	idx -= HL_I2CI_REQ_RDATA_LEN;
+	if (idx < i2csi_req.rd.length)
+		return i2csi_req.rd.data[idx];
+
+	return 0;
