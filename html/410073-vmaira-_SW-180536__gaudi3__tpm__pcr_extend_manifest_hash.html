[SW-180536] gaudi3: tpm: pcr extend manifest hash

For Gaudi3, instead of separately extending PCRs for
individual ppboot and preboot images, the process is
consolidated by extending the PCR of the manifest.
Given that, hashes of all images are embedded in the
manifest, this approach would effectively extend the
PCR for all images.

Manifest hash is computed at ppboot stage via SHA384
operation on manifest image copied to ARC1 ICCM by
boot rom. Contents of ICCM are overwritten when preboot
execution starts. Therefore, manifest hash computation
is done only once after rom freshly transfers manifest
from flash to ICCM. This hash is then stored in boot
info. For resets that don't involve transfer of manifest
image from flash to ICCM, the manifest hash is instead
retrieved from boot info. Manifest hash is then used
to extend the TPM PCR
