Commit Message

[FSW-401] fs1: efuse: early efuse trigger

This patch is to avoid delay with efuse shadowing
to efuse data register. For this, boot rom will
set efuse fsm bit in early boot rom init, and
continue to initialize psoc resources. Once boot
rom init completed, check fsm completed shadowing
efuse data.
