Commit Message

[SW-15543] greco: remove gpio assert check

In case of greco, when SW_ALL reset is done PSOC
block does not get reset. In few platforms this
asserts/deasserts host gpio used for i2c slave
debug mode. Due to this next time preboot boots
it goes in idle state without even completing
preboot command loop. This is "revert me" patch
added until this issue is resolved.
