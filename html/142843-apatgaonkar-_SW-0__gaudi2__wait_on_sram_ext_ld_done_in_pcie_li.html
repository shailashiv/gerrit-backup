[SW-0] gaudi2: wait on sram ext ld done in pcie link up flow

Currently, as part of pcie link up flow code waits for SRAM_INIT_DONE
and timeouts when its not set. INIT_DONE means that the PCS has finished
initializing its internal SRAM, and that always happens after
deasserting the PHY reset. Also the HW state machine itself waits for
those bits to be set. Instead of waiting on SRAM_INIT_DONE, this patch
add changes to wait on EXT_LD_DONE to be set which indicates that our
logic has finished copying the PHY FW from PIF SRAM to the Synopsys
PCS IP SRAM.
