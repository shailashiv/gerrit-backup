Commit Message

[SW-69540] gaudi2: pci: notify if phy fw ld failed

If pci phy fw load done indication is low for an excessive amount
of time (10mSec), user message is printed.
Before, there was no indication for failure, aside from absence
of pci link, which made the failure investigation quite difficult.
This message might help in future investigations.
