[SW-0] gaudi2: arc: set internal dccm address

Currently, stack pointer of ARC0 which runs pcie initialization
code is set DCCM using HBW address. Since ARC access to DCCM via
HBW address is slower compared to direct address access, this patch
uses direct address to set stack pointer of ARC0.
