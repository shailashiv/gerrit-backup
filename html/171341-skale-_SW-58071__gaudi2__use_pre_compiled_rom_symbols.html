Commit Message

[SW-58071] gaudi2: use pre compiled rom symbols

Since the addition of gaudi3 changes in ROM code base, the code
compiled for gaudi2 ROM doesn't match exactly with ROM code on
device due to which ppboot fails to find exact symbols of ROM
when ran on device. In order to fix this issue, this patch add
change to use pre-compiled ROM symbols for ppboot compilation which
exactly matches with ROM symbols on device.
