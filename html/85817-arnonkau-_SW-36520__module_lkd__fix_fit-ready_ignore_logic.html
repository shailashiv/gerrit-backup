Commit Message

[SW-36520] module_lkd: fix fit-ready ignore logic

The status flag "is_fit_ready_ignored" needs to be cleared
for any incoming command rather then "FIT READY" command, that
includes (especially) the KMD_MSG_NA command. The flag was not handled
while receiving KMD_MSG_NA (val = 0), as it no longer part of the legacy
relevant code, it became a meta cmd, and should be taken care of at the
meta command level.
