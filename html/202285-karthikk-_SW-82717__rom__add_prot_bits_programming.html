[SW-82717] rom: add prot bits programming

In recovery flow, we need to open the PSOC_GLOBAL_CONF registers
for fw loader application to access config spare registers. All
other registers marked in soconline as privileged needs to be
blocked using protection bits.

Hence protection bits programming is added in rom.

+void security_prot_bits_config(void)
+{
+	int i, reg_addr;
+	for (i = 0; i < MAX_NUM_SPECIAL_PRIV_REGS; i++)
+	{
+		reg_addr = mmD0_PSOC_GLOBAL_CONF_SPECIAL_GLBL_PRIV_0 + i * sizeof(uint32_t);

+	}
