[SW-0] pll: split the clock select programming

The clock select programming is not done correctly as it moves both
selectors at the same time.
Those selectors are independent entities and are not synchronized in
any way.
Moving them both at the same time might result in a fast clock
propagating to a slow fabric which cannot receive that fast clock.
The solution is to change the selectors one at a time in the correct
order.
First we change to divided reference clock and only then we move to
divided PLL.
