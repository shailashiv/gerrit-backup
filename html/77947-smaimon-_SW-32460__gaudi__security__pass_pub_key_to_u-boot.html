[SW-32460] gaudi: security: pass pub key to u-boot

Passing the u-boot public hash key value to u-boot.
In fake security mode, u-boot using command will program
this key to the fake OTP.
Since this is the u-boot public key, this will reduce the need to create
special OTP for fake security mode.
