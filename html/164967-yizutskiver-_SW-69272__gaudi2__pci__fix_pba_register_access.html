Commit Message

[SW-69272] gaudi2: pci: fix pba register access

The HW reset value for MSIx PBA offset register is incorrect, and should
be overwritten before the PCIe link is enabled. Originally the overwrite
was done at a point where perst_n can still be asserted, and DBI space
is not available for writing. Moved the register overwrite to a stage
where perst_n is de-asserted.
