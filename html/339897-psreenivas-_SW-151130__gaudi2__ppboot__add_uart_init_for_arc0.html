[SW-151130] gaudi2: ppboot: add uart init for arc0

There are time constrains for the PCIe link establishment
which is performed by ARC0 firmware. Hence operation such
as uart prints must be avoided. In order to preserve the
debug information, the uart prints are written into a
memory buffer, and flushed to the uart after link is
established.
