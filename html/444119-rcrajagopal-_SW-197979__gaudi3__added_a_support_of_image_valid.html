Commit Message

[SW-197979] gaudi3: added a support of image validation at erom

This patch add a support of image validation at erom, before loading
the new firmware.

libfdt library expects public key dtb address must be aligned to
8byte. Otherwise, fdt_check_header(pub_key_fit) will fail and not
load any new firmware. So, aligned that fit_sec variable to 8byte.

Added preboot_img_validation_is_enabled() for gaudi3 erom.
