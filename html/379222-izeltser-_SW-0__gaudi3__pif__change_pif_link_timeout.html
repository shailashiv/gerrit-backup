[SW-0] gaudi3: pif: change pif link timeout

Pif Arc is monitoring the time it takes for the pci link to go up.
Before the timeout value was tightly coupled to the reset type
and the PCIe standart. but in real world the Host can decide to
bringup the pcie link at any later time, so this tight monitoring
is pointless.
this patch simplifies the timeout monitor and sets it to constant
500msec.
