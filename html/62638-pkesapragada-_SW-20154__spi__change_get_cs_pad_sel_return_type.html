Commit Message

[SW-20154] spi: change get_cs_pad_sel return type

u32 is defined in preboot.h and spi.h is included
as a header file in <HL_DEV>/common.h. In the next
patches, when base addresses of CFG/SPI/FIT etc are
moved into platform specific common.h, this would
create compile errors. Hence change return type
of get_cs_pad_sel to "unsigned int", so as to
prevent including preboot.h file
