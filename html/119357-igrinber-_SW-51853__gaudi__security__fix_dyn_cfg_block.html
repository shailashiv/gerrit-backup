Commit Message

[SW-51853] gaudi: security: fix dyn cfg block

The PCIe RRs are 32 bits and extend the values with leading 0x7F.
HOST_PHYS_BASE is defined by 0x8000000000 which turns to be 0x7F00000000
in the register. This is not correct max value for the protection we
want.
Fix this by subtracting 1 from the HOST_PHYS_BASE to get a valid max
value.
