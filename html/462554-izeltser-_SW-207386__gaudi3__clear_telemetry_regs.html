Commit Message

[SW-207386] gaudi3: clear telemetry regs

Telemetry uses PCIe Core Spare registers for config and status.
for safe operation those registers should be cleared before host
access is enabled. For reset types that reset the PCIe blocks,
such as cold/warm reboot, this is not necessary.
In addition, to be on the safe side, it's also best to verify prstn
is not set, otherwise the PCIe blocks are held in reset.

+static void clear_telemetry_regs(void)
+{
+	unsigned int rst_src, prstn;
+
+	/*
+	 * Telemetry uses PCIe Core Spare registers for config and status. for safe operation those
+	 * registers should be cleared before host access is enabled. For reset types that reset
+	 * the PCIe blocks, such as cold/warm reboot, this is not necessary.
+	 */
+	rst_src = hl_rst_src_get();
+	if ((rst_src != HL_COLD_RST) && (rst_src != HL_PRSTN_RST)) {
+		prstn = regmap_readl(D0_PSOC_GLOBAL_CONF_REG(mmGLOBAL_CONF_PRSTN));
+		if (prstn) {
+			regmap_writel(0, mmINBAND_TELEMETRY_CONFIG);
+			regmap_writel(0, mmINBAND_TELEMETRY_STATUS);
+		}
+	}
