[SW-66640] gaudi2: add polling for clearing flr int

Currently as part of FLR interrupt processing flow, FLR interrupt
is cleared at source in FLR_INT register followed by cleared in
SPI_INTR_CLR register. However SPI_INTR for FLR doesn't get cleared
as there is some latency in clearing FLR interrupt at source. To
overcome this, this patch add polling for FLR_INT to be cleared with
timeout of 10us after which interrupt is cleared in SPI_INTR_CLR
register. This makes sure the FLR interrupt is cleared at source before
clearing it in SPT_INTR register.
