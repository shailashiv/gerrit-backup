Commit Message

[SW-79498] gaudi3: rma: override sig val efuse bit

In post-production phase, in case a rma is detected in a device,
the security requirement is that a rollback to a previously stable
version should be allowed.

This effectively means we need to bypass the svn checks in case of
a rma detection.

As per the security requirement, the fw allows to run an unauthenticated
image if rma is set.
