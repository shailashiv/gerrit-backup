Commit Message

[SW-20810] arm64: use strict-align flag

Add strict-align flag to GCC compilation flags. This ensures the GCC is
aware that the CPU is unable to handle access to unaligned data. When
the parser requires to perform unaligned read/write, it will use 8bit
read/write in order to ensure aligned access.
