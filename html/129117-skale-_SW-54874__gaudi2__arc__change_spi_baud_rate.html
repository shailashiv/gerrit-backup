[SW-54874] gaudi2: arc: change spi baud rate

Currently for secureboot, preboot image is copied to SRAM using
SPI DMA. However with default baud rate of SPI DMA set to 0x2,
overruns are observed as the data read from SPI is faster compared
to data write to SRAM due to which copied SRAM preboot image does
not match with SPI preboot image. To overcome this issue, this
patch change the baud rate of SPI DMA to 0x4 before DMA to SRAM
and restore it to default value once DMA is completed.

HW Errata: GAUDI2_0307
