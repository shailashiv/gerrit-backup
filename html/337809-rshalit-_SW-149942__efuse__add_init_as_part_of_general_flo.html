[SW-149942] efuse: add init as part of general flow

efuse init was recently removed, as part of a patch
which removes tpm enable:
[SW-142278] h6: tpm: remove tpm_en efuse bit check

efuse init was done in code in the first attempt to read
efuse, hence - since no one reads anything from efuse
(as part of the above patch), there is no init and any other
later project (preboot, mgmt etc) fails in efuse read.

This patch fix this issue by forcing efuse init as part
of general initialization in main.
