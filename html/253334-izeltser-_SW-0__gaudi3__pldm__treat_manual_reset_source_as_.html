[SW-0] gaudi3: pldm: treat manual reset source as cold

In paladium emulator the full design reset signal sets the reset
cause to "manual reset" when in fact the entire design is being
reset same as in cold reset. In order to properly support PCI
init that depends on the reset source, the "manual reset" source
in paladium is treated as cold reset

+/*
+ * In paladium emulator the full design reset signal sets the reset
