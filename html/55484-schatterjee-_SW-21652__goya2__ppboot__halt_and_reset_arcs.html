[SW-21652] goya2: ppboot: halt and reset arcs

In legacy bootflow ARM boots first and then it boots
ARCs. ARCs need to be explicitly restarted for cases where
those are not done by hardware. For example when LKD module(on host)
is removed (rmmod), LKD resets ARM but ARCs continue to run.
So ARCs need to be restarted by ARM in the boot flow.
To cater this flow ARCs are first halted and then triggered for reset.
