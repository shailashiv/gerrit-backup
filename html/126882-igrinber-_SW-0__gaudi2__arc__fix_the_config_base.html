[SW-0] gaudi2: arc: fix the config base

Gaudi2 ARC maps 16 regions to access SoC.
The region 15 (16th) is the LBW (CFG) access, but is mapped to the
lower 128MB of the section, thus bit 27 should be clear.
The reason it works with bit 27 set is that h/w discards bit 27 when
ARC accesses CFG space, so effectively this bit is "don't care".
Yet, clear bit 27 so we have a clear and correct picture of the
address accessed.
