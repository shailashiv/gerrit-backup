Commit Message

[SW-66547] gaudi2: sec: psoc_boot_msg_done reg

LKD uses PSOC_BOOT_MNG_DONE after HARD_RESET to know
hard_reset is done.  But this register is blocked
by RR in ppboot/preboot. So even though hard_reset works
following error print seen on host,

Change-Id: I5b12165e629cc4b5397272aa7f1030a2c2a51eae

--------------x--------------

[Mon Dec 13 07:55:20 2021] habanalabs hl0: Firmware performs
				HARD reset, sleeping 500ms
[Mon Dec 13 07:55:20 2021] habanalabs hl0: Timeout while
				waiting for device to reset 0x0

------------x----------

So opened PCIE_WRAP region from RR protection and used
protection bit configuration to open only PSOC_BOOT_MNG_DONE
register.
