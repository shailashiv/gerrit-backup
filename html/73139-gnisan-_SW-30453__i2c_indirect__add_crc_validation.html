[SW-30453] i2c indirect: add crc validation

Add CRC integrity check to I2C indirect.

CRC is only active when IC bit is set in WDATA header.
In validates both header and payload alike.

For write request, CRC is following the payload of WDATA:
  [WDATA w=1 ic=1][Payload][CRC]

For read request, CRC follows the WDATA header:
  [WDATA w=0 ic=1][CRC]

When validation fails, integrity error (10) is set to status.

RDATA CRC is calculated in the same way (header + payload) while CRC
follows the payload:
  [RDATA ic=1][Payload][CRC]
