Commit Message

[SW-42811] gaudi: pcie: increase timeout to link

Increase timeout on waiting for link up, as we found
scenarios in which the timeout from device power up
till hw is ready in host side is longer than 5 seconds
and can reach to ~15seconds. A timeout of 60 seconds
was decided as a time interval which is good enough
for most scenarios, yet allowing to continue in preboot
flow, so that it is serving other interfaces too such
as BMC.
