[SW-21029] ppboot: gaudi: add support for bss section

This patch adds support for bss section to ppboot
so that SW can use uninitialized global vars. Futher,
these variables will be cleared in the crt before jumping
to ppboot_main. These were required to be added
in Goya2 and hence the same is being ported to
goya/gaudi as well. It’s needed to prevent compilation issues
