[SW-0] gaudi3: qualify spi gw access via fuse

Currently upon fuse emulation, master die provides required fuse
values to slave die by writing to slave scratchpad registers using
spi gateway. Recommendation from ARCH team is to qualify usage of spi
gateway with fuse. This patch adds new fuse bit BIT(23) (d2d spi gw en)
to determine access of spi gw as below.

Value 0: Skip usage of spi gw. From ROM POV, Master die skips providing
values to slave die via spi gw and slave die skips waiting for fuse
emulation values from master.
Value 1: Use spi gw. From ROM POV, Master uses spi gw to write values to
slave die and slave die waits for indication from master die to
read the fuse values.

This efuse bit can be used by other FW component to determine usage
of spi gw.
