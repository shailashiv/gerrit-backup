Commit Message

[SW-227794] g3: adjust hbm temp calc in ctemp

The current HBM temperature value which is included in the
composite temperature value has a offset of 13 degrees after
the temperature reaches 80 degrees Celcius.
This can cause an oscilation when the chip temperature is
wandering above and below 80 degrees.

Modify the HBM temperature to use the following formula.

HBM_TEMP = HBM_TEMP (SoC Throttling_temp/HBM Throttling_temp)
