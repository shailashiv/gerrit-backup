Commit Message

[SW-56687] gaudi2: arc: use arc viewpoint address to copy images

Currently, the logic used for converting 64 bit address received
as part of FIT loadaddr to ARC viewpoint address is incorrect which
causes hang while copying FIT images to loadaddr. This patch
fixes the logic and use correct ARC viewpoint address to copy
images.
