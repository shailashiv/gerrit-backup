Commit Message

[SW-30985] ppboot: add reset status decoding capability

In all platforms until Greco, PSOC_GLOBAL_CONF_RST_SRC
contained an index which will determine the cause of reset.
But for Gaudi2, more resets have been added, each with
a bit mask, with each reset denoting a specific case.
Hence add a capability to decode the reset causes per
platform basis. The platform specific resets
are mapped to a common structure which ppboot uses to
take appropriate actions
