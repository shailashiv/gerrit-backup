Commit Message

[SW-22029] initialize complete dccm memory

Currently, in order to avoid fake DCCM memory exceptions caused due
to uninitialized DCCM reads, DCCM memory used by arcboot ROM is been
initialized to zero. Based on recommendations from hardware team and
to avoid any uninitialized reads to DCCM, this patch adds changes to
initialize complete DCCM memory of 16KB. Since complete DCCM memory is
initialized, initialization of bss, heap and stack sections which
resides on DCCM are not required and are removed.

The total cycles taken to initialize complete DCCM memory are ~4100
cycles.
