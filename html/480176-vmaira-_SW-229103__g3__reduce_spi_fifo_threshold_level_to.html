Commit Message

[SW-229103] g3: reduce spi fifo threshold level to fix tpm failures

TPM transactions are failing intermittently due to SPI RX buffer overflow
at the Gaudi3 SPI controller. Reducing the TPM SPI frequency leads to TX
buffer overflows.

This patch reduces the 'fifo-depth' property in the device tree for the
TPM SPI controller on gaudi3. Since the FIFO threshold levels (RXFTLR and
TXFTLR) are derived from fifo-depth, lowering it indirectly reduces these
threshold levels as well.

Reducing the FIFO thresholds causes 'FIFO full' interrupts to trigger more
frequently. This ensures RX buffer reads happen faster and TX buffer
writes are delayed slightly, helping to avoid overflows.

This is a temporary workaround until the root cause of the buffer
overflows is identified.
