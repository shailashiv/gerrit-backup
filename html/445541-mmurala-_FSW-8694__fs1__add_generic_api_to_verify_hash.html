[FSW-8694] fs1: add generic api to verify hash

Generic API which accepts manifest index and
firmware image type as inputs, it extracts
img desc from manifest and provide required
inputs for key hash library api.
This API can be used to verify key hash of any
firmware image which has img desc inside
manifest.

+
+	if (secure_boot_verify_image_hash384(desc.chksum, image, act_img_size) != 0) {
