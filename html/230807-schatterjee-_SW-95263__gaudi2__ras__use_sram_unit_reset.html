Commit Message

[SW-95263] gaudi2: ras: use sram unit reset

In this patch SRAM UNIT reset is used in place of
explicit scrubbing after running sram self repair.

Scrubbing using MEM_CPY takes several seconds of time.
So faster alternative of UNIT reset is used. This is required
to avoid in ECC after BIST.
