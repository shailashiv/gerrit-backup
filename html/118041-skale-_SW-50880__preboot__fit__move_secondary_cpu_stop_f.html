Commit Message

[SW-50880] preboot: fit: move secondary cpu stop function

In secureboot flow, ARC0 is used to run PCIe initialization and
put to sleep once initialization is done. reset needs to be performed
on ARC0 before copying FIT images in ICCM and DCCM memories of ARC.
Currently stop of secondary CPU is performed as part of fit_run_image,
this patch add changes to move it fit_load_images function before
copy of FIT images.
