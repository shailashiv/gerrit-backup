Commit Message

[SW-48529] makefiles: use root dir definition

Define and use variable PREBOOT_ROOT_DIR, which reflects the root
directory from which the preboot is built.

This variable will be defined in the primary makefiles and used there
internally in order to facilitate future changes in the preboot
directory hierarchy.

Furthermore, it will be used in internal architecture-specific Makefiles
when referring to files inside the preboot build directory, allowing
them to be included by the primary makefiles.
