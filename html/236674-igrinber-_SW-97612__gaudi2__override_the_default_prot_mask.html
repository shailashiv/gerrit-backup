Commit Message

[SW-97612] gaudi2: override the default prot mask

The default protection mask specifies protection of the whole flash.
Gaudi2 needs to protect only the eROM binary area which is 128KB from
the start of the flash.
Override the PROT_MASK with Gaudi2 specific value.
