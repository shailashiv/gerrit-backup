Commit Message

[SW-10967] gaudi: linux: pca953x: enable driver

Enable PCA953x gpio expander driver in Gaudi's Linux.

This change is added as preparation for the HL200 QSFP-DD driver.
QSFP-DD modules are controlled by TCA6416 I/O expander, and we can use
the PCA953x driver to control this device.

GPIO sysfs support is also added to the configuration in order to allow
us to manually control these modules from userspace.
