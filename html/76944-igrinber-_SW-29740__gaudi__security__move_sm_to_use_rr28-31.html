[SW-29740] gaudi: security: move sm to use rr28-31

Since we are requested to use additional RRs for protecting more LBW
areas, move the SYNC_MNGR protection (which is PCIe only) to the last
PCIe RRs, so those ranges used till now (2-5) will be free for
additional LBW use, but still have a PCIe HBW dedicated registers
contiguous.
So the new PCIe RRs dedication:
LBW: 0-15, 28-31
HBW: 16-17
