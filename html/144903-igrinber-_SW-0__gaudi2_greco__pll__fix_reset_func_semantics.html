Commit Message

[SW-0] gaudi2/greco: pll: fix reset func semantics

The hl_pll_reset() function in Gaudi2 and Greco have a reversed
semantics:
true - means unreset
false - means reset.
Reverse the semantics to correspond to the function name and update the
callers to work with new semantics.
