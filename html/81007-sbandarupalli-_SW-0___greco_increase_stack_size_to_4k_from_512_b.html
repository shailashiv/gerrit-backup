Commit Message

[SW-0]: greco increase stack size to 4k from 512 bytes

with recent code changes in preboot, existing stack size of 512 bytes
is not sufficient. Stack overflow is seen and corrupts global variables
like hl_ts_data. Increasing stack size to 1k resolves the problem.
But keeping stack size to 4K to align with Gaudi and Greco secure boot
flow stack size
