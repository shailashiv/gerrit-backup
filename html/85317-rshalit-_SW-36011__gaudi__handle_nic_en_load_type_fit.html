[SW-36011] gaudi: handle nic en load type fit

Add handling of nic enable load type fit.
This fit is given through secured transport layer (ELBI),
and used for overriding value of nic enable ports.
The information is also preserved in case of reset from
LKD.
NIC enable is required as a secured mechanism for updating
and overriding internal NIC enable configuration with the
value given from KVM.
