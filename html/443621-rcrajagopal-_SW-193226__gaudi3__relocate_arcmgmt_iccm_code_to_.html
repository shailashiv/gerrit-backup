[SW-193226] gaudi3: relocate arcmgmt iccm code to die1 spsram

Since ARC1 MGMT consumed 99% of its own ICCM, to free up some
space, we are relocating certian code and data to DIE1 SPSRAM.

This patch define macro of RELOC_FULL_ADDR and RELOC_SIZE to
pass the preboot_is_valid_address_range() while copy the fit
to its destination address.
