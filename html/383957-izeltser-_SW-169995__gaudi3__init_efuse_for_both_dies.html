Commit Message

[SW-169995] gaudi3: init efuse for both dies

die0 & die1 efuse should be initialized so later FW components can read
the shadow registers and get valid efuse data.
bootrom is initializing the efuse whenever the efuse flag is not set in
the cold flop register. bootrom is running locally on each die, so the
best and fastest way to init the efuse of each die is simply clean the
efuse flag in the cold flop after every boot and let bootrom handle
the efuse init during the next boot.

In d2d device, if spi gw is enabled, ppboot clears efuse flag in die1
via the spi gw.
