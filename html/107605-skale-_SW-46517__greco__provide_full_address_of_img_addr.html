Commit Message

[SW-46517] greco: provide full address of img_addr

In secureboot flow, the SDRAM addresses are defined from the ARC
viewpoint due to which img_addr is set as ARC viewpoint which is
not understood by LKD. This patch add changes to pass full address
of SRAM as part of img_addr.
