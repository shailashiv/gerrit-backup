[SW-112281] board: support sve zephyr builds on bins

Add support for sve zephyr builds when creating the .bins files.

When building sve_zephyr package, the dtsi files are located on a clone
of the zephyr project inside the br-e output folder.

By default build based on the dtsi files inside embedded/zephyr.
