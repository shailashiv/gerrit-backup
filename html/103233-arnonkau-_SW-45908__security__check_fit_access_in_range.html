Commit Message

[SW-45908] security: check fit access in range

When checking the incoming FIT validity the size of the fit should fit
into the SRAM valid address space. The same goes with the FIT's footer.
Before accessing the fit or footer the calculated intended address is
checked against the valid SRAM boundaries.
