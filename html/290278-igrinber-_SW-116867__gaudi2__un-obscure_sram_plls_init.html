Commit Message

[SW-116867] gaudi2: un-obscure sram plls init

The PLLs init should not be obscured inside the SRAM self repair code.
Introduce the ppboot_plls_init() common function that can be used for
initializing PLLs in ppboot.
Move Gaudi2 SRAM PLLs initialization to run out of this function.
