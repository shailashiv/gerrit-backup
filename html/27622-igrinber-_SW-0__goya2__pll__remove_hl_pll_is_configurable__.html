Commit Message

[SW-0] goya2: pll: remove hl_pll_is_configurable()

Since the tests were run and proved there is no need to configure the
CPU PLL prior to waking the CPU (since the clock switch has been fixed
in H/W), there is no more need for the Goya2 private implementation of
hl_pll_is_configurable() function.
We still do not add the CPU PLL configuration to preboot, just remove
the protection.
