[SW-97583] gaudi2: remove usage of secured pcie ids

Its decided not to support two different dev ids (secured and
non-secured) for gaudi2. LKD will rely on boot_status sec_en bit to
identify if FW security is enabled.

This patch removes the logic to change the dev id if security is enabled
