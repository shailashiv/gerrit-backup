Commit Message

[SW-14252] preboot: goya2: handle multiple images start

As boot FIT contains multiple images which are copied into respective
load address, this patch adds preboot_fit_start_images function to
handle multiple boot FIT images. preboot_fit_start_images function of
goya2_arc_gnu HL_TARGET is also modified to boot ARC0 with zephyr pid
image and jump ARC1 to zephyr mgmt image along with booting UBOOT on
ARM.
