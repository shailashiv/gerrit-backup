Commit Message

[SW-12004] boot_desc: add struct for image data

Instead of passing offsets around, introduce internal struct boot_desc.
For now it contains only the offset of the image in the SPI flash.
It is needed as a preparation for switching to dynamic image size and
load address.
To reflect the change appropriately, rename the boot_desc_get_offset()
function to boot_desc_get_img_desc() and change is parameter list and
return value semantics.
