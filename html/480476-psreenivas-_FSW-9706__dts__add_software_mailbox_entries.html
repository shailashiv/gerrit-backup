Commit Message

[FSW-9706] dts: add software mailbox entries

This patch adds reset and mgmt tx and rx sw mailbox
and io mgmt and compute mgmt tx and rx sw mailbox
dtsi ipm entries to device tree.
IO0_HALF0_SW_MAILBOX1_1 - TX(MGMT) --> RX (RESET)
IO0_HALF0_SW_MAILBOX2_1 - TX(RESET) --> RX (MGMT)
COMPUTE0_SW_MAILBOX0_0 - TX(IO MGMT) --> RX (CMPT MGMT)
IO0_HALF0_SW_MAILBOX0_0 - TX(CMPT MGMT) --> RX (IO MGMT)
