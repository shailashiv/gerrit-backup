Commit Message

[SW-0] gaudi2: use strict-align flag for arm

Add strict-align flag to GCC compilation flags for preboot arm
compilation. This ensures the GCC is aware that the CPU is unable to
handle access to unaligned data.
This will create assembly according to arm64 alignment requirements.
Without this we were getting unaligned exception in gaudi2 preboot.
