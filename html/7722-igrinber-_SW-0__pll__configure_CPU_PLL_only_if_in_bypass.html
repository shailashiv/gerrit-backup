[SW-0] pll: configure CPU PLL only if in bypass

Currently we are not configuring the CPU PLL at all as a w/a to
stability issue.
While working on palladium, or just loading bootloader components
directly to memory (with JTAG), the CPU PLL does not get configured.
Add CPU PLL configuration depending if it is in bypass
or already configured.
