Commit Message

[SW-0] gaudi: pll: remove hl_pll_is_configurable()

Since the MF Gaudi chip the CPU PLL configuration has been verified to
work correctly during preboot (executing on ARM CPU).
Meaning, we can configure the CPU PLL which was skipped till now.
Therefore, there is no more need for the Gaudi private implementation of
hl_pll_is_configurable() function (which only skipped the CPU PLL).
We still do not add the CPU PLL configuration to preboot, just remove
the protection.
