Commit Message

[SW-98239] erom: recovery: remove redundant version

The version related defines and arrays are used for dynamic security
init.
Those are used incorrectly because they do not contain the correct
version information. Additionally, starting from Gaudi2 the version
information is no longer provided in SRAM and therefore the
preboot_security_dynamic_vers_init() function should not be called.
Remove these redundant pieces of code.
