Commit Message

[SW-0] fuse: use fuse emulation done flag

Currently, validation pass flag is used to determine whether to
read fake fuse offset from manifest image or use directly from
rom global structure. Using validation pass may cause problems
in scenario where ppboot image was failed to dma, verify and
validation pass flag was not set. This will cause ROM to read
spi offset from manifest again in next non-cold reset. In order
to avoid such dependencies, this patch adds separate flag for
fuse emulation init done indication.
