[SW-30207] i2c indirect: clr sts print as dbg

During fw update, preboot recevies multiple CLR STS
commands. Each time printing this msg to console
causes delay in processing next buffers resulting
in firmware update failure. Made this print dbg but
kept other command prints as their frequency is very
less.
