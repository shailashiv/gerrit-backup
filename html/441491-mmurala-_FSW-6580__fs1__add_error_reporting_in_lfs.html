Commit Message

[FSW-6580] fs1: add error reporting in lfs

With this patch, added support to report errors
in lfs library during run time. It will catch
internal errors during mount, format, read and
write.
With this error report enablement, identified
corrupted dir pair error from lfs_dir_fetchmatch.
This particular error will occuer only when mount
performed on empty disk. So it was recomended
that format and mount the disk when we know disk
is empty in some well known conditions like cold
reset.
There is no error identified when direct mount
without format on disk which has pre existing
data, especially scenarios like hard reset.
