Commit Message

[SW-40470] gaudi: sec: adding fit descriptor verification

Proprietry descriptor is added to all fit images in order
to increase security, by avoiding using public u-boot code for
signature verification.

The descriptor is attached to the fit image as a footer.
If security is enabled, for every received fit image preboot
verifies the Image signature prior to parsing it or using any of
the data.
The signature is calculated on the entire fit image as a whole +
the security descriptor with zeroized signature field.
