[SW-185990] boot_desc: use actual descriptor size

Remove the descriptor size assumption and use the actual descriptor
size that read from the hl_fw_boot_ptrs structure.

For legacy descriptor (relevant for G2 EROM decriptors only) known
constant size is assumed.

+

+		if (magic[i] != BOOT_PTRS_NEXT_MAGIC &&

+	}
