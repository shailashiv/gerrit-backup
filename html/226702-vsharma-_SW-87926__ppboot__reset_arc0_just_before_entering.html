Commit Message

[SW-87926] ppboot: reset arc0 just before entering preboot

This patch brings arc0 out of reset so that preboot while
reading bootinfo in binning driver can access arc0 iccm.
In gaudi2 preboot, binning driver comes as part of zephyr os
and at that time for custom binning, we need to check if boot info entry
is available and apply masks. To access it arc0 should be out of reset
before accessing it, currently it was done quite late in flow.
Without it during reset like fw reset, preboot tries to read
boot info and goes into indefinite wait.
