Commit Message

[SW-68803] boot_desc: fix erom specific hardcoding

1) Fixing the hardcoded macro for max images in erom to refer from
image index enumeration. This is to improve forward compatibility.

2) hl_boot_desc_erom.h is renamed to hl_boot_desc_rom.h as the header
is no longer dedicated to erom. This header will now contain defines
specific for boot rom. Any common definitions that should be shared
with ppboot/preboot will refer the specs header for boot descriptors.

3) Referring the image descriptor type from common hl_boot_desc.h
specs file.
