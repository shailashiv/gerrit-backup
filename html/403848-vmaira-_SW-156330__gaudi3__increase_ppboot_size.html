Commit Message

[SW-156330] gaudi3: increase ppboot size

As preparation for addition of TPM feature, gaudi3
ppboot size is increased from 16kB to 17Kb. TPM
feature addition increases the size of ppboot by
around 5.2kb. Current ppboot size is found to be
around 11.5kB.

Given that secondary image support is disabled,
PCIe link up time with this increase of ppboot
image size is calculated to be 77ms and well
within the 100ms limit.
