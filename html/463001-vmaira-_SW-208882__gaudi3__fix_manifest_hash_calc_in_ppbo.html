[SW-208882] gaudi3: fix manifest hash calc in ppboot

Manifest image is used to calculate the manifest hash. The manifest
image header which is part of the manifest image, includes a key
index that changes after the image is signed. Consequently, manifest
image used to generate the gaudi3-pcr.bin and the signed manifest
image sent to card during FW update are different. This causes the
TPM PCR mismatch if image signing is used.

This patch removes the manifest image header from the image used
for manifest hash calculation in ppboot.

This is a temporary fix as it removes useful data such as the key
index, key, and signature from the manifest. In future patches, the
manifest hash calculation will include the entire manifest. Since
the hash changes after key signing when the full manifest is
included, the PCR generation will be done post-signing. This
temporary fix is implemented to avoid the step of PCR generation
after signing with a new key.
