Commit Message

[SW-0] pll: remove needless return values

The hl_pll_cfg() function does not return any meaningful value,
but just 0, so remove the return value at all.
Once we remove the return value from the hl_pll_cfg() function, the same
can be done for hl_pll_set() function, as no value it can propagate to
the caller.
