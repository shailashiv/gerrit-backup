Commit Message

[SW-103303] ppboot: add time critical section handling

A portion of the PPboot application is running before the
PCIe link is up, since there are time constrains on the PCIe
link establishment, this portion of the code is time critical.
This section is explicitly marked in the code, and start/end
functions are added.
during the time critical section, non-important and time consuming
operation such as uart prints must be avoided. In order to preserve
the debug information, the uart prints are written into a memory
buffer, and flushed to the uart when time critical section is over.
