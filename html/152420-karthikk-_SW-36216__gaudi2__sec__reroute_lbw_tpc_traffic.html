[SW-36216] gaudi2: sec: reroute lbw tpc traffic

As dcore0 rtr0 lbw if is a shared interface for pcie, tpc0 and tpc1
it is required to re-route the traffic for tpc0 and tpc1 such that
only pcie traffic is allowed through dcore0 rtr0. This flexibility
is present for lbw ifs. The routing config block is connected only
in dcore0 rtr2 block in hardware, hence we program the dcore0 rtr0
range register whilst configuration of trafiic re-reroute is done
in dcore0 rtr2.

+static void preboot_lbw_rtr_preconfig(void)
+{
+	/*
+	 * As dcore0 rtr0 lbw if is a shared interface for pcie, tpc0 and tpc1
+	 * it is required to re-route the traffic for tpc0 and tpc1 such that
+	 * only pcie traffic is allowed through dcore0 rtr0. This flexibility
+	 * is present for lbw ifs. The routing config block is connected only
+	 * in dcore0 rtr2 block in hardware, hence we program the dcore0 rtr0
+	 * range register whilst configuration of trafiic re-reroute is done
+	 * in dcore0 rtr2.
+	 */
+	u32 reg = regmap_readl(mmDCORE0_RTR2_TIF_LBW_USR_RTR);
+
+	reg |= BIT(DCORE0_RTR2_TIF_LBW_USR_RTR_TPC0_RTR_SHIFT);
+	reg |= BIT(DCORE0_RTR2_TIF_LBW_USR_RTR_TPC1_RTR_SHIFT);
+
+	regmap_writel(reg, mmDCORE0_RTR2_TIF_LBW_USR_RTR);
+}
