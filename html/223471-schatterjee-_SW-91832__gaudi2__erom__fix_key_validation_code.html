Commit Message

[SW-91832] gaudi2: erom: fix key validation code

In Gaudi2, ROM and eFUSE store hash of public key properties.
The public key received as part of fit is the complete public
key dtb. Currently hash was calculated on complete key. But
it should be done only on the key properties. So extracted key
properties and computed hash on 784 bytes of key properties
to compare with stored ROM/eFUSE hash.

This is align with key validation code with proboot-rtos code.
