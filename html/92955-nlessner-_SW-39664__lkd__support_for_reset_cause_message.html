Commit Message

[SW-39664] lkd: support for reset cause message

Add support for new message types like reset cause. To keep current flow
and backward compatibility we validate first that data received isn't a
FIT image. If not FIT we check for comms message via magic in header.
If msg magic found in header we evaluate the type otherwise fail as
before.
