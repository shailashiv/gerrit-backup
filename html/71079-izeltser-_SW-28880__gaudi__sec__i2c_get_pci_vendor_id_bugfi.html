Commit Message

[SW-28880] gaudi: sec: i2c get pci vendor id bugfix

in secured mode the pcie configuration space registers are
inaccessible during iatu access, so when the bmc is asking
for the vendor id the wrong value is retrieved.
in order to fix that, the value is stored while conf space still
accessible, and used when BMC is asking for it.
