Commit Message

[SW-0] preboot: skip btl version print for secureboot flow

Currenlty, BTL version is printed in preboot for both btl and
secureboot flow. However in secureboot flow, BTL version is printed
as 0. This patch add changes to skip BTL version print for
secureboot flow by reading bootstrap register.

Due to hybrid mode used for greco, flow is identified in software
rather than reading boot_strap register.
