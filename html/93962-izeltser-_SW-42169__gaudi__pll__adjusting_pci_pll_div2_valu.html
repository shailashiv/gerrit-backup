Commit Message

[SW-42169] gaudi: pll: adjusting pci_pll div2 value

Lowering the clock produced by pci pll div2 output from 166Mhz to
103.75Mhz due to unstable pci phy operation.
The unstable operation is obsereved when the host pcie insteface
goes through multiple enable/disable cycles, at some point the
pcie phy in gaudi device goes to power down mode unexpectedly.
