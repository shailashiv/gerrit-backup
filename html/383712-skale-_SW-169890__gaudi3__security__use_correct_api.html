Commit Message

[SW-169890] gaudi3: security: use correct api

This patch uses the proper ppboot api to check whether
real or fake security is enabled or not and decide whether
to open pcie registers using range registers. Earlier efuse
driver api was used which was checking only real security
is enabled or not and opening the pcie registers using range
registers even in case if fake security was enabled.
