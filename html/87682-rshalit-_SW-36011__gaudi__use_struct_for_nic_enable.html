Commit Message

[SW-36011] gaudi: use struct for nic enable

Instead of using bitmask only for nic enable, use
of struct hl_nic_en which contains both bitmask
and validity, so that validity is used to ensure
that bitmask was written by KVM. If validity is 1,
it means that bitmask is valid. This flag is set
when nic enable fit is received, and is only used
in preboot internally.
