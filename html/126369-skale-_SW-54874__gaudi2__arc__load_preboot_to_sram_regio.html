Commit Message

[SW-54874] gaudi2: arc: load preboot to sram region

Currently, preboot image is dma'ed from spi to scratchpad sram
in secureboot flow. Since scratchpad sram is limited and is used
for other stuff in FW, this patch add changes to load and run
preboot at sram location.
