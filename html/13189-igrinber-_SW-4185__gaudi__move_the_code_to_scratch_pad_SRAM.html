[SW-4185] gaudi: move the code to scratch pad SRAM

This is a part if the W/A for the PLL clock switch h/w bug.
We move the preboot in to scratch pad SRAM, so there will be no
transactions on the HBW (e.g. instruction fetch) during the PCI PLL HBW
clock switch.
