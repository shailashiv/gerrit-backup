Commit Message

[SW-41316] preboot: make flexible fw load setting platform specific

Currently CPU_BOOT_DEV_STS0_FW_LD_COM_EN bit is set for all platforms
as part of module_lkd_enable function. This causes issues in greco
LKD load where flexible FW load is not supported. This patch
moves setting of CPU_BOOT_DEV_STS0_FW_LD_COM_EN bit platform specific
and enables for goya and gaudi.
