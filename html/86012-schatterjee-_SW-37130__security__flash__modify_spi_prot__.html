Commit Message

[SW-37130] security: flash: modify spi_prot()

spi_prot() is modified as given in "WRSR flow"
in flash datasheet
@https://media.digikey.com/pdf/Data%20Sheets/Macronix/MX25U25635F.pdf

Now spi_prot() check added for 'WEL' bit to set before writing into
WRSR register. Also verified for WEL=0, BP[3:0], SPWD data
for successful WRSR update.

Also spi_prot() is moved to ppboot before pcie link init from
current spi_copy() function. Now as spi_prot() is moved before pci link
init, some whileloops are modified to use timeout to avoid infinite
loops.
