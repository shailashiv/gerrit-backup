Commit Message

[SW-94722] gaudi2: remove clearing msix address reg from ppboot

It is observed that accessing PCIE_DBI registers during pci link
transition can cause a cpu freeze. This issue has been observed
earlier(https://gerrit.habana-labs.com/#/c/101296/). Hence,
clearing msix match address registers after pcie initialization
in preboot.
