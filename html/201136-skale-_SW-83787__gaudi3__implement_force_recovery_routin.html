[SW-83787] gaudi3: implement force recovery routine

Currenlty in common recovery function, the function checks for GPIO
assert as well as recovery flag upon which it enters in recovery.
However for automated recovery only gpio assert check is enough as
recovery flag is set by ROM when primary/secondary image load fails
and if that bit is not cleared, then it will force ROM to enter recovery
again on next reset till cold reset is not issued or ROM doesn't clear
recovery flag which is only done when primary/secondary image load is
successful. This patch adds platform specific recovery routine for gaudi3
which only checks force recovery GPIO to enter recovery.
