Commit Message

[SW-15002] gaudi: security: dis iatu access once

Spare configuring the iATU access disable (including security) after it
was already done.
In the new LKD protocol, the iATU access is disabled on any command sent
via the PCIe, so it might be done multiple times.
Doing this multiple times is not a problem, but is also redundant, so do
this only once.
