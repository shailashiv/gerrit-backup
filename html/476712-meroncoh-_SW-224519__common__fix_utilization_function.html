[SW-224519] common: fix utilization function

When calling hl-smi with -Q for querying utiliztion.aip, the displayed
value could be corrupted. However, when calling hl-smi without -Q, then
the utilization was displayed correctly. The reason is that in the former
case, the power drawn from the secondary PSU is not getting updated, while
in the latter case it is. Therefore, there was a need to update it in the
utilization function: hlml_device_get_utilization_rates.
