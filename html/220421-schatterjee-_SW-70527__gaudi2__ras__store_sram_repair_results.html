[SW-70527] gaudi2: ras: store sram repair results

Added support to store sram repair results i.e.
rings failed before built in soft repair and rings
failed after built-in soft repair.
These data is stored into a predefined memory location
(ARC1 DCCM start address) as a temporary location.

In preboot these would be read and stored in boot_info.
