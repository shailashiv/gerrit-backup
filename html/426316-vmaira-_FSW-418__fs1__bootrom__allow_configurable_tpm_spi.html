Commit Message

[FSW-418] fs1: bootrom: allow configurable tpm spi freq

In FS1, TPM SPI frequency is configured based on a
2-bit setting in eFuse. This patch adds changes to
read frequency configuration from efuse and compute
the baudrate to be configured to SPI controller
accordingly.
