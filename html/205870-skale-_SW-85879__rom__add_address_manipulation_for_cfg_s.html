Commit Message

[SW-85879] rom: add address manipulation for cfg space

Currently the ROM code assumes the address manipulation for config
space is done by hardware. ie. if die1 performs read/write with
die0 register offset, hardware will route it to die1 register offset.

However, with latest update from ARCH/HW team, the address manipulation
by hardware for config space is only done for PARC_LOCAL_CFG page where
die-id register resides and not complete config space. This patch
add changes to perform address manipulation for config space.
