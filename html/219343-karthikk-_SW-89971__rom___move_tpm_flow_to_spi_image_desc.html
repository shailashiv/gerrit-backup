Commit Message

[SW-89971] rom : move tpm flow to spi image desc

As per the updated security specification requirement for gaudi3, tpm
image is moved as a part of regular image descriptor.

The bringup api of ppboot image in rom is re-used for tpm image as well,
which also includes the secondary image processing. Currently it is not
intended that tpm would have a different secondary image, but is kept
for forward compatibility purpose.
