Commit Message

[FSW-418] fs1: bootrom: reduce tpm timeout values

TPM execution cannot have timeouts as long as
750ms or 2000ms, as these prolonged timeouts
can cause the boot ROM to fail to boot within
the PCIe boot timing restrictions.

This patch reduces timeouts to 2ms or 10ms.
