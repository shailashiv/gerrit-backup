Commit Message

[SW-20806] i2c: add write support

In order to support loading firmware via I2C it is needed to add I2C
write support to I2C module.

This patch introduces basic i2c write support which does not process the
written data but rather just removing it from the queue and call a write
stub function.

The I2C module was refactored in order to optimize the write procedure
so that the HW queue will not overflow.
