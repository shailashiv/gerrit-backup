[SW-91832] gaudi2: erom: increase stack size of recovery image

Currently erom recovery stack size is set to 512 bytes which is not
sufficient as erom recovery run image verification code as part of
image validation and will need more stack. This patch increases stack
size of erom recovery image to 4KB.
