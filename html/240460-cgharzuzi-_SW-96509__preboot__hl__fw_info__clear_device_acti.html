[SW-96509] preboot: hl: fw_info: clear device activity counter

The device activity counter, which indicates the number
of times the device was used by the user from the last
cold reset or prstn reset, this data is provided to fw
from LKD and reported in RAS, this commit clears the counter
whenever cold reset or perstn occur.
