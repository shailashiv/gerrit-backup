Commit Message

[SW-91832] gaudi2: erom: add security boot_info

HL_BOOT_INFO_SECURITY_OTP was not getting set in
erom_recovery application. This was causing invalid
otp in fw loader agent which reads otp from boot_info.

In this patch code is aligned with preboot to call
preboot_security_sp_sram_init() function from erom_recovery()
app too. This function takes care to set SECURITY_OTP as
well as SECURITY_FUSE for fake security.
