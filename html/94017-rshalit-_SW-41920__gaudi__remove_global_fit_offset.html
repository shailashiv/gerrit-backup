Commit Message

[SW-41920] gaudi: remove global fit offset

In preboot we used global fit offset with getter
and setter function. This is problematic because
the global can be changed from various command
interfaces. Also is was only partly used in some
of the interfaces, which introduced bugs in load
types such as nic enable and rma erase. This patch
fix it by using the offset as a function argument
instead of using a global.
