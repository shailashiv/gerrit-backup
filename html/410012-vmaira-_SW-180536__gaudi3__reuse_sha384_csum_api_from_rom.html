Commit Message

[SW-180536] gaudi3: reuse sha384_csum api from rom

For gaudi3, reuse the sha384_csum api exported from rom.

Since gaudi2 still makes use of sha384_csum function
defined in preboot/lib/common, this function is moved
from common to gaudi2 specific files. For gaudi3,
sha384_csum function definition is removed since it
is no longer utilized and instead reuses rom api.
