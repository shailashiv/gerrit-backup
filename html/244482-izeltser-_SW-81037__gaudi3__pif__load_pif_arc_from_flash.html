Commit Message

[SW-81037] gaudi3: pif: load pif arc from flash

PIF ARC firmware is stored on the SPI flash, ppboot is responsible
for loading the FW from flash to the CCM memories, and starting
the PIF ARC execution.

PIF CCMs have some limitations, access time from psoc is quite slow
and unaligned address access is not allowed. In addition they are
connected on the LBW bus, it's not possible to use efficient copying
engines such as psoc mem copy and spi dma.
Therefore the images are copied from SPI Flash to ARC1 ICCM (SPI DMA),
validated, and then copied using SW memcpy to the PIF CCMs.

+static void pif_arc_mem_init(struct cpu_load_data *data, struct boot_desc *desc)
+{
+	u32 buff_addr;

+static void ppboot_halt_n_reset_pif_arc(u32 cpu_cfg_base)
+{
+	u32 halt_ack_reg = cpu_cfg_base + PIF_RUN_HALT_ACK_OFF;

+	u32 rst_reg = cpu_cfg_base + PIF_ARC_RST_OFF;

+	/* Check if already in reset state */
+	val = regmap_readl(rst_reg);
