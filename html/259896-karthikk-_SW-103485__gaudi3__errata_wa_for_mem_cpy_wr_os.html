Commit Message

[SW-103485] gaudi3: errata wa for mem cpy wr os

As a workaround for hw errata GAUDI3_0315, memcpy wr_os register
is set to 62. Default value for the register is 32 . The workaround
would increase performance and make sure the register is not programmed
with the error case value (i.e 63)
