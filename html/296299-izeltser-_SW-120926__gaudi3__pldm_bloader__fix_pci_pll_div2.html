Commit Message

[SW-120926] gaudi3: pldm_bloader: fix pci pll div2

Since on PLDM we change the CLK driving the D2D SPI GW,
application can't reconfigure the PCI PLL over the SPI GW.
Instead, we rely on boot FSM to configure the PCI PLL, and add some
fixups in the pldm-bloader application, which runs on both dies.
Yet Boot FSM actually doesn't configure div2 of the PCI pll to
nominal clk (100MHz), so we fix it as well in the pldm-bloader.
