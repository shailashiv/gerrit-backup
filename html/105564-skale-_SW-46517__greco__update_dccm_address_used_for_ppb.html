Commit Message

[SW-46517] greco: update dccm address used for ppboot

In secureboot flow of greco, ppboot is copied into fw sram
and ppboot running on arc1 uses dccm for stack and data.
The current offset used for ppboot overlaps with dccm range
used by arcboot ROM which causes issues with ppboot execution.

This patch moves dccm address for ppboot so that it won't overlap
with arcboot ROM dccm useage.
