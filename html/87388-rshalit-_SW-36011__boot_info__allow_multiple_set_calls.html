Commit Message

[SW-36011] boot_info: allow multiple set calls

Allow boot_info set to be called multiple times during
preboot runtime. If already exist then the same pointer
is used. Otherwise - a new boot descriptor is added.
This is required to allow multiple set operations off
the same boot descriptor.
As this is not restricted, on loading NIC enable fit can be
done multiple times, and therefore shall result in multiple
call for setting the same boot descriptor.
