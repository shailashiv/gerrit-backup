Commit Message

[SW-94323] gaudi2: reset cold_rst recovery_flag in erom_recovery

If the recovery flag is set the arcboot executes the erom_recovery
without even trying to load ppboot image and this flag is set in
arcboot rom whenever it fails to load ppboot image. Therefore
even after successful firmware in erom recovery the arcboot rom is
loading erom recovery image hence recovery flag needs to be cleared
in erom to allow arcboot rom to load the ppboot image after firmware
update.
