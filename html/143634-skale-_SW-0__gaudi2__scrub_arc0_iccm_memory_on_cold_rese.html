[SW-0] gaudi2: scrub arc0 iccm memory on cold reset

In gaudi2, ARC0 ICCM is used to store boot info. Since boot info read
is performed first as part of preboot, fake ECC exception can be
observed due to uninitialized reads performed on ARC0 memory.
In order to avoid ECC exceptions due to uninitialized reads,
this patch add changes to scrub ARC0 ICCM memory in case of cold reset.
