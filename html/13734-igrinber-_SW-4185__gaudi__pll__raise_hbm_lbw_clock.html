[SW-4185] gaudi: pll: raise hbm lbw clock

The PSOC HBM PLL LBW clock can use the regular W/A and is configured
accordingly.
The NIC2 HBM PLL LBW clock cannot use the gated switch as a W/A,
because we will loose the ability to write to its configuration.
Therefore we apply the same W/A as for the NIC2 HBM HBW clock which
includes the same reset procedure.
We configure the NIC2 HBM LBW at the same time as the HBW and use call
the reset afterwards, so only one reset will be needed. Reset in turn
removes the clock switch glitch.
