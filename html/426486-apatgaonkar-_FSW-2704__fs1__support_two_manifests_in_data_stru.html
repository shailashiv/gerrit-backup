Commit Message

[FSW-2704] fs1: support two manifests in data structures

In two manifest design, each manifest will have single
instance of ppboot and recovery images required. There
will be no support for tpm spi. To accommodate this design,
after image validation has passed rom will store only
one manifest header and relevant image descriptors
in persistent data boot_rom_manifest.
This persistent data is redundant if boot info is
enabled and rom will read this data from boot info
file.
