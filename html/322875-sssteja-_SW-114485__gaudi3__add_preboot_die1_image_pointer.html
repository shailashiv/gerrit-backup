[SW-114485] gaudi3: add preboot die1 image pointer support

This patch adds preboot die1 image pointer support.
Preboot Die1 present at SPI offset Sector 20 (0x140000)
Die0 preboot FW does SPI DMA first to D0_ARC1_ICCM and later does
mem_copy to D1_ARC1_ICCM. This is needed because Die0 SPI DMA cannot
copy to Die1 memories.
