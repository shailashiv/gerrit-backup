[SW-79482] gaudi2: security disable in production for rma

To support RMA debug in production, firmware needs support of
disabling security and image validation across the flow. This
scenario will be called fake unsecurity and detected based on
following GPIOs:
GPIO_77 = '1'
GPIO_78 = '1'
GPIO_57 = '0'
