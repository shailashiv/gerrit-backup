[SW-195340] g3: ppboot: increase ppboot size

Increase ppboot size for Gaudi3 from 18K to 20K
in order to implement watchdog timer support.
After this patch the amount of free memory in ppboot will be ~2kb.
According to the estimation, since we don't use secondary images
fallback during boot, the boot time after this change will be ~77ms.
