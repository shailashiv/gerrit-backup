Commit Message

[SW-106014] gaudi3: use arcboot boot_info get api

boot_info get api is exported by arcboot and available for ppboot
to use. Calling the arcboot api instead of the local implementation
will decrease the ppboot size. Ppboot should be kept as thin as it
can be, so boot time loading/processing/validating operations will
perform as fast as we can.
