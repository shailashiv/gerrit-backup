[SW-65638] gaudi2: release: change the --* args

Change the auto evaluate variable that holds the command line
related arguments. It uses the original variable name wit the addition
of a suffix.

Two variables are created. ${var}_args and ${var}_f.
The ${var}_f set to 1, when the parser handles it. The second arguments
holds the arguments supplied with the command.
