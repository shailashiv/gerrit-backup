Commit Message

[SW-195014] gaudi3: tpm: fix manifest hash calc in ppboot

Earlier, the manifest image used for calculating the manifest
hash included the public key. During, signing process the
public key gets modified. Because of this manifest image used
to generate the gaudi3-pcr.bin and the signed manifest image
sent to card during FW update are different. This causes the
TPM PCR mismatch if image signing is used.

This patch removes the public key area from the image used for
manifest hash calculation in ppboot.
