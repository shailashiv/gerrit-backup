[SW-69872] gaudi3: add delay post slave detection

Currently for inter die notification, master holds a pulse of 10us
and slave detects the same. But logically, slave can detect the pulse
at any point on the 0-10th microsecond. Due to this, if the pulse is
detected on slave in the first half pulse, slave starts executing
whilst master is still completing the indication pulse.

Due to this there is a possibility that slave mis-interprets this pulse
when checked again in the execution flow.

To avoid such race, a delay is added on slave so that each pulse is
detected only once on slave.
