[SW-47990] gaudi2: pll: add sram plls init

Add SRAM PLLs initialization for asic.
The SRAM PLLs initialization is needed for Preboot to be able to serve
the BMC requests in time.
For this task use SRAM PLL half nominal configuration (400MHz).
