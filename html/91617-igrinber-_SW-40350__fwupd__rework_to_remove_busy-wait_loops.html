Commit Message

[SW-40350] fwupd: rework to remove busy-wait loops

The module_fwupd was implemented like U-Boot implementation which was
done before I2C slave bus support and thus did not take into an account
I2C slave bus handling while being single threaded w/o interrupts.
Rework the FWUPD module to remove any busy-wait loops and make all the
possible handling of the protocol fast.
The only commands that are handled slow are those requiring significant
time to process.
