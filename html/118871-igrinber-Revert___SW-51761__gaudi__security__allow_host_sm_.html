Commit Message

Revert "[SW-51761] gaudi: security: allow host sm access"

SM monitors are not needed to be accessed from PCIe and also are
vulnerable when accessed from PCIe and can result in various
instabilities. The same true for the gaps between the SM address space
and other components.
Given the above, we block the SM monitors and gaps access from PCIe.
Revert the commit that opens the full access and open it partially -
only monitors and gaps are blocked.

This reverts commit 67392f04247cb0e9d1ca37d755b835e2f8d1c61a.
