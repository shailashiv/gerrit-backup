[SW-113135] gaudi3: use btm fsm fifo to read reset source

Currently ppboot makes use of rst_src register to get information
about last reset source. FW needs to write this register to clear
reset source. However as per Errata GAUDI3_0325, rst_src register
is used by boot FSM and FW should avoid writing to register. This
patch implements workaround and make use of BTM FSM FIFO to retrieve
reset source information. Upon reading reset source information from
BTM_FSM FIFO, it is copied to local structure and also needs to be
copied to boot info which will be added in later patches.
