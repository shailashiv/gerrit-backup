[SW-0] ppboot/preboot: replace preboot_start()

The preboot_start() function is the same as the more generically called
image_start() function. Reuse the later also for Preboot start.

As a side effect got Goya2 ARC, this brings into Ppboot the
image_start() function which has an implementation instead of the
preboot_start() function which had no implementation for that platform.
Since on the Goya2 ARC the call to preboot_start() (and thus for
image_start()) is not reached (because we return to BootROM), this
should not be a problem.
