Commit Message

[FSW-2704] fs1: add manifest spi dma constants

SPI DMA of manifests is from fixed offset in SPI
to fixed offsets in ICCM. This patch defines all
constant values needed for copying both manifest
0 and 1.
Manifest0 : SRC SPI offset: 0x0 Dest ICCM Offset: 0x0
Manifest1 : SRC SPI offset: 0x400000 Dest ICCM Offset: 0x10000
