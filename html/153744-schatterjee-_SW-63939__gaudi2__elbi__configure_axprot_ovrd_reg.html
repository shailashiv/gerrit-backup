[SW-63939] gaudi2: elbi: configure axprot_ovrd reg

Configured CORE_LBW_AXPROT_OVRD of PCIE_ELBI_RR_MSTR_IF
as secured. This is to block transactions via ELBI interface.
ELBI RRs(PCIE_ELBI_RR_MSTR_IF) also configured for privilege access.
So any transaction via ELBI will be considered as secured and expected
to be blocked by ELBI RRs.
