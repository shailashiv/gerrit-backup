[SW-22078] preboot: goya2: set arcs in running state

As per new requirement of loading zephyr images on ARC from BTL based
boot flow, ARC should be put to running state as part of start
image function in preboot after fit images of zephyr are copied in ARC's
ICCM and DCCM. This patch add support to put ARC0 and ARC1 in running
state which will start zephyr OS (PID and MGMT) on ARC0 and ARC1.

+/*
+ * Set ARC in running state
+ * 1. Set run bit in RUN_HALT_REQ register
+ * 2. Wait for ACK from core in RUN_HALT_ACK register
+ * 3. Clear run bit in RUN_HALT_REQ register
+ */
+#define RUN_ARC(id)							       \
+	do {								       \
+		regmap_writel(BIT(0), mmPSOC_ARC##id##_CFG_RUN_HALT_REQ);      \
+		while (!(regmap_readl(mmPSOC_ARC##id##_CFG_RUN_HALT_ACK) &     \
+				PSOC_ARC##id##_CFG_RUN_HALT_ACK_RUN_ACK_MASK)) \
+			;						       \
+		regmap_writel(0x0, mmPSOC_ARC##id##_CFG_RUN_HALT_REQ);	       \
+	} while (0)
