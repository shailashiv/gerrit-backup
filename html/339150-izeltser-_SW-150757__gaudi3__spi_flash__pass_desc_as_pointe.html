Commit Message

[SW-150757] gaudi3: spi_flash: pass desc as pointer

for some odd reason the compiler sees desc.spi_offset under
spi_flash_slave_init() as a dangling pointer.
this seems like a compiler confusion, but as a WA, instead of
defining desc on the stack it is passed from the calling function
as a pointer, since it's already defined there.

compiler output:
spi_flash.c:60: error: dangling pointer to 'desc' may be used
