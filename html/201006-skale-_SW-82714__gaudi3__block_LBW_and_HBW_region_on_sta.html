Commit Message

[SW-82714] gaudi3: block LBW and HBW region on startup

In gaudi3, HW FSM will block entire LBW and HBW region using RR. However if
there is bug in HW in blocking entire config space, backup needs to be kept
inside ROM to block entire config space. This patch modifies current
implementation to block HBW interface and block/unblock JTAG/TWI LBW/HBW
region based on efuse bits.
