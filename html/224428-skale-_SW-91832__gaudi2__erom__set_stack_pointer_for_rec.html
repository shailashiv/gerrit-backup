Commit Message

[SW-91832] gaudi2: erom: set stack pointer for recovery image

Currently, erom recovery image is running on SRAM and uses stack
assigned by arcboot rom in DCCM. After loading erom recovery image, it is
not expected that control will go back to arcboot rom as erom recovery
image will perform secured firmware update and will wait for commands
from firmware loader. This patch seperates .S file for erom recovery
and sets stack pointer to be used from SRAM.
