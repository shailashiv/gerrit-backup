Commit Message

[SW-101652] gaudi3: pcie: add timeout for para sts clear

Currently, as part of SNPS DCC WA, rom loops infinitely for clear
status. As per HW team recommondation, this patch add timeout
of 10ms for PARA status to be cleared. Timeout in status clear
is recorded in ROM status update.
