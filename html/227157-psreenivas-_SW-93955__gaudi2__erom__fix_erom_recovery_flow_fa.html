Commit Message

[SW-93955] gaudi2: erom: fix erom recovery flow failure

In gaudi2 COMMS protocol is used to read all the firmware
versions and hence the preboot_ver_off_map offset is mapped
as 0. when trying to read this offset(0) is causing the recovery
flow to hung. Therefore read the btl version only in legacy flow.
