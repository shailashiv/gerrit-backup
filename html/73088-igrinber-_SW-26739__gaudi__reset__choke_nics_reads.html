Commit Message

[SW-26739] gaudi: reset: choke nics reads

Choke the NIC TXE read transactions on reset, so no new
read transactions will be issued to host direction.
Issueing read transaction to host during reset (or driver rmmod) might
return with error and raise interrupt which in turn will result in more
transactions towards host. This is not a recommended behaviour during
the reset time and thus should be avoided.
We do this by removing forcibly all the credits from the TXE engines.
