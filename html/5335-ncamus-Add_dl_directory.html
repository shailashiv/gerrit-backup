Commit Message

Add dl directory

This saves build time and avoid dependency on connectivity to WWW.
It also insures we reproduce same rootfs each time.

NOTE:
This commit is a pure binary files.
GIT cannot have delta petches for binaries.
Since I use frequent rebase operations I put this
commit to be the first commit despite it is not natural.
This way this commit won't change till we really want it to.
