Commit Message

[SW-66329] pif_arc: add error logging to spare register

Pif Arc might encounter some error conditions during runtime.
Since by definition this CPU is not allowed to access to any
resources outside of the pci block, the chosen way to report
those error is by logging them to a register (1 of the spares)
and let other CPUs read it when they can.
