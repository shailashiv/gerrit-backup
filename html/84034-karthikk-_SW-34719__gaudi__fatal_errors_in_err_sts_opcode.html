[SW-34719] gaudi: fatal errors in err_sts opcode

preboot fetches values of rma events from flash
and the same needs to be stored in nvme mi
opcode 11 (Error Status).

This patch adds changes to update rma events termed
as fatal errors classified into sram_ecc, hbm_ecc
and hbm_parity errors respectively.
