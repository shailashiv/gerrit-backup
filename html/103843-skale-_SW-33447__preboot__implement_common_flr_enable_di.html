Commit Message

[SW-33447] preboot: implement common flr enable disable fn's

In order to FLR interrupt handled by firmware, hw_ctrl and
int_mask needs to be cleared and should be set back again while
exiting preboot. This patch implements common function to
enable/disable FLR to avoid code duplication and enable it
for gaudi, gaudi2 and greco platform.
