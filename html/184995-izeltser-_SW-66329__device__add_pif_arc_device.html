Commit Message

[SW-66329] device: add pif arc device

Pif Arc is an Arc CPU positioned as part of the PciE block, and used
for FLR request handling.
The pif arc registers are added to the device structure, and
initialized for both dies of the gaudi3 device. in the following
patch FLR module will be added and it will be using those registers
for handling the FLR for both dies (same binary loaded to both dies).
