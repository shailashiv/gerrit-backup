[SW-225915] fu: set correct pci device id

Set the pci device id for the firmware update device descriptor
based on card type.
Add function to get the device descriptors and the descriptor count.
This will allow platforms to make adjustments to the default
descriptors during runtime and present fewer descriptors if needed.
