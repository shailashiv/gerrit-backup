Commit Message

[SW-15774] build: refactor zephyr package and scripts

For backward compatible, Zephyr's package's build script needs to be
refactor, and no longer leads the build process, but rather use as a
consolidator of individual packages. It is done by adding the relevant
packages as dependencies.

The second goal of this patch is to update the location and names of
intermediate files.
