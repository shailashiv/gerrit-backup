Commit Message

[SW-81036] boot_desc: use plat specific max num of images

Max number of images is hardcoded locally in the boot desc
implementation file.
Gaudi3 device has larger amount of images in SPI flash due to
additional CPUs such as the PIF ARC.
In order to preserve the memory consumption of the other devices
the max number of images definition is moved to platform specific
header file and larger number of images is given to gaudi3.
