Commit Message

[SW-51853] gaudi: security: add dyn cfg block rrs

While in Preboot, Gaudi's engines are vulnerable to PCIe attacks and no
monitoring (e.g. interrupts) is done.
This can result in Gaudi to become unstable.
To overcome, add 2 PCIe RRs to dynamic configuration and block the
entire CFG space. Only the communication area is left open.
