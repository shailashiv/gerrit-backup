Commit Message

[SW-47229] greco: legacy: set default pci id to addin card

PCI ID for greco ADDIN card(75W) is 0x0030 which should be set
as default because all cards available right now are ADDIN.
This patch does following change:
Default PCI ID in non-secure mode: 0x0030
Default PCI ID in secured mode: 0x0031

As there is no secured mode available in legacy flow so it
will always go for non-secured mode.
