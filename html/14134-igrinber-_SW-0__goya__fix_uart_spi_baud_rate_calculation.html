[SW-0] goya: fix uart/spi baud rate calculation

In Goya (unlike in Gaudi), the UART and SPI clock is derived from the
PCI PLL divisor output 1, and not output 2 (as is currently).
This worked till now because both outputs were the same (reference
clock) and thus the calculation produced the correct values.
Correct the source for both UART and SPI baud rate calculations.
