Commit Message

[FSW-418] fs1: bootrom: separate tpm sendrecv function

This patch splits the TPM function that sends and
receives commands to and from TPM, into separate
send function and receive function.

TPM has significant wait times before responding to
commands. To avoid being idle while waiting for a
response, the send and receive functions are split.
Other tasks will be interleaved between the send
and receive functions, to reduce idle time
