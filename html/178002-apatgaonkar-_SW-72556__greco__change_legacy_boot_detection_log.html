Commit Message

[SW-72556] greco: change legacy boot detection logic

Due to DCCM ECC issue in arcboot rom, hybrid mode is enabled
for greco where execution starts from BTL and BTL starts
ROM flow on ARC1. Due to this, BTL_EN bit is set but still
ROM flow is executed. In mixed flow, BTL version needs to
be passed to host. This patch uses security_bypass strap
bit to distinguish between mixed flow and pure arcboot flow.
