Commit Message

[SW-228856] fit: call with original name

Context:
We encountered several code duplications related to
fit_foreach_property.
So we created a new fit services infrastructure
to solve this issue in a clean way.
The main Lego pieces are the newly created files:
fit_services.c/h

Current commit:
In this current commit, we invoke the function
fit_foreach_property with its original name
and not with its temporary name _fit_foreach_property.

General remark:
This infrastructure is intended to support ANY of the
fit related functions that we find today in fit_utils.c
or fit.c
Therefore, from now, please, anyone doing a change related
to the fit files should carefully double-check:
Any unified code can be (and should be) located in
fit_services.c/h
For this, please, follow the example of how it has been
done with fit_foreach_property.
