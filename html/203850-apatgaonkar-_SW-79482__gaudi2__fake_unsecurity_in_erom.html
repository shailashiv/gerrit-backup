Commit Message

[SW-79482] gaudi2: fake unsecurity in erom

To support RMA debug in production, firmware needs support of
disabling security and image validation across the flow. This
scenario will be called fake unsecurity and detected based on
following GPIOs:
GPIO_77 = '1'
GPIO_78 = '1'
GPIO_57 = '0'

In case of erom recovery mode when in fake unsecurity mode it
needs to ignore recovery procedure and load ppboot which will
allow for firmware flow to continue normally.
