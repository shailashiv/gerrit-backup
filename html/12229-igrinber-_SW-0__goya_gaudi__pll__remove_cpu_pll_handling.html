[SW-0] goya/gaudi: pll: remove cpu pll handling

Remove completely the CPU PLL handling from preboot as we cannot
change it while running on it.
The only one that should change/setup the CPU PLL is BTL.
For the JTAG case, we should update the script, which loads the
preboot/U-Boot directly to SRAM, to setup the CPU PLL if needed.
