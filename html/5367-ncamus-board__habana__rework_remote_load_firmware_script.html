Commit Message

board: habana: rework remote_load_firmware script

Current script assumes that there is a ready setup of the repo stuff
and also relies on some additional aliases that should be in place.
This is prone to repo corruptions and can't be ported simply to new machines.

Rework the remote_load_firmware script to not assume anything, but setup
all the needed prerequisites by itself.
Since the above might take a lot of time, move all the stuff to tmpfs.
This also makes the process more robust and immune to repo corruptions.

Signed-off-by: Igor Grinberg <igrinberg@habana.ai>
