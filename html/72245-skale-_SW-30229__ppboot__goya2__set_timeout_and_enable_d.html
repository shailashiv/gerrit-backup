[SW-30229] ppboot: goya2: set timeout and enable drain

Currently while running workloads, it is observed that some of
blocks register becomes inaccessible from ARC due to error on block
which causes ARC to go in bad state as the transaction to inaccessible
block doesn't get completed. Upon hard reset of device after failure
and even after performing halt and reset of ARC as part of ppboot,
the ARC doesn't come in good state and doesn't respond to halt request.

This patch add changes to enable drain control and set timeout of 1000
cycles which invalidates incomplete transaction after timeout. Upon
performing above configuration, ARC is able to respond to halt request
in error scenario.
