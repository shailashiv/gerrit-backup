Commit Message

[SW-39260] greco: disable pcie ltr capability

The Latency Tolerance Reporting capability is included
and supported in the PCIe controller and was integrated
into all projects. However, it seems that the controller
will not send an LTR message when needed if the latency
values are not configured in the PCIE_WRAP.

This causes us to fail PCI-SIGs CV tests that are related
to LTR: the controller reports LTR supported, but the
rules for this feature are not applied.

We agreed that the best solution would be to disable support
for LTR as this capability is not used or needed.
