Commit Message

[SW-0] make: rename preboot max size variable

Rename PREBOOT_MAX_SIZE variable to PREBOOT_BIN_MAX_SIZE.
This is to remove the ambiguity and make it certain that this variable
is the binary maximum size (usually to fit the flash region) and not
something else (e.g. sram section).
