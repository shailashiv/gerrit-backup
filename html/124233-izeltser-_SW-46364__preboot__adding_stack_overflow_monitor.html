Commit Message

[SW-46364] preboot: adding stack overflow monitor

The Stack monitor is checking the magic word that is stored at the
last address of the stack. If the value is not preserved during
the execution, or stack overflow indication received from ppboot,
fit image runnig by the LKD driver is prevented.
FW upgrade module continue to function normally so system can
be upgraded to a fixed version.
