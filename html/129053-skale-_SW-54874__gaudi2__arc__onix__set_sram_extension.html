[SW-54874] gaudi2: arc: onix: set sram extension

On Onix, SRAM is carved out of HBM region. This patch changes
SRAM_LSB_ADDR and SRAM_MSB_ADDR values for ARC1 so that ARC1
points to correct SRAM_BASE.

+/*
+ * SRAM on Onix is mapped at address 0x1001_0002_0000_0000,
+ * change SRAM extension for ARC1 accordingly.
+ */
+#define SRAM_EXTENSION_MSB      0x10010002
+void sram_set_extension(void)
+{
+	/*
+	 * On Onix SRAM memory is carved out of HBM region,
+	 * so change the extension address for onix.
+	 */
+	regmap_writel(SRAM_EXTENSION_MSB, mmPSOC_ARC1_CFG_SRAM_MSB_ADDR);
+	regmap_writel(0x0, mmPSOC_ARC1_CFG_SRAM_LSB_ADDR);
