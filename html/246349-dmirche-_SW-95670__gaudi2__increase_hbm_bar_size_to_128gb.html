Commit Message

[SW-95670] gaudi2: increase hbm bar size to 128gb

BAR size for HBM is set to 128GB instead of 64GB.
This is required for host to access of all available
space, so that host won't need to shift small BAR window
for every access which is outside the window.
Therefore, this method is more efficient and more secured.
