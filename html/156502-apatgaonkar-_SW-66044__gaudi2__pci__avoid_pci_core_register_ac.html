Commit Message

[SW-66044] gaudi2: pci: avoid pci core register access

During hot reset handling, if firmware accesses pcie core
register it causes self halt in ARC due to memory error.
This implied that during hot reset pcie core registers
are not accessible temporarily. As a work around this
patch handles hot reset differently for gaudi2. It checks
for hot reset irq after pcie link is up. As ltssm_en is
already set to 0x3 there is no need to reconfigure it.
