Commit Message

[SW-137122] gaudi3: erom rec: use arcboot api's to set boot info data

Since boot_info_finalize_no_merge will not copy the old boot info data,
explicitly copy the old boot info data using boot_info_sync_data() api.

Use arcboot api to set a erom version and fw info in boot info, so that
boot_info.ptrs.count will incremented along with existing boot info data
and which will get finalized when boot_info_finalize_no_merge() is called.

So added device specific function to set a erom version, fw info and
boot info finalize.
