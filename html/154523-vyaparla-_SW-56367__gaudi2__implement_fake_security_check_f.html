Commit Message

[SW-56367] gaudi2: implement fake security check function

This change adds fake security check support in preboot.
To reduce processing in ppboot pre-linkup, pcie rrs are blocked
unconditionally in ppboot, and based on the security enable
criteria, it opens up these rr's in preboot in case secuirty is
disabled and continues other rr configurations in case security
is enabled
