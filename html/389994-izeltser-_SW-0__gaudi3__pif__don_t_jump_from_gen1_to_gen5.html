[SW-0] gaudi3: pif: don't jump from gen1 to gen5

the default configuration is to allow direct jump from gen1 to gen5.
testing show that when such jump happens on HLS3 the link is
unstable. to improve stability, this option is disabled, and the link
should speedup gradually
