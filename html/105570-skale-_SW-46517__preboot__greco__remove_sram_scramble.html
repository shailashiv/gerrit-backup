[SW-46517] preboot: greco: remove sram scramble

In secureboot flow, preboot will be moved from scratchpad SRAM to
SRAM. In order to achieve this, SRAM scrambling init which
is done in preboot is moved to ppboot as it needs to be done before
SRAM is used by FW. This patch removes SRAM scrambler enabling function
from preboot.
