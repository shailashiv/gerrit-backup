Commit Message

[SW-0] common: make progress bits enum device specific

Currently the progress bits enum is common for all platforms. Due to
this, some of the bits remains un-used as those are used by previous
platforms. In order to optimize usage of progress bits, this patch
adds device specific progress bits enum.
