Commit Message

[SW-66329] pif_arc: add runtime status logging

Monitoring of the pif arc activity and status is very limited
because it is not allowed to access any registers of memory outside
of the pci block during runtime.
So to provide some minimal progress information, an enum status is
being writen to a local register.
