Commit Message

[SW-20154] gaudi2_arc_gnu: update the public key hash

Public key is usually the modulus value. Since the
properties are included in the image, there is no need
to include an additional 384bytes in the form of public
key. Hence remove it. Since the recommendation from
Arch team is that the hash calculation should consider
entire public key props, the hash is also updated.
