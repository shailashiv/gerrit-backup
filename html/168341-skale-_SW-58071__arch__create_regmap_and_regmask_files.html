Commit Message

[SW-58071] arch: create regmap and regmask files

This is preparatory patch for adding code for gaudi3. Currently
the common functions used by greco and gaudi2 are defined in
common file. Since the register and mask names for greco and gaudi2
were almost identical, there was not need to add regmap files for
registers used in common file. However in gaudi3, all registers
name and masks differ due to addition of die id. This patch creates
regmap and regmask files for such registers and masks for gaudi2 and
greco devices used in common function.
