[SW-0] gaudi3: rom: fix status update

The logic for SW status update for bringup is hardcoded to
SW_STATUS_0 register. As in gaudi3 the number of status flags
have increased, the image bringup statuses cross 32. Due to
this we need to update the logic to access SW_STATUS_1 registers
and so on according to the status bit number.
