Commit Message

[SW-50527] gaudi: security: enable dbg protection

The DBG space follows the CFG space and has the prefix of 0x7FFF000000,
while the CFG is 0x7FFC000000.
To be able to address both memory spaces with the same security
framework functions, extend the PAGE_BASE mask to 2 additional bits.
0xFFF000 => 0x3FFF000
