Commit Message

[SW-112010] eeprom: add support for comms eeprom msg

The COMMs EEPROM message is intended to let LKD enable usage of the
default EEPROM values for the development environment case (not customer
site).
Add support for this message and propagate the data to other FW
components (e.g. U-Boot).
