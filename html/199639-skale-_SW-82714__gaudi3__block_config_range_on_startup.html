Commit Message

[SW-82714] gaudi3: block config range on startup

In gaudi3, HW FSM will block entire config space. However if there
is bug in HW in blocking entire config space, backup needs to be kept
inside ROM to block entire config space. This patch implements
blocking entire config space based on RR efuse bit.
RR bit 0: skip RR configuration
RR bit 1: perform RR configuration
