[SW-2891] uart: rework preboot_uint2hexstring()

The preboot_uint2hexstring() function padding functionality is not
working and is just always enabled.
Rework the function to fix the padding functionalilty and also reuse
this code in the preboot_puth_raw() function.

This is also a preparation for the version code fix after the code base
move to scratch pad SRAM.
