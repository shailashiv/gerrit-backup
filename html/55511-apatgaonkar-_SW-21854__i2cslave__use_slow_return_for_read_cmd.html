Commit Message

[SW-21854] i2cslave: use slow return for read cmd

In preboot and recovery, for processing read cmds
received on i2c slave fast return was being used.
This caused i2c slave to race other time sensitive
modules as read command processing takes long ms.
Instead now i2c slave check will return slow return
for all commands which will cause other modules to
be disabled before processing i2c slave cmd.
