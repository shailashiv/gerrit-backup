Commit Message

[SW-221070] g2: update temp cache atomically

Original patch for temp cache used two static
variables which were updated separately. It was
possible to read them when while they were being
updated and end up reporting a stale temperature.
The new version uses a single int to store the
temperature and status when temperature sensor
read fails.
