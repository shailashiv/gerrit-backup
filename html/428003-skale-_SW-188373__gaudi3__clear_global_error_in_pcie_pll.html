[SW-188373] gaudi3: clear global error in pcie pll block

Due to unmapped register access in HW FSM [H9-5613], PARC interrupt
is generated with global error cause set in PCI PLL block in
both DIEs. Currenlty we clear PARC interrupt, however the global
error interrupt is not cleared which shows up when arcevent process
any SEI interrupt. This causes incorrect global error info to LKD.

This patch clears global error cause as part of parc interrupt clear
sequence.
