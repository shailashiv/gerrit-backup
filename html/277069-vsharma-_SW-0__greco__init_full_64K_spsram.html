Commit Message

[SW-0] greco: init full 64K spsram

Previously we were initializing spsram after 4K offset, as arcboot rom
copies info like keys, info for image verification, security efuse info.
Since security is not POR for greco, we don't use this info.
Instead of 60K and leaving first 4K offset, now we init full 64K of
spsram as we use spsram for mailbox, bootinfo, rodata etc.
