Commit Message

[SW-56697] gaudi2: add fw cfg skip strap

Add support via strap to skip fw config of section done by LKD for
poweron. If strap is set then skip:
- hbm pll init
- iATU
- clock gating
- axi-drian
- PCIe drain

For paladium and asic allow control via strap, for onix
always run config.
