[SW-0] goya2: asic: fix compilation error

As goya2 register offsets can be accessed through
header file goya2_blocks_linux_driver.h, pll base
offset define mmPSOC_PCI_PLL_BASE has been replaced
by mmPSOC_PCI_PLL_CTRL_BASE. This patch corrects
resulting compilation error.
