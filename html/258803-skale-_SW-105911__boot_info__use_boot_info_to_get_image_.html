Commit Message

[SW-105911] boot_info: use boot info to get image data

Currently, ROM doesn't make use of boot info get api's and use
manifest image data stored in dccm persistent memory on non-cold
reset. This patch add changes to retrieve data from boot info
in case of non-cold reset and stored it in rom data structure to
use it. This will reduce persistent memory usage in ROM in case
no functional bug is discovered in boot info across resets.
