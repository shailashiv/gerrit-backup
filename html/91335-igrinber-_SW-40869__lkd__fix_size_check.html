Commit Message

[SW-40869] lkd: fix size check

The LKD module has accidentally used the already wiped next FW
component size (the state machine has moved to a new command).
This can impose a wrong failure report if the actual size is larger
than the allocated memory frame size.
Save the actual size early enough (before state machine progress) and
pass it for validation.
