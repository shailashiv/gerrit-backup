[SW-12520] hls: install: host: deploy proj_hl

Deploy proj_hl directory as part of the release.

This directory has been developed and used by Accton to generate HLS FRU
binaries using frugen host tool.

It includes templates files specifying HLS FRU properties and scripts
used to generate binaries by converting these templates into JSON files
which are in turn provided to frugen utility.
