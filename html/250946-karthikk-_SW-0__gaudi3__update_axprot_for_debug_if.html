Commit Message

[SW-0] gaudi3: update axprot for debug if

Currently axprot values for debug if is only set during init in case
the efuse bit is set to "disable debug if" as debug ifs are privileged
by default. But as these efuse bits can be also modified using fake
fuse, there is a possibility to switch the debug if values from
DIS -> EN in hard/fw resets also.

Hence the logic in rom also needs to make the debug ifs back to
privilege in such cases.
