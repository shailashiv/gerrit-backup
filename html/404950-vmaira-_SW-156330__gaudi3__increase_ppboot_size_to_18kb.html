Commit Message

[SW-156330] gaudi3: increase ppboot size to 18kb

Current ppboot image size is very close to the 17kB
limit and addition of new code results in build
failure. Increasing the ppboot size limit from
to from 17kB to 18kB to allow new code addition.

Given that secondary image support is disabled,
PCIe link up time with this increase of ppboot
image size is calculated to be 77ms and well
within the 100ms limit for ppboot size 18kB.
