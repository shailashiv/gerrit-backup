Commit Message

[SW-66329] pif_arc: add flr handling implementation

Pif Arc is an Arc CPU positioned as part of the PciE block, and used
for FLR request handling.
This patch adds monitoring and handling sequence of an FLR event by
the PIF ARC cpu, as the device specific implementation of module pci
functions.
Error reporting and progress status via dedicated registers will be
added in future patches.
