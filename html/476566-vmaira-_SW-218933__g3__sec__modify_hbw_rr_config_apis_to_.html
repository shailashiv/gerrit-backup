[SW-218933] g3: sec: modify hbw rr config apis to take prot type

This patch modifies the apis related to HBW RR configuration to take an
additional additional argument, prot_type. This parameter enables api
users to specify whether the HBW region should be read-protected,
write-protected, or both.
