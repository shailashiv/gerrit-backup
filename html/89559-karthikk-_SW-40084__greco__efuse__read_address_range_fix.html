Commit Message

[SW-40084] greco: efuse: read address range fix

Currently the read address register(PSOC_EFUSE_READ_ADDRESS)
for efuse contains a value of 0x3FF8 on reset, which prevents
firmware from reading efuse contents from 0x00 - 0x77.

This value is set by the boot manager during the boot flow.

In order to read all the contents of efuse the
value needs to be updated to 0x3F80 for legacy boot flow

In case of secure boot flow, it is done in arcbootrom

This patch contains the fix for the same.
