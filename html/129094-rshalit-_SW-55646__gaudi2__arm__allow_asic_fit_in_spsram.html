Commit Message

[SW-55646] gaudi2: arm: allow asic fit in spsram

Fit image can reside not only in SRAM but also in SPSRAM (used
with ELBI).
As to pldm and onix, it only converts from arm view to absolute.
This patch differentiate between the configuration by moving
the implementation from common to arch specific.
