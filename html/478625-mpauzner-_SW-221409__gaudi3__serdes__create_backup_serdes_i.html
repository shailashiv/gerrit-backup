[SW-221409] gaudi3: serdes: create backup serdes image

Gaudi3 firmware, prior to v1.22, has hardcodded serdes table.
Starting v1.22, boot-fit will read serdes configuration from serdes
lfs partition in flash. However, during transition period,
the existing flash image may not contain serdes partition.

Thus, create backup serdes configuration for boot-fit.
The image will be loaded to an unused RAM of die1 arc.

Note: due of limitation of gaudi3 preboot, this feature
will work with prebbot v1.21 and above.


in die1 unused RAM.
