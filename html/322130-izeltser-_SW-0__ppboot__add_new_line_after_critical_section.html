Commit Message

[SW-0] ppboot: add new line after critical section

during the time critical section all prints are stored in a memory
buffer and flushed out to the serial port when the time critical
section ends.
if the memory buffer is not large enough for all the prints during the
time critical section, some the last line in buffer might be cut in
the middle and the next printed line will merge with it. to avoid this
an escape sequence is printed after the buffer flush.
