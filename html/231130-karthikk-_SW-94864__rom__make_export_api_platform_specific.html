Commit Message

[SW-94864] rom: make export api platform specific

Dma v2 api was introduced for gaudi3. As the export apis are
to be made project specific, this api and data type which was
added in gaudi3 cannot be referenced in common code.

This patch makes such changes platform agnostic.
