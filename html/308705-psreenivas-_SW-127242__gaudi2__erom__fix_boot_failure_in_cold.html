Commit Message

[SW-127242] gaudi2: erom: fix boot failure in cold reset

The CCM memories gets cleared in cold reset hence
accessing ARC1 ICCM for copying boot info can cause
ecc exception causing ARC to get hung. This patch
adds support to initialize the ARC1 ICCM in cold
reset in erom recovery flow.

Also this patch takes care to avoid copying boot_info
from persistent to spsram during cold boot.
