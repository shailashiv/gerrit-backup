[SW-105911] common: move start addr to global data structure

Currently, startaddr of ppboot which is required to jump to
ppboot in case of validation pass flag is set ie. ROM doesn't perform
dma and sha verification of image is store in non-persistent ROM
structure. This patch moves startaddr to persistent ROM structure
which is retained across non-cold reset.
