Commit Message

[SW-0] boot_desc: remove die id check from boot_desc_init

Currently, the check of die id is kept inside boot_desc_init
which skips for slave die (die_id=1). However the boot desc
failure flag is set for slave die. Since boot_desc_init is called
only from 2 places for gaudi3, this patch removes check of die
from boot_desc_init function and adds it in caller function.
