[SW-142278] h6: tpm: remove tpm_en efuse bit check

As part of SW-117389, tpm init is moved from erom to ppboot to meet pcie
timing constraints. So ROM can't expect TPM on EROM and tpm_en efuse bit
is not burnt. erom tpm boot descriptors were removed from image pointers
so that arcboot rom skips calling erom tpm always.

The decision was to support TPM feature independent of tpm_en efuse bit
in all FW components. So ppboot runs tpm code unconditionally
