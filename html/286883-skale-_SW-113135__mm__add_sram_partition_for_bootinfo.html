Commit Message

[SW-113135] mm: add sram partition for bootinfo

Starting gaudi3, bootinfo is used in ppboot which make use of ROM APIs.
However the ROM APIs for bootinfo is no-merge type hence ppboot retrieve
complete data from bootinfo to SRAM GP section, and then perform
set and finalize to add new boot info type. Currently it uses SRAM GP
section to store the bootinfo data. This patch adds new memory partition
for bootinfo which is kept as 256KB for gaudi3 and carved out of SRAM
GP section.
