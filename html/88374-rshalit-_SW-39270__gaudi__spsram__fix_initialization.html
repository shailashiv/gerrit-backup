Commit Message

[SW-39270] gaudi: spsram: fix initialization

SP-SRAM requires initialization, otherwise ECC
event PSOC_MEM_DERR is triggered when reading
from SP-SRAM. Previously, SP-SRAM SW initialization
is done only if is a cold reset cause. But some
boards may receive PRSTN event before reaching
SP-SRAM initialization, and thus preboot main
for the PRSTN reset did not do the SW initialization
and therefore DERR ECC events were triggered.
This patch fix this issue by using FLOPS_2 register
bit 0, as an indication for SP-SRAM SW init done.
