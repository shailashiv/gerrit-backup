Commit Message

[SW-170792] gaudi3: pif: drop pci vpd type 1 msgs

In previous patch the mctp messages coming from the host were blocked
in the MCTP block, and some interrupt had to be masked to allow that.
much cleaner solution is to block this kind of messages in the pci
controller.
this patch replaces the previous solution and clears FILTER_MASK_2_OFF
register of the DBI space, which according to designware datasheet means
"vendor MSG type 1 dropped silently"
