Commit Message

[SW-0] crc32: move crc32 table init to crc32 module

This change is required for boot info to
calculate crc while reading last boot info. Since boot
info reads are happenings before crc32 table initialization,
this change moves crc32 table initialization to crc32
module. crc32 table will be initialized once whenever
a crc32 call is made.
