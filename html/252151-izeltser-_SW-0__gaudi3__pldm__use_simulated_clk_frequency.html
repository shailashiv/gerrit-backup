[SW-0] gaudi3: pldm: use simulated clk frequency

So far a real world clock equivalent was used for the TimeStamp
counter and uart. This has some significant disadvantages:
1. the real world clk freq on pldm differs from image to image, and
   also from one pldm setup to another.
2. using values below 1MHz is not useful, because the division
   calculation when converting to usec will always return 0.
3. when measuring simulation domain timing, using real world
   equivalent will doesn't help and the simulation clock value should
   be used.

for those reasons, the clock value for pldm is set to simulation
domain frequency value of 250Mhz, which is usually used for PCI
PLL DIV3 output on pldm tests.
