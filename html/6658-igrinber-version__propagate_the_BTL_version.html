version: propagate the BTL version

Propagate the BTL version embedded inside the preboot version to upper
SW layers.
The BTL version is retrieved from the scratchpad 28 register and
prepended to the preboot version.
This forms a single string containing both versions, thus no further
upper layer SW adjustments are needed.
