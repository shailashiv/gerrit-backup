Commit Message

[SW-8229] goya2: invert revoke and fw version from flash

When reading revoke bit or fw_version from security flash sector
we invert the bits so we can erase the sector and clear bits, just
like logic of burning fuses. Then these bit can only be set again
if we erase whole sector.
