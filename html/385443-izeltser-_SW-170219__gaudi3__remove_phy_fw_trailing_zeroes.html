Commit Message

[SW-170219] gaudi3: remove phy fw trailing zeroes

PCI PHY FW has about 22kbytes of zeroes in the end of it.
Instead of storing those zeroes on the flash, and copying them from
flash cold boot, the image is trimmed and the remainig memory
is zeroized using the memcpy engine.
