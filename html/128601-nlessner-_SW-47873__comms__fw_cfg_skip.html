Commit Message

[SW-47873] comms: fw cfg skip

Support comms message from LKD to skip fw configuration
and pass the message to u-boot.
We pass the message to u-boot through preboot because
by the time u-boot is up for communication, it is
already too late and the FW cfg has already happened, so
we must handle the message at preboot.
