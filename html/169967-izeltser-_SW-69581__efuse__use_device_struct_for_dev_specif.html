Commit Message

[SW-69581] efuse: use device struct for dev specific data

Future devices we have multi-die architecture, common code should
be able to handle those configurations. Including device specific
headers from common code is not allowed anymore, and instead the
device structures should be used.

This patch paves the way for this architectural change, and moving
the efuse common code to this method of work.
