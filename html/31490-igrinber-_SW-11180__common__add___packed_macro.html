[SW-11180] common: add __packed macro

Add the definition for __packed which is a short hand of
__attribute__((packed)).
U-Boot and Linux have this definition in their headers, but Preboot is
still does not.
With inclusion of the external hl_boot_desc.h header, we need to define
the __packed attribute, so it will get recognized.
