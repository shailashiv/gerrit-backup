Commit Message

[SW-180536] gaudi3: tpm: remove pcr index get function

For Gaudi3, instead of separately extending PCRs
for individual ppboot and preboot images, we will
consolidate the process by extending the PCR of
the manifest.

In preparation for this change, this patch removes
the functions to fetch the PCR index for ppboot and
preboot images. Weak functions will be used in place
of removed ones, since they return the same values.
