Commit Message

[SW-99831] gaudi3: d2d: implement dphy hw errata fix

This patch implements the sw workaround for GAUDI3_0314.

Problem:
Hardware has a dedicated FSM which is responsible for initializing
the D2D. This initialization FSM has several steps, each step has
a watchdog timer (WD). The default values of the WD timer assumes
200MHz clock while the actual clock in recovery is 50MHz.

Implication:
The WD timer will expire later which will make the initialization
process longer.
