Commit Message

[SW-30548] preboot: uart changed to slow return

Measuring UART timings in preboot shows UART takes significant time,
~2.2msec for handling a key press.
It is therefore required that UART handling in preboot will be of type
"slow return". The "slow return" in preboot assures that while the slow
modules run, other HW "pipes" related to other modules
(such as i2c for example) are not getting overflowed in the meanwhile.
