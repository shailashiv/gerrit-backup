[SW-14676] fwupd: support sram load run

Add support for running FIT images using fwupd sram load protocol

This protocol offer better robustness than LKD protocol while performing
maintenance operations.
The fw-loader utility uses it to communicate with the device, sending
commandw, retrieving statuses and validate exxecution.
