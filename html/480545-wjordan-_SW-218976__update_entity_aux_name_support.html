[SW-218976] update entity aux name support

Change the Entity AUX Name PDR format to
have a single name entry instead of an array.
Unlike Sensor and Effector AUX Name PDRs,
the Entity AUX Name PDR can only has a single
name. This patch reduces the memory footprint
of the Entity AUX Name PDRs.
