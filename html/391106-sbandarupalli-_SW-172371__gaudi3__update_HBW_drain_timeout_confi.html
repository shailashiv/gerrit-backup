[SW-172371] gaudi3: update HBW drain timeout config

As per arch team estimated max HBW latency is ~2500 nsec. Taking margin of
10x it is ~25,000 nsec.
The PLL clock is 1GHz (25,000 = 0x61A8 clock cycles)
so modify currently configured value of 0x1000 clock cycles with 0x8000.
