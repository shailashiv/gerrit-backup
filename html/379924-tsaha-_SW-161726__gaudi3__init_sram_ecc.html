Commit Message

[SW-161726] gaudi3: init sram ecc

SRAM self repair procedure is overwriting the ecc data of
the SRAM, so after running the self repair the sram memory
must be initialized. This patch initializes the ECC data by
writing the whole SRAM address space using the mem_cpy engine.
