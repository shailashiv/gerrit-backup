Commit Message

[SW-69581] boot_desc: add init image desc from bootinfo

So far the image descriptors were read directly from the flash.
In gaudi3 the bootrom is reading and validating the image
descriptors, and stores them in the bootinfo after validation.
For security concerns, ppboot should use the already validated
descriptors stored in the bootinfo.
In order to use the same boot desc functionality and APIs,
for each platform the relevant boot_desc_init() functionality
is executed and the data is stored in the same structures.
