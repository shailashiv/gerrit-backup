Commit Message

[SW-228131]: improved pre-kernel exception handling

Current pre-kernel exception handling relies on thread name. But kernel
provides an api k_is_pre_kernel. This patch
- replaces the earlier code that used thread name to identify
pre-kernel handling and uses this kernel api k_is_pre_kernel
- changes severity of logs to warning if in pre-kernel
