[SW-36011] fit: adding offset setter/getter

When added the ELBI/SPSRAM secured data transfer. The
offset is not constant any more. In the initial implementation
it was using a global variable directly. This patch
wraps the access with getter/setter, allowing checking and sync if
needed.
