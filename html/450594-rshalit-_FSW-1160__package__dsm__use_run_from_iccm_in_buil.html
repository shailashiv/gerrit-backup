[FSW-1160] package: dsm: use run_from_iccm in build

Running dsm from ICCM is convenient in palladium, but
with the general flow from flash it will not run from ICCM.
Hence, for running from ICCM it we use variable in build:

make fs1_arc-pldm-prepare;make dsm-dirclean dsm-rebuild;
make fs1-pldm-build DSM_RUN_FROM_ICCM=true
