[SW-140835] sec: gaudi2: mode based dynamic image sram opening

This patch aligns erom and preboot based on the following patch:
https://gerrit.habana-labs.com/#/c/197942/

This patch add support to open sram image region based on the
access mode requested. In gaudi2, RO and RW modes can be supported.
