Commit Message

[SW-28013] module: pci: adding iatu initialization

Before, the pci address translation unit was configured by LKD,
from now on the iATU initialization is carried out by FW.

Testing showed that for some devices (ie Gaudi) the iATU must be
initialized after the pci memory access is enabled.
The pci module is monitoring the pci memory access bit, and when it's
enabled the regions of iatu are configured.

A flag bit is set in the status register to signal the LKD driver
that the fw is taking care of the iATU initialization.
This is done in an early stage (ppboot) so it would be set before
the LKD driver is reading it.
