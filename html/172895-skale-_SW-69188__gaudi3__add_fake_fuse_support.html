Commit Message

[SW-69188] gaudi3: add fake fuse support

In order to verify ROM flow based on fuse values on pre-production
system, this patch add fake/local fuse support in ROM for gaudi3.

ROM will enable fake/local fuse based on efuse bit and bootstrap bit
dedicated for efuse override. Upon fake/local fuse enabled, ROM
will read fuse values from SPI flash.
