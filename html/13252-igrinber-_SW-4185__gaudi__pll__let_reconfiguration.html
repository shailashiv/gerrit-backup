Commit Message

[SW-4185] gaudi: pll: let reconfiguration

The CPU and PCI PLLs are configured in BTL in a "gated" manner to W/A
the PLL clock switch glitch. Therefore these PLLs should not be
reconfigured in preboot.
All other PLLs can be reconfigured, so let their (re)configuration.
