[SW-11180] preboot: boot_desc: fix update pending

Commit:
f5acb4d ("[SW-11180] preboot: boot_desc: update pending reg")
added updating the "updated pending register", but forgot to take into
an account the actual updated pending status.
This resulted in setting the "update pending register" each boot and
executing the U-Boot "post reset" command.
The "update pending register" must be updated only in case there was
actually an update pending... Conform to this.
