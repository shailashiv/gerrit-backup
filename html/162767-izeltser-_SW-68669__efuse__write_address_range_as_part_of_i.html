[SW-68669] efuse: write address range as part of init

Components that are executing before preboot/ppboot might change the
default address range of the efuse reading.
In order to assure that all the addresses being fetched during the
efuse read command, the default address range should be restored
prior to the read command execution.

The default range value of 0x3F80 is suitable for all the current
platforms that are using efuse (H3, H5, H6)
