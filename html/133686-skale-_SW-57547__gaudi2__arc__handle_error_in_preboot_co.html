Commit Message

[SW-57547] gaudi2: arc: handle error in preboot copy

Currently if preboot dma from SPI to SRAM or verification of preboot
binary is failed, valid loadaddr is sent along with success as part
of ppboot_load_preboot_img function. This patch add support to return
false if preboot image dma or verification is failed which will initiate
recovery flow instead of starting preboot image.
