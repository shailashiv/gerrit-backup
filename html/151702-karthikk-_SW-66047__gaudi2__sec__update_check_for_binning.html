[SW-66047] gaudi2: sec: update check for binning

Currently binning information is received through LKD. Ideally in a
secured setup this should be ignored, instead values would be read
from efuse.

But this precondition check would fail if efuse is not burned with
binning values and security is enabled.

Hence this 'revert me' patch is required to disable this check.
