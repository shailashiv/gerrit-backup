Commit Message

[SW-86866] gaudi3: update udelay routine to use psoc ts

Currently, udelay logic make use of fixed cpu frequency and runs nops
based on the delays requested. However there is possibility that
ARC may run in different frequencies and will impact delay behaviour.
This patch changes udelay logic to make use of psoc timestamp for
delay calculation.

+void udelay(unsigned int usec)
+{
+	uint64_t start, current, end = cycles_per_usec * usec;
+	bool overlap = false;
+
+	start = udelay_get_ts();
+	end += start;
+
+	if (end < start)
+		overlap = true;
+
+	while (1) {
+		current = udelay_get_ts();
+		if (!overlap) {
+			/* Check also for unplanned overlap */
+			if (current > end || current <= start)
+				break;
+		} else {
+			if (current > end && current < start)

+		}
