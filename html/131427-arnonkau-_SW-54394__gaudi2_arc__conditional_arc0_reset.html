Commit Message

[SW-54394] gaudi2,arc: conditional arc0 reset

When running the preboot directly without arc cores initialization
the iccm and dccm associated with those cores are not accessible.

That is usually handled by the ppboot. but this weak function allows
adjustments when the preboot starts. In this case allows running
the preboot without pre-loading the ppboot.

The operation invoked only if the arc0 is not running yet.
