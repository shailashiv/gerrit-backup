Commit Message

[SW-14252] preboot: goya2: load multiple fit images

Currently for goya2 ARC based target, boot FIT contains only uboot
image which is loaded on ARM by preboot running on ARC1. From now on,
boot FIT will contain zephyr images along with uboot which needs to be
loaded on ARC0 and ARC1.

This patch adds support in preboot to load multiple images available
in boot FIT.
