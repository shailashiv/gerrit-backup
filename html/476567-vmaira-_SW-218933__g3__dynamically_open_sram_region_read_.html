Commit Message

[SW-218933] g3: dynamically open sram region read only perm

When the host requests the proto status, the device allocates memory in
SRAM, dynamically opens the region with read-write (RW) permission, and
places the proto status response (FW version) there for the host to read.
The region is then closed when the host sends the `rst_state` command.
However, if the host fails to send the `rst_state` command, a portion of
the SRAM region remains accessible with RW permission, posing a security
risk.

To mitigate this, this patch modifies the code to open the SRAM region
with read-only (RO) permission instead of RW, ensuring that the host can
read the proto response without unintended write access.
