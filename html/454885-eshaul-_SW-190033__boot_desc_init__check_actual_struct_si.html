Commit Message

[SW-190033] boot_desc_init: check actual struct size

hl_fw_boot_ptrs now includes new fields of version & size.
With this information we can detect special cases in which the flash
content is more updated than the firmware that is running.
Is such cases, if we detect that the actual size is bigger, and we
are going to lose the struct tail we will warn, but continue to use
the fields that the firmware knows.
