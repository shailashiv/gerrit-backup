[SW-103768] gaudi2: sram bist: refactor implementation flow

This patch refactors the sram bist implementation. Earlier
the flow was to run BIRA for all rings, then BISR for all rings
and finally to run BIST for all rings.

Now it is modified to run loop over all rings to run BIRA, BISR
and BIST in sequence for a partciular ring.

This will be extended further to skip running BISR and BIST
for a particular ring of BIRA is OK.
