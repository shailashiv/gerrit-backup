Commit Message

Revert "Revert "[SW-43635] lkd: remove legacy protocol""

This reverts commit 4113fdd624143b412cc14f59a04952eafb0fb53e.

Recently we moved from LKD protocol to COMMS
protocol. Therefore, it is not required any more to
use the legacy protocol, because host is using
COMMS protocol. We had to remove original patch
(44fa70ae7218950d0acb1e65cc105bdea89859c3) which removed the
legacy flow code due to issue on Greco. With dynamic fw loading
enabled in FW and latest LKD, linux boot looks OK now on Greco.
So reverted the revert patch to remove the legacy LKD protocol code.
