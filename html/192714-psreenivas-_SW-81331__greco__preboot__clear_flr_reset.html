Commit Message

[SW-81331] greco: preboot: clear flr reset

If FLR interrupt is received while FLR is handled by FW, FW issues
FLR reset by setting pcie2psoc bit PCIE_AUX_FLR_CTRL register. However
this bit is not self clear. This patch adds support to clear pcie2psoc bit
as part of preboot init sequence.

+static void clr_flr_reset(void)
+{
+	u32 val;
+
+	/*
+	 * If FLR reset is issued by FW, the reset
+	 * needs to be cleared by FW as the bit is not
+	 * self clear.
+	 */
+	val = regmap_readl(mmPCIE_AUX_FLR_CTRL);
+	val &= ~(PCIE_AUX_FLR_CTRL_FSM_PCIE2PSOC_RST_SET_MASK);
+	regmap_writel(val, mmPCIE_AUX_FLR_CTRL);
+}
+
+void preboot_reset_init(void)
+{
+	clr_flr_reset();
