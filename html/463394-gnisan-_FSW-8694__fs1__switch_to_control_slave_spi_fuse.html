[FSW-8694] fs1: switch to control slave spi fuse

Fake fuse boot pointer doesnt use key index
because of no security key usage in fake fuse.
Hence, key index flag will be used to control
slave fake fuse initialization. If it is set
255, master will not write slave fake fuse
values on slave scratchpad register.
