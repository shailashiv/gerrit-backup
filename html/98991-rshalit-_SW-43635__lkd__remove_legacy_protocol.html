Commit Message

[SW-43635] lkd: remove legacy protocol

Recently we moved from LKD protocol to COMMS
protocol. Therefore, is not required any more to
use the legacy protocol, because host is using
COMMS protocol.
This patch removes the legacy protocol
code. In case of identifying old legacy protocol,
an error print is displayed. In addition, dynamic
security, which opens sram space for image is not
required any more, because it was required only
with the legacy protocol, and therefore it is removed.
