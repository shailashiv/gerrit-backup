Commit Message

[SW-20141] gaudi: (re)enable the pcie access

During the new reset sequence, we disable the PCIe access before the
hard reset and we should reenable it after the reset has been performed.
Meaning we do this only if the PCIe link is already up.
Enable the PCIe access after reset.
