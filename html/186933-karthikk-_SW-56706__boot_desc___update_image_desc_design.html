Commit Message

[SW-56706] boot_desc : update image desc design

Update the image descriptor as per new design.

This patch implements usage of the new fields
1) boot_ptrs_img_sz : Size of the complete image(boot desc header ,
image descriptors, public key, signature, CRC) present at offset
0x60000 of spi. This should be used for dma.
2) offset2array: instead of hardcoded location for offset2array, this
would provide us the flexibility to extend boot info header in future.

The is in preparation to port boot info onto sram, and then use the
new fields.
