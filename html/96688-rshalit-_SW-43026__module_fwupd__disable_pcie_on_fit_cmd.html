[SW-43026] module_fwupd: disable pcie on fit cmd

PCIe disabling mechanism is using a fit as a command for
device to close any check on fw_upd module and to stop
any further process of fw_upd module if given through pcie.
This is used as protection and security mechanism in order to
guarantee that fw_upd is disabled to pcie after the command
is received and will remain close till power cycle of device.
This fit is received using ELBI interface.
A next patch will save the information in boot_info and
also check boot_info on starting preboot, in order to
keep the closure between sw reset and PRSTN reset.
A later patch shall also use the state's flag in order
to disable access fw_udp from pcie.
