Commit Message

[SW-0] rom: recovery mode detection update

GPIO_76 is used by master die to indicate recovery to slave die.
There is a dedicated "recovery" mode indication bit in
PSOC_GLOBAL_CONF that can be used for this purpose(as per design
team's suggestion). This method replaces an inter die read with a
self die read on slave die, which results in a faster read
transaction.
