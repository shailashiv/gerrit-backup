Commit Message

[SW-146646] gaudi3: skip hash verification based on sim mode

Currently, the asic target is used to run FW flow on simulator. There
are certain configurations such as d2d and HBM trainings which needs
to be skipped on simulator. Also to speed up the boot flow certain
time consuming operations such as hash verification of images needs
to be skipped.

This patch add changes to skip preboot hash verification based on
SIM_MODE fuse bit.
