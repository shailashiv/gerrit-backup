[SW-6739] arcboot: libsb: use rsa fixed

To improve execution speed of the signature verification
we are using now fixed exponent to speed up decryption of
the signature.

The fixed exponent has pre-calculated tables to speed up decryption,
this comes at the cost of allowing key sizes in 64bit increment instead
of 8bit increment with standard rsa. as we only use 3072bit keys this
has no effect expect speeding up the decryption of the signature.

16KB data on pldm with hashing of data blob -
rsa_standard: 37 mintues
rsa_fixed: 3 mintues
