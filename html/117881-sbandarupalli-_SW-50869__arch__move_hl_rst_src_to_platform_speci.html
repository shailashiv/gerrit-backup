Commit Message

[SW-50869] arch: move hl_rst_src to platform specific headers

Gaudi1 and Greco has common bit definitions in PSOC_GLOBAL_CONF_RST_SRC
register for reset cause. But in Gaudi2 reset cause bit definitions are
modified and not backward compatible.

Moved hl_rst_src from common include header to platform specific header
files. Gadui2 specific enum changes will be done later
