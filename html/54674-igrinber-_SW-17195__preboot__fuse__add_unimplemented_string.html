Commit Message

[SW-17195] preboot: fuse: add unimplemented string

On Goya1/2 and later SoCs, the eFuse version reading is still
unimplemented and prints "unknown" string which is misleading and
makes people think there is an eFuse reading problem.
Add "not implemented" string to the "weak" implementation, so it will
be clear this is not a problem of reading eFuse.
