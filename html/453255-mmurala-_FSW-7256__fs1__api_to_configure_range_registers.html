[FSW-7256] fs1: api to configure range registers

With this patch, added support to enable range
register to particular ip by sending rr context
type of ip and access type. All ip block base
addresses are stored in array and retrieved based
on request. Context data provides the min and max
address range of window which is going to get
access.
