Commit Message

[SW-25565] ppboot: validate image size

We cannot allow large foot print of ppboot as it will increase timing
for BTL to copy into SRAM and by that will japrodize PCIe link
establishment due to breaking 20mS time limit of PRSTn.
goya2_arc_gnu does not have ppboot, therefore validation of size
limitation is not applied with this target.
