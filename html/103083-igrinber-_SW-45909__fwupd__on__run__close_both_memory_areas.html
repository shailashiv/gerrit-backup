Commit Message

[SW-45909] fwupd: on "run" close both memory areas

Current code executes FIT according to data received in MAP, but toggles
the security closure according to the RUN command. This enables a
MAP_SRAM -> RUN_SPSRAM attack surface when SRAM is written, but SPSRAM
is closed during validation.
When receiving HL_UPD_RUN_*SRAM command, close both memory areas to
prevent MAP_SRAM -> RUN_SPSRAM attack surface.
