[SW-9837] i2cslave: fix reading block of integers

i2cget is an i2c transaction os type read, therefore a
byte from the command requests is retreived, which means
that 5 bytes (+4 bytes in the for loop) were read
while the comman requested (171) supportes only 4 bytes
of data, this commit sets the command by using i2cset
and then requests 4 bytes of data using i2cget.
