Commit Message

[SW-44814] pci: reading mem enable status from aux block

So far the memory access enable status was read (polled) from the
PCIE_DBI block register. Testing shows that if this register is
being read during pci link transition it can cause a cpu freeze.
To avoid this, the memory access enable status is being polled
from the PCIE_AUX block register PCIE_AUX_MEM_SPACE_EN.
