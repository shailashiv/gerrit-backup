Commit Message

[SW-56241] boot_info: restore back to sha256

Recently sha384 was added for gaudi2. As part of the modifications
for sha384, boot_info record in header was increased in size from 32
to 48, as if to adjust to be gaudi2 and and gaudi1. Yet, this
introduced backward compatibility issue, because reading of older
flash layout will not work correctly. This patch restore sha256
with boot_info (for both persistant and non-persistant).
