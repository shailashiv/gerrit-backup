[SW-13299] hl: i2c-slave: remove interrupt mask

Remove interrupt mask in i2c-slave initialization.
The i2c-slave device can operate in 2 modes:
Operational mode (in which device is configured as address 0x4f)
and debug mode (in which device is configured as address 0x47).
On reset, it boots with default interruot mask, but then in previous
patch in preboot, the interrupt mask was modified to allow all
interrupts. It sometimes resulted in non responsive device.
So, in this patch we are using the default mask interrupt for
the i2c-slave device (both in debug and in operational modes).
