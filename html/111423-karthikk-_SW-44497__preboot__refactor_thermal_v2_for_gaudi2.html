Commit Message

[SW-44497] preboot: refactor thermal_v2 for gaudi2

Currently thermal_v2 is compiled only for greco, which is to be
supported for gaudi2 also.

This patch removes greco specific header files currently in thermal_v2
and moves hl_ts_reset() to platform specific code as it is not common
between greco and gaudi2.

This is in preparation to support ts functionality in gaudi2.
