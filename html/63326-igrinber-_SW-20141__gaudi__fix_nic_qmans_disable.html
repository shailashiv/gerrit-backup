[SW-20141] gaudi: fix nic qmans disable

The gaudi_disable_nic_qmans() function was ported from Linux, but
Preboot takes registers (and bases) defines from specs, so the base is
a full 39 bit physical page address. So when the function adds an offset
to the mmNIC0_QM0_BASE value, it actually changes the lower 32 bits, but
overflows... This results in incorrect address access and stalls the
SoC.
Fix this by clearing the upper bits which correspond to the CFG base of
the chip.
