[SW-93113] hl: preboot: fix out of bound write issue in crc8 library

This patch fixes an issue pointed by synopsis static analysis tool by
avoiding an out of bound write to table array in crc8_populate_msb
by using a modulo operator to make sure the writes to this array are
within the array length limits.

"47755 Out-of-bounds write
This could cause an immediate crash or incorrect computations.
In crc8_populate_msb: Out-of-bounds write to a buffer (CWE-119)"
