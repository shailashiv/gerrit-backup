Commit Message

[SW-28697] lkd: implement the comms protocol

The new comms protocol is based on the hl-fw-loader update base protocol
with slightly updated building blocks as a base for communication.
It implements LKD communication specific high level commands and
supplies generic statuses.
Preboot implementation of the protocol is required to separate the
execution process to "fast" and "slow" in a way that busy-wait loops
must be avoided. This limitation forces the implementation to keep the
communication states in between the execution stages.
The protocol is implemented in a way that all the communication is done
using the "fast" response and thus does not interfere with the I2C slave
sensitive response time.
To achieve that kind of separation (fast vs. slow), the processing of
the data is done after the communication phase is finished, so the
processing can take the relevant path (e.g. slow).
