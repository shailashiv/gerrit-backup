[SW-99461] gaudi3: add persist section in rom

Boot info infrastructure is introduced in gaudi3 ROM. It is
the first platform to use this infrastructure in ROM code.
As a general practice, as the code would be frozen, a
contingency flow should be in place.

Boot info is currenlty used in ROM boot flow to read ppboot,
tpm and fake fuse image descriptors. Hence as a contingency
plan these image descriptors and relavent data needs to be
stored in an alternate memory which is persistent in nature,
as re-dma of the image descriptors is done in cold-reset and
fw update, all the other resets need to re-use the stored
data.

Hence we store the arcboot_rom_global data structure in the
initial 3KB of DCCM. This memory region would be carved out
such that it would persist through out the boot flow.
