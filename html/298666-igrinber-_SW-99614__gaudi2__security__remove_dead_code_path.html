Commit Message

[SW-99614] gaudi2: security: remove dead code path

Functions hl_secure_lbw_rr(), hl_secure_hbw_rr(), and
hl_secure_hbw_common() have paths that are never executed in Ppboot and
cannot be garbage collected, so they are compiled with dead code inside.
Remove usage of those function in Ppboot by using hl_secure_lbw_rr_gen()
and hl_secure_hbw_pcie_rr() functions directly.
This removes the dead code paths for Ppboot.
