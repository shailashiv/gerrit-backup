[FSW-9512] fs1: separate pre-init constants

Persistent DCCM(P-DCCM) will be used by different
variables which are 3 types.
1. Variables which hold 0 by default, Those
doesnt has any issue because P-DCCM will be
written with 0 by BOOTROM during cold reset.
2. Variables which hold constant other than 0,
and which never modified in run time. This
values can be initialized in any reset.
3. Variables which hold pre-init values, and
those are modified during run time and required
for next non-cold reset. This values need to
initialize only in cold reset.
