Commit Message

[FSW-4077] fs1: efuse: verify volt protection pattern

Low voltage attacks on device can cause all efuse bits to
be read zero disabling secuirity for entire device. To
validate if efuse values are read correctly, config fuse
value has voltage protection pattern of '1010'. This patch
validates said pattern and if valid pattern is not found
bootrom goes in halt.
