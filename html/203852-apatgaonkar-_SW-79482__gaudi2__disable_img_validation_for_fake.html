Commit Message

[SW-79482] gaudi2: disable img validation for fake unsecurity

To support RMA debug in production, firmware needs support of
disabling security and image validation across the flow. In
case of ppboot validating preboot, it uses arcboot rom exported
functions to verify the image. For fake unsecurity, ppboot
should skip image validation completely.
