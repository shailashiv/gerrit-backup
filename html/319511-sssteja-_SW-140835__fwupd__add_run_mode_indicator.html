[SW-140835] fwupd: add run mode indicator

This patch aligns erom and preboot on the patch below:
https://gerrit.habana-labs.com/#/c/257047/

The current running mode, needs to be available, to the module_fwupd's
state machine. Allowing decision making according to running mode,
such as FAST, SLOW and NO_RET.

There are operations that shouldn't be executed in FAST mode, but only
in SLOW mode.

The original scenario was observed on a secured machine and a corrupted
FIT image. The FW rejected the update request as it was aware of the FIT
error.

The acknowledge appears immediately on the FW console. But the FWL
didn't receive any indication.

It appears that the fit error happens always when the preboot is in
"fast" mode. Moving to "slow" mode didn't triggered the delayed work of
sending the SRAM_RUN error status FIT.

The cause as mentioned above was not using the right indication while in
"slow" mode to build the error message.
