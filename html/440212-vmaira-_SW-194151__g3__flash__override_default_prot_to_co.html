[SW-194151] g3: flash: override default prot to cover only 128kB

Default PROT_MASK protects all the four flash blocks by default
in the common spi flash driver in ppboot. This patch overrides
the default PROT_MASK for gaudi3 to protect only 128KB of the
flash space where recovery image resides.
