Revert "[SW-39285] gaudi: security: gic privilege en bit"

This reverts commit b7f1769a2fe1aa13e3ca5fb4694bb9ac8ea0b93b.

This revert is done as the "gic privilege enable" status bit
is now set in ARMCP, Linux(constituents of gaudi-fit.itb). ARMCP
contains the implementation of irq polling mechanism.
So its better to keep the status bit enable code in the relevant
components to avoid version mismatch.
