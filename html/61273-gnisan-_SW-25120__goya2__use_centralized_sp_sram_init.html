[SW-25120] goya2: use centralized sp sram init

SP SRAM is initialized in cenralized way on init flow. This is then
initializing it during FIT copy. This way the code is aligned with the
rest of the archs. And there is less time waist since initialization is
done before the wait for a new FIT.
