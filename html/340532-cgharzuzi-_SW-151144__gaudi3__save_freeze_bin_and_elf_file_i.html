[SW-151144] gaudi3: save freeze bin and elf file in project git

The Gaudi3 freeze images should be saved in the project .git
to be used in CI/CD + developement, using the images
built from master is a problematic scenario in case
the images are changed due to build tools changes,
like updating the build toolchain for example.

the frozen binary files are built using the snsp 2019.09 Arc toolchain.
the easiest way to create them is to rebuild arcboot from the v1.11.0
branch.
