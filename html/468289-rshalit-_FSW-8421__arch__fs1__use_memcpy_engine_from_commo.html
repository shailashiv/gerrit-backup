[FSW-8421] arch: fs1: use memcpy engine from common lib

No need for baremetal implementation of copy-engine,
as it is already implemented in common library.
Also, the common library implementation is more
complete as it also has a substitute as regular
memcpy instead this feature is not supported (as
for today it is not yet supported in coral)
