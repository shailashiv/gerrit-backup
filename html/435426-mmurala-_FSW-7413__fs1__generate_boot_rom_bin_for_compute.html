Commit Message

[FSW-7413] fs1: generate boot rom bin for compute

With this patch, added support to generate boot
rom binary for compute die, the only difference
between io and compute boot rom binary is a four
byte constant memory section that has some unique
value for io and compute. remaining complete
binary should be the same. The reason for this
change is to avoid risk if someone modify
die id's intentionally, hence we can avoid
compute die running io bootrom.
