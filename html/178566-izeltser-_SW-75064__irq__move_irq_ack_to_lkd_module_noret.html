Commit Message

[SW-75064] irq: move irq ack to lkd module noret

So far the IRQ ack function call was in uart module teardown, but it
has very little to do with the uart module.
Since those IRQs are mostly relevant for the FW loaded by the LKD,
this function call is moved to the cleanup phase of the LKD module,
prior to running the FW image.
