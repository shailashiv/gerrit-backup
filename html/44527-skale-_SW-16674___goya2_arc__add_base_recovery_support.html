Commit Message

[SW-16674]: goya2_arc: add base recovery support

In goya2 arc based flow, arcboot loads recovery image in case of
primary and secondary image load or verification failed.

recovery image is responsible to support set of NVMe MI commands which
also include firmware update (modify SPI flash). Since recovery image
can re-use some of i2c based infrastructure from preboot, its
implemented as part of preboot git.

This patch adds base support for recovery image.
