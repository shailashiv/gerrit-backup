Commit Message

[SW-227587] g2: nic: add timer for solving nic_sts_event problem

OAM sends NIC STS events to LKD immediately after receiving PCIe
enable event from LKD. But because callback that responsible for sending
ack to NIC STS event is part of dependent driver, the ack is not sent.
Adding watch-dog timer per NIC STS event with timeout 10 seconds enable
to repeat the loop with sending NIC STS events to LKD. At this time
dependent driver already loaded and its callback sends ack as required
