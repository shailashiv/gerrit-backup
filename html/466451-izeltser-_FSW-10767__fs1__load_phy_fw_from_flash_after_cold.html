Commit Message

[FSW-10767] fs1: load phy fw from flash after cold boot

PCIE Phy FW should be loaded from flash to PCIE Sram only after cold
boot or manual reset. Other reset sources do not affect the PCIE Sram
memory content so copying the PHY FW again is a waste of time.
