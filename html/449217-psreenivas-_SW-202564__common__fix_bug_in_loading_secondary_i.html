Commit Message

[SW-202564] common: fix bug in loading secondary image

If the dma copy of preboot primary image fails, the ppboot
is not trying to load secondary image as the status of
dma is not returned from ppboot_cp_preboot. This patch
fixes this by returning the status of dma copy.
