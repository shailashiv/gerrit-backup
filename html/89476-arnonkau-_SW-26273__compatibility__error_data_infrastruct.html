Commit Message

[SW-26273] compatibility: error data infrastruct

As part of compatibility, the firmware error indications should be send
out as a FWUPD FIT response.
It should be meaningful, and more descriptive.

Due to responding back with a fit, a SLOW MODE is required to prevent
starvation of the time sensitive modules (e.g. I2C).

NOTE: Till all functionality will step in, the slow/fast state is
disabled
