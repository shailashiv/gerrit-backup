[SW-76678] gaudi3: add iatu configuration

In gaudi3, there is alternate method provided to configure
address transalation using BMU (BAR Mapping Unit). This patch
perform IATU configuration for following region using BMU
1. CFG Region 256MB
2. FW SRAM region 256MB
3. FW MEM region 256MB
