Commit Message

[SW-85036] rom: fix efuse read address setting

Efuse read address is currenlty configured only on cold reset as the
efuse re-initialization is done based on cold reset flops.

Due to this, in other resets(except cold) the value read by rom for
mmEFUSE_READ_ADDRESS is not the soconline default value as boot manager
updates the same, which effectively shortens the efuse read ability
from firmware.

This patch fixes this by decoupling mmEFUSE_READ_ADDRESS configuration
from cold reset flops flag.
