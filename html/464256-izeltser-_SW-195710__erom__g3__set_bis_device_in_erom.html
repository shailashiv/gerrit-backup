[SW-195710] erom: g3: set bis device in erom

In Gaudi3 (unlike G2) EROM is not disabled in BIS mode, so it should
be able to identify BIS mode and set the PCI revision respectively.

To maintain platform specific functionality in Erom an erom.c module
is added to all platforms. At the moment only gaudi2 erom.c has content,
for the other platforms the erom.c is a place holder for future
erom specific platform specific code.
