Commit Message

[SW-172027] gaudi2: security: modify svn version check

Due to bug in arcboot rom, firmware svn version one less than
the efuse svn version was allowed to boot, ex: if efuse svn = 7,
firmware svn 6 was allowed to boot. To fix this it is decided
to program an additional efuse bit in SVN. i,e. if SVN 7 then efuse
bits 0 to 7 are programmed (0xFF). This patch adds support to decrement
svn version read from efuse by 1.
