Commit Message

[SW-0] pll: fix the CPU PLL config condition

The hl_pll_is_bypass() semantics are to return the bypass value and
not the true or false, as opposed to its name which is thus misleading.

Fix the CPU PLL bypass check bug, resulted from the ambiguity of the
hl_pll_is_bypass() function name.
Change the function name from hl_pll_is_bypass() to hl_pll_bypass_get()
thus resolving the ambiguity.

Fixes c33fdb4 ([SW-0] pll: configure CPU PLL only if in bypass).
