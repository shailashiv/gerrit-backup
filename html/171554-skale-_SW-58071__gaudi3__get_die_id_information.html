[SW-58071] gaudi3: get die id information

Gaudi3 has two die support and bootrom code will run on both die.
However the bootrom flow will differ based on which die its running.
In order to identify which die code is running, the patch add support
to read die id from register. Note that die id 0 will be always
master die.
