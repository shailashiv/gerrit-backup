Commit Message

[SW-166459] gaudi3: print cpu pll freq

CPU PLL (PCI pll div0) is configured by HW depending on the efuse
values.
In order to prevent confusion during gaudi3 PO because of wrong efuse
configuration, CPU PLL frequency is printed to UART, and if the
configuration differs from nominal an additional warning is printed.
