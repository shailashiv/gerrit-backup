greco targets(i.e. arm, arc and arc_elf32). In this
patch many functions common in greco/arm and greco_arc_elf32
implementations are moved to common/common.c.

As preboot_disable_pcie_ltr() needs to be non-static to have common
implementation, relevant change required in relevant gaudi, gaudi2
files too.
