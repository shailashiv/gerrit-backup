Commit Message

[SW-49907] gaudi: ras: fix btl index

Fix BTL index reading for RAS, as the BTL ID is
in LSB byte, not MSB. Later, in u-boot it is shifted
8 bytes left, which explains why in Linux we retrieve
BTL index from MSB byte.
