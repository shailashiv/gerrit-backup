[SW-145263] h6: sec: read keys from rom/efuse

"FAKE Security keys" offset from flash. But in Gaudi2 as per
efuse bit nap, keys can be read only from ROM or efuse

Code change are done to read keys from ROM or EFUSE even if
fake security is enabled
