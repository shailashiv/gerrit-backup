Commit Message

[JSW-704] jgs: address space update

With this patch, updated firmware memory filter
api as per new address space.
Removed support to filter 32bit address because
it may wrongly filterout input address when
address space changes and to make it more
accurate.
Updated arc address conversion macro, since
fw mem sizes changed from fs1 and existing
macro not working for new address space.
