Commit Message

[FSW-6580] fs1: report failures in lfs wrapper

With this patch, added support to report failures
using software status bits. Especially this
failure bits added for present bootrom using
api's, those are lfs disk mount, open file
config, file read and write.
Failure report hierarchy is as follows, lfs
disk mount, open file config, partial set or
copy.
