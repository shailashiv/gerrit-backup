[SW-0] ppboot: add dev specific log of pcie wait

Add ability to print a log of the PCIe link waiting fact.
It is done in device specific manner, so each device can obey its
restrictions.
For example Goya is very sensitive to the PCIe link enablement timing,
so keep it clear - no log.
Others, add currently a minimalistic log of 3 characters: 5, LF, CR.
