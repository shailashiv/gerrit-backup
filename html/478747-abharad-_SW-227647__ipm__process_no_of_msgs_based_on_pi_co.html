Commit Message

[SW-227647] ipm: process no of msgs based on pi count

Current ISR implementation only processes one msg at a time. This patch
improves this by processing (pi-ci) msgs. This ensures that if there
are more than one interrupts sent and one of it is missed, ISR can
still process all the pending msgs.
