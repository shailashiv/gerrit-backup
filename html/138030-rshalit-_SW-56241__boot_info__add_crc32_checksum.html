Commit Message

[SW-56241] boot_info: add crc32 checksum

Add crc32 in hl_boot_info_desc struct.
In addition, a version represent the checksum
algo and the checksum data in struct, i.e.
version #0 is for sha256 with checksum field in
struct, and version #1 is for crc32 with crc32 field
in struct (version number is set in zephyr config).
This design is more generic then code dependent,
and was proposed by IgorG.
