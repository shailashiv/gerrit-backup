[SW-0] gaudi2: fix halt read status for arc

Currently as part of preboot where ARC0 is halted and reset
conditionally, the arc status is not read correctly instead register
offset is used to check status of ARC0. This patch add fix to read
register value using offset and check status of ARC0.
