Commit Message

[SW-17415] gaudi: remove ltssm_en write

It was decided (designers and validation) that Gaudi's LTSSM_EN should
stay at value 0x3 (In Detect and Mask) and not overridden to 0x1 (In
Detect).
Remove the write to LTSSM_EN to keep it at previous value.
We do this in a device specific manner, so other devices will be kept
intact.
