Commit Message

[SW-86607] gaudi3: spi: use spi dma for copying preboot

So far the preboot image was copied from flash by a SW loop.
Now the bootrom code had reached maturity, and it has
implementation for SPI DMA functionality.
This patch switches to using the SPI DMA function from the
bootrom code for copying the preboot image from flash.
