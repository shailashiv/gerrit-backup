Commit Message

[SW-99614] gaudi2: security: refactor rrs usage

Refactor static definitions of RRs for both LBW and HBW to enable better
garbage collection during FW components compilation (linkage).
To make this possible split the static arrays to single per type
definitions and update functions using the arrays to use the new
definitions.
This allows garbage collector to remove the dead code from Gaudi2 ppboot
and eROM PCIe. The removal from each component saves approx. 260 bytes,
otherwise occupied by dead code.
