[SW-37341] gaudi2: arc: support for dma above 64k

The SPI dma used to copy ppboot and preboot images in secureboot
flow supports upto size of 64KB only. Currently, dma logic used
to copy preboot image assumes preboot image less than 64KB. To
support growing preboot size, this patch add support to perform
dma of preboot above 64KB.

Approach:
===========

In Buildroot-external:
----------------------
MAX_DMA_SIZE=64KB-16
if image_size > (MAX_DMA_SIZE + CRC),
payload_size = image_size - 2*CRC
split flash binary to
bin1: MAX_DMA_SIZE + CRC @flash offs 0x0
bin2: (payload_size - MAX_DMA_SIZE) + CRC @flash offs 0x10000

In preboot:
-----------
image_size = payload_size + (2*4)
below logic when image_size > (MAX_DMA_SIZE + CRC)
copy first chunk (size1 =MAX_DMA_SIZE + CRC) from flash offs_0 to
SRAM at offs_0.
copy second chunk (size2 = payload_size - MAX_DMA_SIZE + CRC) from
flash offs_0x10000 to ICCM at offs_0.
later memcpy from ICCM_offs_0 to SRAM_offs_MAX_DMA_SIZE

Example:
--------
1)MAX_DMA_SIZE --> MAX_DMA_SIZE + CRC --> only 1 chunk
2)MAX_DMA_SIZE+4 --> (MAX_DMA_SIZE + CRC), (4 + CRC) --> 2 chunks
