[SW-32519] i2c_slave: fix module disable

The i2c disable procedure was not working properly.
And the i2c bus stopped responding. (i2cdetect could not see info)

By adding delay and toggling the psoc i2c enable. as the i2c teardown
function is doing. The issue was fixed.
