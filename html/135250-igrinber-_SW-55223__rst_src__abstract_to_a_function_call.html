[SW-55223] rst_src: abstract to a function call

For Gaudi2 reset source, we cannot just simply read the reset source
register, as we have an erratum that this register cannot be cleared and
therefore it accumulated the reset bits.
So the reset source cannot be simply tracked by reading the register.
Instead, we need to implement an algorithm of some kind to track the
reset sources.
Introduce an API for reading the reset source which will allow us to
implement a more complicated algorithm for Gaudi2.
It will be sensible to make a weak function for anyone aligned to the
register, but we simply do not have yet a common place for all devices
and all components (e.g. ppboot, preboot), and this weak functionality
is too small to deserve a file of its own.
Thus implement for all devices.
