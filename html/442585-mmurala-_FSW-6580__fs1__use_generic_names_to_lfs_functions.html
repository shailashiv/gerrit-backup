Commit Message

[FSW-6580] fs1: use generic names to lfs functions

With this patch, used generic names to all lfs
functions instead of boot info naming, because
lfs file operations are not only for boot info
and also used for all types of data and variable
storage.
Removed boot info type argument for file name,
so that any other enums can be used for
different type of file naming.
