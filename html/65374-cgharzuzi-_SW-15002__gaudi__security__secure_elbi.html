Commit Message

[SW-15002] gaudi: security: secure elbi

secure DBI registers but leave SNPS access open for LKD use.

After LKD is done, lock up DBI.

Since LKD will always attempt to configure access to iATU
razwi event will be triggered in secured systems and cleared
in the FW before u-boot is loaded.
