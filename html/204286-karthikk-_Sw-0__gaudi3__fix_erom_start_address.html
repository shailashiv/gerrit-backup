[Sw-0] gaudi3: fix erom start address

erom in gaudi3 is executed on iccm . This patch modifies
the start address to use internal addressing.

This is required as:
-> Internal addressing would improve the execution speed compared
to cbu i/f addressing.
-> An exception is observed when using cbu i/f addressing when
instruction cache is enabled.
