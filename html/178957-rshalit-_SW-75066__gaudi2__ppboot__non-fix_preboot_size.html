Commit Message

[SW-75066] gaudi2: ppboot: non-fix preboot size

Support preboot img size with any number of sectors, instead
of assuming that image size is less then 128KB, as it is
expected that preboot image size will get increased above 128KB.
The approach for copying from flash to sram, is similar to the
one done before, only that it uses a loop iteration according
to number of sectors, which is depends on image size,
(instead of assuming limited number of 1 or 2 sectors).
