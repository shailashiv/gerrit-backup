Commit Message

[SW-170792] gaudi3: pif: disable vpd capability

By default Vital Product Data (VPD) capability is enabled in PCIe
configuration space. This makes the host to send VPD requests which
by default are translated to unsupported transactions to the device,
which are translated to DMARs to HOST or LBW transactions to blocked
address of the device (depending on BMU configuration).
This capability is disabled.
