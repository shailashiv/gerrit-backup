Commit Message

[SW-20154] gaudi2: Fix for overlapping DCCM region

There is an overlap in the DCCM memory region
for arcboot ROM and ppboot.

Current ppboot DCCM starts at : 0x80002000
Current Arcboot ROM DCCM usage :
0x80002028 + 0x2000 (size) = 0x80004028.

The offset for ppboot has been updated to maintain
unique memory access range in DCCM memory.
