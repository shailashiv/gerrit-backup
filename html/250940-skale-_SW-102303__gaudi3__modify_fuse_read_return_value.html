Commit Message

[SW-102303] gaudi3: modify fuse read return value

Currently, fuse init return value is explicitly check to 0 else
ROM enters in halt state. if fuse init is already done (checked
by reading cold flops) fuse_init function returns -1 which will
cause rom to enter halt state. This patch change return value
to 0 in case fuse init is already done.
