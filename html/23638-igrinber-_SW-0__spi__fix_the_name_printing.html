[SW-0] spi: fix the name printing

The spi_copy() function receives a name string of the component it works
on, so it can print it to the console. This way we can differentiate
between the different spi_copy() function invocations.
While printing the name, it calls preboot_puts() function which does not
output the trailing EOL ('\n') character, but it does output the
trailing CR ('\r') character, so the next call to preboot_puts()
overwrites the actual name string.
Fix this by switching the preboot_puts() call to preboot_puts_raw() call
which does not output the trailing CR character.
