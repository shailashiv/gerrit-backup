Commit Message

[SW-166373] gaudi2: reset bist_skip_enable in non hard reset

It is observed that on some host prstn reset is asserted
followed by cold reset. If the firmware has already completed
the bist in cold reset and before issuing the hard reset if the
prstn is asserted will result in skipping of bist. This patch
adds addtional check for bist skip by checking the reset source
for sw_all_reset.
