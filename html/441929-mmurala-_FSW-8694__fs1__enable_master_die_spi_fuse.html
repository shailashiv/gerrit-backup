Commit Message

[FSW-8694] fs1: enable master die spi fuse

Efuse bit - fuse_override is used to enable spi
fuse feature, if this bit set spi fuse is disabled.
After voltage protection pattern verified from
actual efuse, boot rom will start enumerating
this spi fuse boot desc. Developer can use this
flexibility to create a fake fuse environment
from spi flash binary image for development and
to debug.
