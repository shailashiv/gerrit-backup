[SW-20154] preboot: extended rom support

Gaudi2 has a new SW component called extended rom,
which runs at the same time as ROM. There are 3
APIs that can be executed from ROM based on efuse
settings. Each of these API is a part of its own
individual binary.ROM code executes the erom
functions that are part of the extended rom residing
on flash. This patch adds basic support for the creation
of 3 new binaries called erom_pcie.bin, erom_recovery.bin
and erom_tpm.bin that can be built and generated
independent of the ROM.

efuse settings to trigger the erom APIs"
	1)erom_pcie-> efuse bit 13 (logic low)
	2)erom_recovery-> efuse bit 13 (logic low)
	3)erom_tpm-> efuse bit 11 (logic high)

These binaries are indexed using a separate 'image
pointer' binary.

+ * This is ext_rom pcie code entry point
+ * Clearing bss,setting lr and jumping to C code
+ */
+.globl  _start
+_start:
+
+/* lf2flt: to avoid compiler (buildroot wrapper) warning during linkage */
+.global lf2flt
+lf2flt:
+
+	/*
+	 * Arcboot ROM stack is utilized as the context
+	 * needs to switch back to ROM code
+	 */
+
+	/* Clear BSS */
+	mov     r5, __bss_start
+	sub     r6, __bss_end, r5
+	lsr.f   lp_count, r6, 2
+	lpnz    1f
+	st.ab   0, [r5, 4]
+1:
+	push_s  blink
+	bl      erom_main_function
+	pop_s   blink
+	j_s     [blink]
