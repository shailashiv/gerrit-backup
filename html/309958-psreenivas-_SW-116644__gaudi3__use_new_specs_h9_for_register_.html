[SW-116644] gaudi3: use new specs_h9 for register access

In order to reduce the specs header file sizes CAD team
came with new repo specs_h9. This patch adds support to
use register addresses from specs_h9 repo which uses block
base instead of config bar base. This aligns firmware
implementation with LKD.
