Commit Message

[SW-43475] greco: support lzo decompression

Application like DSV is big in size (~3.7 MB).
This is bigger than the size of image supported to
load from host(via PCIe). So DSV image needs to be compressed
to fit into the size requirement set in preboot.
So removed the stub function such that common weak function
implementation gets effective which does the decompression
lzo compressed images.
