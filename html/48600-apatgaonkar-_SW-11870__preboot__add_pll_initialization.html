[SW-11870] preboot: add pll initialization

This patch adds the infrastructure changes required to initialize
plls and their divs based on config provided. This change is reqd
if pll or div frequency change is necessary in specific platform.
e.g. In case of goya2 pldm, uart clk needs to be bumped up to
250Mhz to get prints.
