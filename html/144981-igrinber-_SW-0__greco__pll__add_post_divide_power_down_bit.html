[SW-0] greco: pll: add post divide power down bit

The "Post divide power down" bit was not used as a part of the
configuration sequence.
According to the PLL spec, this bit must be set, so the post divisors
are powered.
Add the FOUTPOSTDIVEN bit to the reset sequence.
