Commit Message

[SW-218933] g3: use access mode enum from specs

The `mem_access_mode` enum was defined within individual Zephyr apps. This
enum has been moved to specs dir to avoid definitions across multiple apps
in an earlier patch. This patch replaces the older enum with enum from
specs dir in baremetal preboot.
