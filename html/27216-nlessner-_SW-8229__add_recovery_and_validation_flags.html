Commit Message

[SW-8229] add recovery and validation flags

When we reboot becuse of fw upgrade or PERST we want to
make sure PCIe link will come up as quick as possiable.
If image failed validation or was in recovery and a warm
reset occurred we run pcie_recovery and only then try to
validate fw again. If not in recovery but fw is already
validated we dont need to do it again, because there won't
be time for it in warm reset.
