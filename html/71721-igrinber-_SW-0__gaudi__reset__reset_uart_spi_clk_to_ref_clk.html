Commit Message

[SW-0] gaudi: reset: reset uart/spi clk to ref clk

Since we raise the PCI PLL in Preboot now, upon reset we get the BTL and
early Ppboot messages gibberished. This is happening because BTL expects
the UART/SPI clock to be at the reference clock frequency.
Reset the UART/SPI clock to reference clock before the actual reset
fires.
