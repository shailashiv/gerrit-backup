Commit Message

[SW-66329] efuse: refactor preboot_fuse_read function

The previos implementation assumes notification methods like prints
and psoc status bits are available, which is not the case for all
the CPUs that are using the efuse infrastructure.
In addtion not all CPUs are allowed to run the fuse initialization.
This Patch moves the cpu specific functionality to __weak functions.
