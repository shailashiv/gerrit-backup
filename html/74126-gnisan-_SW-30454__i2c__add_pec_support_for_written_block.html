[SW-30454] i2c: add pec support for written block

I2C (SMBus) defines a way to validate the data written by the master.
The PEC algorithm is CRC-8-CCITT which is defined by polynomial (0x07)
x^8 + x^2 + x + 1.

The PEC is calculated over all the data and addresses from start to stop
including read and write bit.
e.g. for slave address 0x4f -> (0x4f << 1) | is_read -> 0x9e / 0x9f

When master sends a block:

          w        w       w      w         w          w
Master -[0x9e]->-[LEN]->-[CMD]->-[D]-...->-[D]-...->-[PEC]
        ADDR-W                   data      data

When master sends the PEC, the slave will compare it to the PEC
calculated by the slave. Since there is no way in current I2C controller
to send NACK in PEC comparation fails, the calculated PEC is saved to be
read by master to check if write was successful.

The way the master may read the calculted PEC is by reading the PEC byte
directly. This is not part of SMBus standard.

If master reads different PEC than it calculated, it may assume that
block write failed and abort its operation.
