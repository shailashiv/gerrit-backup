[SW-0] gaudi3: remove c2c pll configuration for pldm

Currently, mesh, nch and c2c pll configuration is done as part of
network pll configuration to speed up dma copy of preboot image and
execution of preboot on sram. It is identified that only mesh
and nch pll configuration is required to copy preboot on sram
by SPI DMA correctly (w/o SPI DMA FIFO) so removing c2c pll
configuration.
