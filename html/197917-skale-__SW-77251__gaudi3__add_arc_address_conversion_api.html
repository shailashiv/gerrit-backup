 [SW-77251] gaudi3: add arc address conversion api

Currently, the macro used for converting 64bit address to
arc viewpoint assumes the address falls in FW memory
region. This patch add changes to convert 64 bit
to arc view point based on address region (SRAM
or FW MEM).
