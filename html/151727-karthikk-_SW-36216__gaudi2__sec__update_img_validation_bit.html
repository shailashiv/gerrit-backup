Commit Message

[SW-36216] gaudi2: sec: update img validation bit

For existing platforms a single efuse bit is commonly used for
security enable and image validation. Gaudi2 has dedicated bits
for security enable and image validation in efuse.

In order to maintain backward compatibility the default implementation
is redirected to security enable check.
