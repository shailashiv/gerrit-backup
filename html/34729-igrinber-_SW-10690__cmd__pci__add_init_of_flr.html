Commit Message

[SW-10690] cmd: pci: add init of flr

Since in Linux we start handling the FLR by moving to H/W FLR handling
and performing a hard reset, we need here to hand it back to to S/W.
Add module_pci_setup() function which performs this action by device
specific flows.
