Commit Message

[FSW-334] preboot: remove legacy preboot build

Legacy baremetal preboot is not used anymore. the sources and
makefile code is removed.
Some of Preboot's code is used in erom recovery, preboot object was
linked directly into erom. Instead the relevant code was moved to
erom recovery source file.
