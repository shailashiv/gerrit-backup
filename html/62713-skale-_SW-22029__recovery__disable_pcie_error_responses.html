Commit Message

[SW-22029] recovery: disable pcie error responses

By default, PCIe error responses for LBW and HBW are enabled in
recovery mode which may lead to PCIe link down in case error are seen
on LBW and HBW. In order to avoid PCIe link down, this patch add changes
to disable error responses for LBW and HBW in recovery mode.

Error responses are disabled by setting value 0x1 in
mmPCIE_WRAP_PCIE_RSP_OK register.
