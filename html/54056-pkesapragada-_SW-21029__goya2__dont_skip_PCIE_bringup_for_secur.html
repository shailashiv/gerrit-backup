[SW-21029] goya2: dont skip PCIE bringup for secure boot

According to HW team, Boot Strap bit for PCIE_EN
(Bit 2 of mmPSOC_GLOBAL_CONF_BOOT_STRAP_PINS_L) is
valid only in legacy mode, where BTL has performed
the PCIE Phy initialization.
In secure boot mode, this bit should not be checked
and ARC1 PPBoot should always bring up pcie.
