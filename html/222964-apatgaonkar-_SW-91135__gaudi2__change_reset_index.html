[SW-91135] gaudi2: change reset index

As part of all resets reset index for units
ARC0, ARC1, ARM CPU and PSOC has been changed
as a WA for BTM_FSM failure after hard reset.
This patch makes the change during platform
early init to make sure any reset including
prstn has correct reset index for these
components.
