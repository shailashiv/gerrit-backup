Commit Message

[SW-0] uart: print 64bits address

In order to print a 64 bits hex value rather then 32 bits value.
By default the preboot's print function prints a 32 bits
hex values, when trying to use those function with a 64 bits value,
only the lower (lsb) 32 bits is printed out.
