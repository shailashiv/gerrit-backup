Commit Message

[SW-66329] cmd_module: move extra functionality to weak func

Cmd_module implements a generic infrastructure for handling multiple
modules in a "init/poll/run" loop.
Some functionality was added later to the main loop and has somewhat,
unrelated nature, but it's required for some devices.
Also there is printing function before entering the main loop.
All mentioned above makes it impossible using the cmd module as a
truly generic infra.
In order to fix this, and enable usage of the cmd module by all CPUs,
the device specific extra functionality, and the printing function,
were moved to weak functions. so if a CPU doesn't have an output
printing port, or it doesn't need any extra functionality in the
main loop, it can simply implement empty functions.
