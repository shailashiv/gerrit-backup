Commit Message

[SW-28668] gaudi2: configure arb timeout to max

This patch changes the arb_timeout default value
of register ASIF_SLV_ASIF_SLV_CFG from 0xFF to
0xFFFF. This is workaround for HW errata which
needs to be done as aprt of PLL configuration
before PLL is locked.

Check HW JIRA H6-2881 for reference.
