Commit Message

[SW-143472] gaudi2: erom: use recovery-conf in erom

The erom recovery is a mechanism to recover the card
by updating firmware hence it should only load and
execute the fit with load type as flash. Hence the
recovery-conf node is added in agent fw loader to
identify the fits that are supported in erom. This
patch adds support to read the fit configuration from
recovery-conf node and executes the agent from the
fit which contain recovery-conf node.
