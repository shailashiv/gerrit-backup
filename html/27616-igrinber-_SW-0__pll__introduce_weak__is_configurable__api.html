Commit Message

[SW-0] pll: introduce weak "is configurable" api

Introduce the weak variant of the hl_pll_is_configurable() function, so
there will be no need to implement it for each H/W variant (e.g. PLDM,
ONIX, etc.).
Remove the anymore unneeded implementations.
Note, the new weak implementation uses the positive logic (e.g. returns
true) while those removed stubs were using the negative logic (e.g.
return false). This is not a problem as those stubs were never called
because their hl_pll_get_cfg() stub which always returned 0 as the
nummber of PLLs.
