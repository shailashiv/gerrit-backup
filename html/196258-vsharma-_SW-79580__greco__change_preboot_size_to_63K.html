[SW-79580] greco: change preboot size to 63K

This patch changes preboot size to 63K. Currently PREBOOT_MAX_SIZE
is already set to 63K, so changing macro PREBOOT_SIZE to 63K also,
to be aligned.
Also due to hw errata  spi dma copy size should not be greater
that 63K, more then that, it should be in multiple copies.
Since current greco preboot size(approc 50K) is well under 63K,
multi-copy support is not required as of now.
