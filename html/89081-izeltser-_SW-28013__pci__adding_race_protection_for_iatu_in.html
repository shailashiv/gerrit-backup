Commit Message

[SW-28013] pci: adding race protection for iatu init

In order to avoid any access from the host to configuration registers
and memory space during the iATU initialization, we temporary disable
pcie access while programming the iATU registers.
During that period The ELBI access gets "retry" response, and memory
access will read 0xFF.
when iATU init is done the pcie communication is enabled.
