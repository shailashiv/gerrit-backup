[SW-92237] greco: increase preboot stack and sram footprint

In order to support future growth, MAX_INFO_DESCS is about to be
increased to 64 descriptors.
Since the boot info descriptors metadata is statically allocated,
this increases the stack and bss consumption of preboot.
To accommodate the memory requirement, the stack was increased to
8kb, and the overall sram footprint limit was increased to 72kb.

It's important to note that this change doesn't affect the binary
size of preboot application, so the 63Kb limitation on the flash
is preserved. This bin size limitation is enforced by the makefile
and defined by PREBOOT_BIN_MAX_SIZE value.

Although ARM preboot is not in use, the stack and sram was increased
for it as well, because it is being built.
