Commit Message

[SW-205447] gaudi2: add eeprom agent app modules

In HL288 board revision 0, second stage VR controller uses different
i2c address compared to HL225. But the address remains the same
between HL338 and HL325. Therefore, we can't rely on 'is_card_pcie'
check, but have to read the eeprom to identify that the card is HL288
and board rev is 0.

To satify this, function to read the eeprom is added to g2 common_utils.
Since this file is used in hbm, pcie and serdes agents, adding eeprom
app modules to resolve build errors.
