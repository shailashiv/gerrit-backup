Commit Message

[SW-156330] spi driver: add timeout for poll transfer

In scenarios where communication with SPI controller
is broken, FW may fail to read SPI controller's FIFO
depth. This has the potential to turn the SPI
transfer polling loop into an infinite loop. Adding
timeout to this loop to prevent ppboot hang.
