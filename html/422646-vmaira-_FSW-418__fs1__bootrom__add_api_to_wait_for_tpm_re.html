[FSW-418] fs1: bootrom: add api to wait for tpm resp

This patch adds a function that waits for a TPM
response to become available. This function will
be used to check the availability of a response
after sending a command to TPM. With its short
timeout, it can be invoked periodically while
other ROM tasks continue to progress.
