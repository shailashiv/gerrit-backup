[SW-57800] gaudi2: run tpm only if efuse is burned

Run TPM only if sys cfg efuse is burned and tpm bit is set.
If they are not, TPM functions exit on the beginning.
Add EOPNOTSUPP errno.
Return EOPNOTSUPP if TPM is not enabled.
On ppboot notify if TPM is not enabled.
