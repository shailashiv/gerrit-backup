Commit Message

[SW-195710] g3: set pci rev for bis device

When a device is operating under BIS limitations for China market, the
PCI revision is changed to reflect that to the host at the earliest
stage.
The PCIe revision is set by PIF ARC. To maximize PIF ARC stability, it
is not accessing outside of PIF, but instead the BIS status is passed to
him via a local configuration register.
