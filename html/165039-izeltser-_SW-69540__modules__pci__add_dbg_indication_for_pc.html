Commit Message

[SW-69540] modules: pci: add dbg indication for pci init wait

In case the CPU handling the PCI init is stuck for some reason,
for example because the prst_n signal is stuck low, the developer
doesn't get any indication about it aside from the absence of
the pci link.
This patch adds a periodic print indicating that the PCI
initialization still not finished by the relevant CPU.
The user will not see those prints unless debug mode is intentionally
enabled (by typing "dbg").
