[SW-84464] greco: fuse: print version

This patch adds support in print fuse version for greco.
Also since it calls efuse_init() in fuse_read(), it takes
care of initialization of efuse, if not already done.
efuse init is required by upper fw layers to use read efuse
values, else it returns 0 values on read.
