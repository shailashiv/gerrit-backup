[SW-113268] gaudi2: pcie: bis compliant check

New PCIe revision(2) should be configured by ppboot incase
BIS Compliant efuse is set.

For BIS Compliant check, ppboot needs to read only BIT 16
at offset 0x3A. But currrent code reads 5 dwords from real
fuse or fake fuse (SPI flash) which introduces delay in PCIe
link up and PCIe link doesn't come up consistently after PRSTN

Modified code to read the BIS Compliant bit from efuse shadow
registers. Before PCIe link up fake fuse contents are not used
(Ex: PCIe gen limit). 

No need to check for fake security is enabled or not
