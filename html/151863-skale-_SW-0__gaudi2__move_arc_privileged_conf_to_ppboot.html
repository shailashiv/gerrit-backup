[SW-0] gaudi2: move arc privileged conf to ppboot

With protection bits configuration done for multiple block in LKD/FW,
it is observed that bootrom flow doesn't restart as expected
upon hard reset. This is due to ARC1 privilege mode configuration
is cleared upon ARCs reset as part of hard reset and ARC1 tries to
access registers of block which are set to privilege or secured by
LKD/firmware.

Apart from bootrom, there are few PLL registers ARC1
accesses in ppboot which are configured as secured/privileged.
This patch moves setting of ARC to privilege as part of ppboot
security init routine (before PCIe link up) and before the
configuration of PLL registers in ppboot.
