[SW-0] pll: introduce hl_pll_is_bypass() function

The hl_pll_is_bypass() function returns the actual bypass state.
Make use of it in the hl_pll_udelay() function and remove the static
global flag used till now.
The new function uses the enum hl_pll_div_out for readability sake.
