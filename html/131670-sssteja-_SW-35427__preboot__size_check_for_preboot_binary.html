Commit Message

[SW-35427] preboot: size check for preboot binary

This patch adds checks for preboot binary size in greco-arc,
gaudi2-arc & gaudi2-arm.
Preboot build fails for binary size > (64-1)KB.
1KB added as a guard to have time to take action if overflows.

This is needed to ensure that preboot binary size doesn't overflow
beyond preboot boundaries in spi flash layout and throws error to user
at build time.
