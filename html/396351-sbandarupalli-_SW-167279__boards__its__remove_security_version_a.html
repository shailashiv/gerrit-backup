[SW-167279] boards: its: remove security version and key idx from its

Currently, while generating fit some of the ITS files adds security
version and key idx to the fit. In the signing process, the script
checks where key idx is part of fit and if its available it will
update it with key idx user passed to sign the image. If key idx is
not found in fit, script goes and takes it from fit footer.

The problem of adding this information in fit occurs for computing
fit sha's which are used for TPM PCR extention. Ideally when
the signing script replaces the signature from key0 to key1 or key0
to key2 and viceversa, the hashes of the images (ppboot, preboot,
boot fit and linux fit) should not change and in CI, it uses the
same pcr binary. But since the key idx is added in fit, when it changes
from 0 to 1, it causes boot fit hash to change. So on system fw
reports new hash but the tpm tool compares it with pcr which has
hashes without key-idx value change.

To resolve above problem, this patch removes security version and key
idx values from fits where they are added as they are ideally taken
from fit footer.
