Commit Message

[SW-37085] gaudi: security: lbw decoder errata fix

Due to a LBW address decoder bug, all the
access to DBG address area via MESH needs
to be restricted.

This patch implements the suggested
workaround for this hardware errata by
adding a LBW RR to restrict the DBG
address access via all RTR paths.
