Commit Message

[SW-73994] module_pci: postpone setup till link up

On some systems the PERSTn can still be low when we reach the setup
routine, so the FLR setup has no effect.
For the FLR setting to take effect we need to wait for the PCIe
controller and wrappers to be ready.
Add a state machine which enables tracking the PCIe initialization and
postpone the FLR setup up till it is ready.
