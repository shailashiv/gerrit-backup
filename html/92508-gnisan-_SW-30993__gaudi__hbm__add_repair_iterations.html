[SW-30993] gaudi: hbm: add repair iterations

Add iterative repair procedure to the AC test:
- Run MCBIST, pass if successful.
- If not, restart the problematic device/channel/pseudo channel from
  the next row (MCBIST stops at the first bad row).
- If successful, attempt row replacement (placeholder for now), if not,
  attempt lane (IO) repair.
- Reapeat (up to 5 iterations)
