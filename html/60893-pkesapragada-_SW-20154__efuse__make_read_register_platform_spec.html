Commit Message

[SW-20154] efuse: make read register platform specific

Efuse register's name has been modified in Gaudi2,
since the backward compatible name for this register
which is "read" has been made a reserved. Hence
it has been changed to "read_ctrl". To make such
usage possible, EFUSE_READ register offset is being
made platform specific and will be updated in the
platform specific files
