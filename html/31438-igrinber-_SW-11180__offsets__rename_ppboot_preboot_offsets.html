Commit Message

[SW-11180] offsets: rename ppboot/preboot offsets

Rename the Ppboot and Preboot SPI flash offsets to legacy.
This helps to differentiate between the old boot way with hard coded
pointers and the new one which is going to be introduced soon.
The new way will involve using the image descriptors instead of hard
coded offsets.
