[SW-105079] gaudi3: pldm: unblock pcie and elbi range register

In gaudi3, HW FSM or ROM blocks the complete config range based
on fuse bit. This patch unblocks RR for PCIE and ELBI using ROM
api only for PLDM plaform. On ASIC, ranges will be unblocked
for required registers which needs to be accessed from PCIe.
