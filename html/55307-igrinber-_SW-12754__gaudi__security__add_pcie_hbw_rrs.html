Commit Message

[SW-12754] gaudi: security: add pcie hbw rrs

To complete the HBW protection add initialization of the PCIe IF RRs on
the areas not protected by the IF RTRs RRs (accessed directly from PCIe
- not through IF).
The PCIe IF RRs are implemented using "min and max" concept, so we can
use a single register to protect all the directly accessible HBW areas.
