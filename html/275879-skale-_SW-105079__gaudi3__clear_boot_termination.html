Commit Message

[SW-105079] gaudi3: clear boot termination

In secure boot mode, for non-cold resets the access from PCIe to
NoC is blocked by HW FSM. Due to this, any access from PCIe I/F
to ASIC will be blocked. FW need to clear boot termination in order
to un-block the access. This patch add changes to clear boot
termination as part of hl_pcie_enable_access function. This configuration
also needs to be done in PCIe link up sequence in ppboot and erom.
