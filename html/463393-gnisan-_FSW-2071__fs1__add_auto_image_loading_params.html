[FSW-2071] fs1: add auto image loading params

Images can be loaded automatically from flash by using data from the
image manifest. To enable that some additional parameters are added
to the manifest, such as memory address & size, cpu details, and
image flags.
Since Preboot is the only image currently loaded in an automated manner,
the new parameters are currently initialized only for Preboot
