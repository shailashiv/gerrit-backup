[SW-0] goya/gaudi: cleanup private base defines

Goay and Gaudi has been using privately defined *_BASE defines which are
conflicting with specs *_blocks.h header and thus it cannot be included.
Resolve the conflicts in favor of the *_blocks.h header inclusion.
This makes way for the new reset code in Gaudi and less pollution with
private defines,
