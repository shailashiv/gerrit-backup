Commit Message

[SW-4185] pll: don't skip clk switch prior pll cfg

Do not skip the divisor output clock select moving to reference clock
before PLL configuration.

The HL_PLL_SKIP is used to skip the divisor output clock select
configuration, but it is not checked while configuring the PLL core.
This effectively allows the "skipped" divider output clock select to
output clock from PLL while it is being configured/reset/etc.
This scenario is not good and should be avoided.
