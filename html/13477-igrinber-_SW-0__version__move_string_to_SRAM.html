[SW-0] version: move string to SRAM

Since we now run in scratch pad SRAM, some of the transactions do not
work with values not aligned to 32 bit.
In order for us to be able to manipulate the string and keep providing
versions for upper level S/W, move the version string to the real SRAM.

Consequently, we no longer need the version string in the global scope,
so move them into the function scope.
