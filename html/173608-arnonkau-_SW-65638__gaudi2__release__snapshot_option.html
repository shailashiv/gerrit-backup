[SW-65638] gaudi2: release: snapshot option

Allows a temporary caching of the environment variables.
So consecutive, operation on the same setup can be done with reduced
command line arguments.
It differ froms config link, as the link just points to the
configuration file, while the snapshot copy the current env and save it
in a special snapshot file. The amount of saved variables is more
extensive than the ones yo u get from the --create-cfg
