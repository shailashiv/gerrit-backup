[SW-0] correct the efuse read address register

The bootrom code incorrectly configures the
read address of the DFT_EFUSE instead of the
functional EFUSE. This patch corrects this
problem.

There is a need to reset the efuse read address
in bootrom as boot manager changes the default value
during its execution
