[FSW-6167] fs1: init pci vf mem bar size

Set the size of VF memory BAR to 512GB for Palad emulator.
Set the alowed sizes of VF memory BAR. Resizable BAR is used
for the VF MEM BAR, so the size is not set statically, but the allowed
sized are set and the actual size is negotiated with the host.
