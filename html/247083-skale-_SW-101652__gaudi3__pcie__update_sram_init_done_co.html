Commit Message

[SW-101652] gaudi3: pcie: update sram init done condition

Currently, rom polls for value of sram init done to be 0 instead of 1
thats why it remains stuck in infinite while loop. This patch add changes
to poll for 1 instead of 0 and also add timeout of max 100ms instead of
looping infinitely. Timeout in init done is recorded in ROM status
update.
