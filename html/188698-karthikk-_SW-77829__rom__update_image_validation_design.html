Commit Message

[SW-77829] rom: update image validation design

As per the new image validation design, the signature validation is
to be done on the image descriptor data and not on the actual ppboot
and preboot image. The ppboot and preboot image validation would
only consist of sha verification of the actual image compared to the
hash stored in image descriptor.

Hence the validation functions are defined as:
1) secureboot_verify_image_v2() : api that is used to verify
the signature on image descriptor manifest.
2) secureboot_verify_image_hash384() : New api to perform sha384
checksum verification on payload (ppboot/preboot) images.
