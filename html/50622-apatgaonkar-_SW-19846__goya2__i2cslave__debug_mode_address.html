[SW-19846] goya2: i2cslave: debug mode address

In case of goya2, debug mode address of i2c slave
is 0x6A in case of secure boot. It will remain 0x47
in case of goya2 legacy flow. This patch adds
changes so each platform can have its own i2c slave
debug mode address.
