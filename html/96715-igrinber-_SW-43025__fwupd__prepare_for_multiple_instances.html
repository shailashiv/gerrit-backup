Commit Message

[SW-43025] fwupd: prepare for multiple instances

We are going to have multiple instances of the fwupd module, so we can
serve additional modules with fwupd interface.
To prepare for the addition, stop using the global variable all over and
switch to use/pass function parameter.
Additionally introduce operators for reading and writing the interface
registers - this is to virtualize the interface.
