Commit Message

[SW-57369] gaudi2: arm: perform checks using sram full addr

Currently, it is assumed that SRAM address received from FIT file
for uboot load is of ARM viewpoint and used directly to validate
address range as well as to copy image to address. This patch
add changes to convert full address received from FIT to ARM viewpoint
and then use to validate and copy the contents.
