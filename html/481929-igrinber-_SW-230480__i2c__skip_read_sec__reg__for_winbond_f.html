[SW-230480] i2c: skip read sec. reg. for winbond flash

Skip read security register for Winbond flash
during OOB recovery via I2C. For Winbond flash
this command is not supported. Instead, it has
3 256 byte security registers, that can be filled
with any OEM specific information and we are not
using them
