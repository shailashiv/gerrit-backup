[SW-22029] goya2: increase stack size to 2k

Currently in arcboot flow, it is observed that maximum stack arcboot
uses is of 1260 bytes which is overflowed by 236 bytes from stack size
of 1024 bytes (1k). The stack overflow is mainly seen in arcboot key
validation flow while synopsys SDK API's are called. This doesn't
cause any corruption issue as stack uses 236 bytes of heap area which
is unused. This patch increase stack size to 2k in order to avoid any
stack overflow.
