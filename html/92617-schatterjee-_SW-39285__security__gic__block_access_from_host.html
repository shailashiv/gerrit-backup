Commit Message

[SW-39285] security: gic: block access from host

Any unprivileged entity (e.g. malicious driver
on host) can exploit the GIC access rights. In other words
keeping GIC accessible from host  makes the system vulnerable
to security threats. So GIC region access is blocked using RR
registers.

With this modification, host can not generate interrupt using
mmGIC_DISTRIBUTOR__5_GICD_SETSPI_NSR anymore. Alternatively
firmware would implement a polling based mechanism to handle
interrupt requests from host.
