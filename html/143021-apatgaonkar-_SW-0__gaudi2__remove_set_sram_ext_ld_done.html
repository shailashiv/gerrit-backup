[SW-0] gaudi2: remove set sram ext ld done

Instead of waiting for sram_init_done, wait for ext_ld_done to be
set was added to confirm that logic has finished copying the PHY FW
from PIF SRAM to the Synopsys PCS IP SRAM. This patch removes
pcie_phy_set_sram_ext_ld_done function which manually sets
sram_ext_ld_done.
