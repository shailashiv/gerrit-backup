[SW-108985] drivers: hbm: gaudi: fix hbm row repair flow

fix a sw bug on hbm row repair function.
in the end of row repair a reset to ieee1500 bus
is asserted as it should but not being de-asserted
so the ieee1500 is stuck at reset in case of row repair.
added the de-assertion and print row repair data.
