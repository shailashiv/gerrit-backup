Commit Message

[SW-26558] gaudi: block pci access to SYNC_MNGR

Block PCIe access to SYNC_MNGR with RR registers.
Only if initiator is PCIe then access to SYNC_MNGR is blocked.
Otherwise, when using other initiators, such QMAN for example,
it is still possible to access SYNC_MNGR.
This patch is done as part of security access requirements.
