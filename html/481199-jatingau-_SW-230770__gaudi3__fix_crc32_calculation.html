Commit Message

[SW-230770] gaudi3: fix crc32 calculation

This patch adds a WA to fix crc32 calculation error which
occurs when the file path contains a hexadecimal string.

Issue was seen during gerrit to github migration where the
jenkins jobs being run were using a different folder structure
and that path contained a hexadecimal string.
