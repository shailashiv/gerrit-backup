[SW-68327] gaudi2: clear cpld last reset cause

After prstn, watchdog or ecc serr and derr cpld firmware informs
last reset cause using GPIO_66 and GPIO_67. Once ppboot has read
these gpios it needs to clear up this cause in cpld. This is done
using GPIO_68. Currently clearing this reset source is not working
in CPLD_REV 0x94. With CPLD firmware revision 0xA4 which has fixes
for GPIO_68, this patch writes 0x0 and then 0x1 to GPIO_68 to clear
last reset cause.
