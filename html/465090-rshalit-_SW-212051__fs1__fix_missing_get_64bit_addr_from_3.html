Commit Message

[SW-212051] fs1: fix missing get_64bit_addr_from_32bit_addr imp

Implementation for get_64bit_addr_from_32bit_addr was not linked
in code, which results in wrong return address, and FW
getting stuck as part of updating pcie phy.

Fixing composed of 2 parts:
1. added fs1 implementation for get_64bit_addr_from_32bit_addr
2. skip pcie phy update if it is not implemented

Temporary the implementation is done for palladium only because
coral memcpy is not implemented yet - see SW-212050
