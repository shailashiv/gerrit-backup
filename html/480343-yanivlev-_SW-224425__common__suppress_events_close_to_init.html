Commit Message

[SW-224425] common: suppress events close to init

We should allow time for the regulation threads to stabilize before
sending power and thermal events.

For some reason, early events are causing SRAM Repair RMA errors in
Gaudi2 when cycling LKD load and unload for hundreds of times.

While this patch isn't addressing the inherent issue of early events
triggering the SRAM Repair RMA errors, it does help to avoid the issue
without any unintended side effects. The suppression of events in the
first 1 second after init is actually a good idea regardless. Moreover,
before [PNP-194] these early events were suppressed unintentionally.

Add a condition to suppress events in the first 1 second after init.
