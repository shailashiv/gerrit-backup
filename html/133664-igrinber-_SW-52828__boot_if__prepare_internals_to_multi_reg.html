Commit Message

[SW-52828] boot_if: prepare internals to multi reg

Prepare the internal implementation for the multiple registers use for
both the errors and device status bits.
This make the implementation more close to what we have in U-Boot.
Still internal API (Preboot wide) changes are required before we can
fully switch to multi-register error and device status bits.
