Commit Message

[SW-36711] greco: change load address of uboot

Currently, fit image is copied at SRAM offset 0x200000 and uboot
is loaded at SRAM offset 0x100000. This works as expected till
the size of uboot is less than 1MB. In the cases where uboot size
increases beyond 1MB, uboot overwrites FIT contents stored at
offset 0x200000 which leads to preboot unable to find images of
zephyr.

In order to keep fit image load location same as it is common across all
devices, this patch changes uboot load offset to 0x400000 for greco
onwards devices.
