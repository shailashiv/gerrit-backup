[SW-12754] gaudi: security: rename pcie rrs func

The preboot_secure_pcie_lbw_rr() function can (and will) not only be
used for LBW, but also for HBW.
In order to avoid confusion and make the function name reflect better
its purpose and available functionality, rename to
preboot_secure_pcie_rr().
