Commit Message

[FSW-9512] fs1: set validation pass

This patch set validation pass flag just before
bootrom handover control to ppboot.
Ppboot transition is the place where we see at
least one manifest is enumerated, validated
properly and atleast one ppboot image is
prefetched, validated properly.
Store same manifest index to persistent dccm
and cold flops which is going to load ppboot.
Recovery is the flag which hold opposite value
to validation pass, to route recovery when
validation fail.

+void boot_rom_validation_status(bool validation_pass)
+{
+	struct fs1_cold_rst_data cold_rst_data;
+
+	/* validation pass, set validation flag and clear recovery or viceversa */
+	cold_rst_data.data = regmap_readl(IO0_H0_PSOC_BOOT(mmPSOC_BOOT_CONF_COLD_RST_REG_2));
+	cold_rst_data.recovery_flag = (validation_pass ? 0 : 1);
+	cold_rst_data.validation_flag = (validation_pass ? 1 : 0);
+	regmap_writel(cold_rst_data.data, IO0_H0_PSOC_BOOT(mmPSOC_BOOT_CONF_COLD_RST_REG_2));
+}

+void boot_rom_set_manifest_index(enum hl_fw_manifest_type man_idx)

+	struct fs1_cold_rst_data cold_rst_data;

+	if (cold_rst_data.valid_manifest_idx == man_idx)
+		return;
+
+	cold_rst_data.valid_manifest_idx = man_idx;
