Commit Message

[SW-17444] preboot: fit: remove usage of public key property

Currently, in order to get public key node as part of secure boot flow,
preboot tries to get pub-key name as property and then retrieves
public key node from fit.

Since public key name is pre-defined, this patch add changes to pass
public key string directly and retrieve public key node thus avoiding
adding public key as property in .its file
