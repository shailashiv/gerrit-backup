Commit Message

[SW-65531] efuse: efuse data read during init

This patch adds support for reading the efuse data
in the first efuse initialization. This init reads
and stores complete efuse data in the psoc efuse
data register which works as shadow register. This
is done to avoid multiple physical access to efuse.
Also efuse init is avoided in rest of the boot flow.
