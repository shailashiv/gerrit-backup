[SW-151130] gaudi2: ppboot: clear arc0 dccm bss segment

The bss segment(DCCM) of arc0 in ppboot is used
as stack for threads in arcpid and all the thread
stack regions in bss are initialized to 0xAA pattern
In prstn reset when bringing pcie link up accessing
this bss is causing both arc to stuck which inturn
causes arc1 to get stuck. This patch adds support
to clear bss segment of arc0.

The issue is seen only in prstn because in cold reset
entire DCCM is cleared and in other resets the pcie link
will be already up.
