Commit Message

[SW-29377] i2c indirect: defer op process to fast

Process I2C indirect OP within "fast" context instead of "slow". This is
needed when an OP has interaction with other preboot modules.

In this case the motivation is while performing config access "read"
from CPU status register (mmPSOC_GLOBAL_CONF_CPU_BOOT_STATUS) it
contains different status within "slow" context vs. normal flow.
This affects interoperability when integrating hl-fw-loader OOB.
