[SW-140835] fwupd: sec: ro access to err sts msg

This patch aligns erom and preboot based on the following patch:
https://gerrit.habana-labs.com/#/c/266783/

When error occurs during RUN state, The response message
body is not accessible from the pci. The FWL reads zeros (RAZWI).

When executing the RUN command; It closes the access to the downloaded
FIT. When it exits with an error, a status message containing the error
information is passed as FIT towards the host. Its memory area should be
re-opened in RO mode. The access will be blocked again as a response to
RESET_STATE cmd.

It is the host responsibility to send a RESET_STATE command. Indicating
the end of transaction.

NOTE: In secure mode while in MAP_SRAM, the FIT area should be open in
RW mode, allowing the host to upload a FIT.
