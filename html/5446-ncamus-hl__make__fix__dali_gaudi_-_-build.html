Commit Message

hl: make: fix {dali,gaudi}-*-build

On new systems the build path is yet to be created.
Therefore the {dali,gaudi}-*-build fails with:
$ make dali-asic-build
/bin/sh: 1: cannot create /home/dbarak/trees/npu-stack/buildroot-external/output/.hl-vars.mk: Directory nonexistent
Makefile:50: recipe for target 'hl-dali' failed
make: *** [hl-dali] Error 2

Fix by adding the output directory as a dependency for builds.
