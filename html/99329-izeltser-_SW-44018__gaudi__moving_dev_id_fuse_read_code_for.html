[SW-44018] gaudi: moving dev_id fuse read code for reuse

Both the present preboot_rate_limiter_init and the future to come
preboot_hbm_credits_init functions are using device id data from
fuse for internal logic.
Moving the code retrieving this data to a separate function
for future code reuse.
