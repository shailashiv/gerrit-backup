Commit Message

[SW-0] upd_pending: switch to regmap

Remove the per platform getter functions providing the "update pending"
register offset.
This is in favor of the regmap headers available in specs.
This should lower the code size as the resolving is done in compile time
and no variables used to hold the offset.
