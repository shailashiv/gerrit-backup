[SW-106171] gaudi3: remove vid and rid in tpm init

Currently vid and rid are read in tpm init, but this data is un-used.
Currently this routine would only confirm us that the spi communication
itself is successful, which would anyhow be confirmed by earlier apis
that set the locality.

Hence these apis are redundant and can be removed from rom sequence.
This would save us some time of tpm validation.
