[SW-226950] pmc: add set numeric sensor enable

Add the PLDM command SetNumericSensorEnable. Sensors can be
manually set to ENABLED, DISABLED, or UNAVAILABLE. Sensor
operational state is persisted across soft resets (oobi) as
long as table is not full.
