Commit Message

[SW-78052] gaudi3: notify slave fuse value

Currently, for fake fuse emulation the values used are common for master
and slave die. However certain fuse bits have different meaning for master
and slave die. This leads to create different set of fuse values
for both dies. This patch adds implementation for master to read slave
die fuse values from slave fuse offset and inform required fuse value to
slave die as slave die cannot access SPI flash. Notifying fuse value
from master to slave die is only valid for fake fuse emulation.
