Commit Message

[SW-0] reset: gaudi2: reset psoc as part of reset

Currently, ARCs are reset as part of hard reset and WD reset so that
bootrom flow re-starts in secureboot flow mode. However, AXI_ERR is
observed in PSOC when hard reset is issued without PSOC being reset.
It is recommended by HW team to reset PSOC as part of reset when ARCs
are reset. This patch updates mask for hard-reset and WD reset to
reset PSOC.
