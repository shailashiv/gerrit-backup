Commit Message

[SW-195710] g3: set bis device in erom

In Gaudi3 (unlike G2) EROM is not disabled in BIS mode, so it should
be able to identify BIS mode and set the PCI revision respectively.

To maintain the logic for gaudi2, the BIS check function definition is
separated for G2 and G3.
