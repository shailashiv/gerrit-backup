Commit Message

[SW-46517] greco: change location of rom export fn elf

Since ppboot uses arcboot ROM export function to read from spi, perform
dma and perform verification of image, ppboot compilation requires
export.elf file created out of arcboot ROM compilation. The export.elf
generated with latest arcboot code doesn't match with the arcboot ROM
flashed on greco cards. In order to resolve issue, export.elf is created
with the arcboot ROM code which is available on greco card and
copied to buildroot external folder. This patch add changes to use
pre compiled arboot rom export elf.
