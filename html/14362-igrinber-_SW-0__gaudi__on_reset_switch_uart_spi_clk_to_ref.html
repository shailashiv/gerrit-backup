Commit Message

[SW-0] gaudi: on reset switch uart/spi clk to ref

The BTL is initializes the baud rate of the UART to a certain value
which cannot be manipulated in run time. This means we need to setup the
UART clock to a frequency which will suit this limitation.
This frequency is 50MHz, so switch the UART/SPI clock (PCI PLL DIV
output 2) to reference clock before reset.
