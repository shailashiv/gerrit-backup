Commit Message

[SW-66329] module: pci: refactor check function

The first part of the check function is common because module pci
should always start executing after the pci blocks are initialized,
or at least not in reset state.
This patch moves the common portion to common code.
In order to avoid breaking onix code for greco/gaudi2, function
module_pci_do_setup() is now __weak, and empty implementation is
added for the relevant platforms.
Also the dbg printing function is __weak now, because not all clients
of this module are able to use prints. It was moved to pci.c where it
fits better.
