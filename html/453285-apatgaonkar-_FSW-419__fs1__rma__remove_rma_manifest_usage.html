Commit Message

[FSW-419] fs1: rma: remove rma manifest usage

As per discussion with security spec, rma manifest bit
indicating if manifest can be loaded in rma is no
longer used. Only rma efuse bit is used to decide
if manifest can be loaded with lower svn and revoked
key. This patch removes all relevant code.
