Commit Message

[SW-39246] spi: add erase capability

Add erase capability in spi flash, as a preparation
for a later patch which handles request command (fit)
for flash erase. Also required increase of size as the
spi code is common from ppboot as well.
Erase timeout was measured (about ~500msec), and
requires increase of wait timeout for commands.
