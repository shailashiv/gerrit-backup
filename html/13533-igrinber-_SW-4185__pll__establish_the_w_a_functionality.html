Commit Message

[SW-4185] pll: establish the w/a functionality

Current code only permits to have one value per divisor output clock
select - either the clock switch value, or the W/A flag.
To implement the W/A functionality for more divider outputs, we need to
have the original clock switch values at hand while also need to be able
to specify that the W/A is needed.
Introduce a new enum hl_pll_wa_sel for W/A implementation specific
values and also add a new array field to struct hl_pll_cfg, so SoC
specific implementation can specify the W/A type while keeping the
original clock switch values along.
