Commit Message

[SW-86865] gaudi3: process core-id property of images

Starting gaudi3, core-id property will be added in fit which
will help firmware understand for which ARC processor the
image is expected to run as part of fit processing. Based on
this information, FW will configure ARC processor, copy content
using load address and will put ARC processor in running state to
execute the image supplied. This patch retrieves core-id property
from fit and process it accordingly.

+static int fit_process_core_id(int core_id, uint64_t load)
+{
+	if (core_id > FIT_CORE_ID_COUNT)
+		return 1;
+
+	/* arcboot rom only support fit load for master psoc arc0 to arc2 */
+	if (core_id > FIT_CORE_ID_D0_PSOC_ARC2)
+		return 1;
+
+	/* Nothing needs to be done for psoc arc1 as its already running */
+	if (core_id == FIT_CORE_ID_D0_PSOC_ARC1)
+		return 0;
+
+	/*
+	 * It is expected to receive two images for single core (iccm/dccm),
+	 * so assumption is made here that 1st image will be iccm followed
+	 * by dccm.
+	 */
+	if (!arc_info[core_id].config) {
+		arcboot_rom_bring_up_arc(core_id, load);
+		arc_info[core_id].config = true;
+	}
+
+	return 0;
+}
