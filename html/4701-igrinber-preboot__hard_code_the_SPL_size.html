preboot: hard code the SPL size

Currently, the SPL size is calculated during the build of U-Boot/SPL
and is passed to BTL build. The BTL build in turn, saves the SPL size
in its code and writes it into the scratchpad 29 register.
Preboot reads the SPL size from the scratchpad 29 and uses it to load
SPL into SRAM.
The above creates a dependency between SPL and BTL builds, and in
addition is error prone during the changes between the primary and the
secondary during update process.
To make the update process more robust and remove the build dependency,
use the hard coded value of 64KB for loading the SPL.
It is a size of an SPI flash sector. It is big enough to cope with SPL
growth (if any) and it is small enough to not impact the performance
during boot.
