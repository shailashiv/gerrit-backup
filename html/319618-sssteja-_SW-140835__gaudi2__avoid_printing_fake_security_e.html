Commit Message

[SW-140835] gaudi2: avoid printing fake security enable

This is a porting patch from preboot-rtos to preboot repo to align
erom and preboot codebase.

Preboot_rtos patch:
https://gerrit.habana-labs.com/#/c/255617/

This patch adds changes to avoid calling fake security
data copy functions when security is not enabled or if
fuse override is enabled. Fake security boot info will
be set only when security is enabled and fuse override
is disabled. This patch also modifies the boot info copy
function names from spsram_init to boot_info_init as the
function does nothing related to spsram.
