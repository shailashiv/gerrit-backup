[SW-0] arc: disable alignment checks on data memory

Currently, misaligned data access exception is observed on ARC while
running preboot which cause preboot to hang in  waiting for commands
routine. The exception is caused when address accessed by ARC is not an
integer multiple of operand size. This patch add changes to disable
alignment checks on data memory by setting AD bit to 1 in STATUS32
register.

> Dont we hide problem this way?

Misaligned memory access is support by our ARC processors. By default AD bit in status32 is set to 0 which raises exception if misaligned memory is accessed by ARC. Since our ARC support misaligned memory access, we need to disable it by setting AD bit to 1. Same approach is used by Zephyr OS as well, it sets this bit if processor is ARCv2
