Commit Message

[SW-50869] arch: rename greco/gaudi2.h to hl.h

this is preparation patch for defining platform specific enums in common
header file and include it in required library code

ex: PSOC_GLOBAL_CONF_RST_SRC bit definitions are changed in Gaudi2 and cant
keep enum hl_rst_src in common header file preboot.h. In up-coming patches
this enum will be moved to hl.h of each platform.

if each platform has different file names like greco.h and gaudi2.h they
cant be included in library code. So keeping same file name as hl.h

arch/gaudi2/arm/common.h -> contains common definitions across ASIC/ONIX/
PLDM targets of leagacy boot flow
arch/gaudi2/common/hl.h -> contains common definitions across arm/arc flows
