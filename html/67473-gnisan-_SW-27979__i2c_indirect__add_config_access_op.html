Commit Message

[SW-27979] i2c indirect: add config access op

This commit adds config access op, which is needed by hl-fw-loadr OOB.

Using this op, BMC can read/write configuration space registers. Since
the LKD and FWUPD protocols are based on scrachpad registers which are
part of the configuration space, this commit is part of the hl-fw-loader
transport layer.

In order to issue a config access command, the master must issue WDATA
write command. This opcode defined field are mostly R/W but there is
also a RO field (status) which is protected and cannot be written on.
If master attempt to write over it, the RO field is considered as a hole
and will not be written over.
An error is issued if there are no writable fields in the request.
