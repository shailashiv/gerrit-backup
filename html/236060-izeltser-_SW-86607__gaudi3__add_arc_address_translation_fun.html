Commit Message

[SW-86607] gaudi3: add arc address translation function

Since preboot image is copied by a DMA, the full chip address
is used. This address should be translated to the ARC view
address when we want to access the preboot from ARC.
At the moment the translation function supports SRAM address
range only, additional address ranges can be added in the
future as needed.
