Commit Message

[SW-87517] gaudi3: configure spi dma mmu bypass for sram dest

As per Errata GAUDI3_0301, SPI DMA AXI attributes should not be
changed during traffic. HW team has recommended to perform MMU BYPASS
configuration for non-PSOC memory as DMA destination. This patch
add changes to configure MMU bypass before DMA transfer based on
destination type.
