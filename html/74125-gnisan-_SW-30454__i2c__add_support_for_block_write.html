Commit Message

[SW-30454] i2c: add support for block write

I2C (SMBus) defines a way to send block of data from master to slave.

The block format is:
[ADDR][CMD][LENGTH][DATA][PEC]

PEC is not part of this patch.

This patch introduces the capability to send complete block, minus PEC.
The length is ignored as it is known.

In order to support the data not wrapped in a block, command sequence
increases for every written byte for non-virtual commands.
