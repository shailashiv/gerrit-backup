Commit Message

[SW-42558] gaudi: security: lock dbi statically

Since FW initializes the iATU, host no longer need to access it, so we
can close the access to iATU/DBI space along with others during the
static init.
Remove the preboot_security_dbi_lock() function and update the static
security configuration to cover the DBI/iATU sapce as well.
