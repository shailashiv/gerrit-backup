Commit Message

[SW-56706] boot_desc : add start address field

As per the new image descriptor design, start address field is added
as a part of image descriptor data structure. This is used because
for few images like zephyr binaries, the start address is different
than the load address due to the linker file's section placement.

This field would provide flexibility in such cases, as load address
can be used for destination of the dma transfer and start address
to specify the point of execution to jump to, post the dma.
