[SW-0] pll: introduce weak hl_pll_get_cfg() api

Introduce the weak variant of the hl_pll_get_cfg() function, so there
will be no need to implement it for each H/W variant (e.g. PLDM, ONIX,
etc.).
Remove the anymore unneeded implementations.
