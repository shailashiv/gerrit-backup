Commit Message

[SW-229044] sensord: pack sensor state structs

Reduce memory footprint by using uint8_t instead of raw enum values
and marking structs as packed.  Switch statements updated to cast
from integer to enum as appropriate.

This change saves 34 bytes of state per sensor. This directly
impacts preboot and the agents, as those apps use a static buffer
for sensor state.  Mgmt allocates sensor state out of the HBM
memory pool.
