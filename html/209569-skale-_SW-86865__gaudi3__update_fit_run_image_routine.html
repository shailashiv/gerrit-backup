Commit Message

[SW-86865] gaudi3: update fit run image routine

Currently arcboot_start_image assumes the image is expected
to be run on ARC1 processor where arcboot rom is running. This
assumption is incorrect and image can be executed on different ARCs.
This patch adds support to call start_image for each core.
