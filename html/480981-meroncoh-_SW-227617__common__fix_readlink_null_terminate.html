Commit Message

[SW-227617] common: fix readlink null terminate

The function readlink doesn't null terminate the target path buffer.
The function returns the number of bytes placed into this buffer or -1
in case of an error. Therefore, if there is no error, null terminate
the target path buffer. The side effect of it was returning wrong process
names (e.g., when running Deep Seek).
