Commit Message

[SW-71880] versions: make setup device specific

Gaudi2 is no longer uses the legacy version registers, but forced to
keep them defined for the common code to compile.
Rework the versions setup code to be device specific and enable the
legacy versions registers to be removed on Gaudi2.
