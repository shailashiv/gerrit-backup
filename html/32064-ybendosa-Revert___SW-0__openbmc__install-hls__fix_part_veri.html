Revert "[SW-0] openbmc: install-hls: fix part verification"

This reverts commit 4ceebe329ee7d0611b3b480fd6f5fd1bba5a0b9e.

It seems that unlike other partition images, the u-boot partition image
size is only dependent on the size of the product of its build process,
and not on the definition provided in the openbmc layer.

This means that it doesn't align to the kernel dts definition, and will
fail partitions verification unnecessarily.
