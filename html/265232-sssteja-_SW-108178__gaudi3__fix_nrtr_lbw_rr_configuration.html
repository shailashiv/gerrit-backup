Commit Message

[SW-108178] gaudi3: fix nrtr lbw rr configuration

PCIE LBW transactions via PIF goes through NRTR1_2CH. Hence, ROM needs
to configure associated RR, i.e mmD0_NRTR1_NW12_DEC1_CTRL_RR_LBW to
open or close LBW access to PCIE. This was wrongly configured previously
and this patch fixes the issue.
