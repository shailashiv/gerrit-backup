[SW-4185] gaudi: pll: add w/a for north hbm pll

The North HBM PLL is different than the others in a way that nothing can
program it while the HBW clock is gated.
Therefore we cannot use the usual W/A here.
In order to W/A the clock switch glitch in the North HBM PLL, we toggle
the clock switch in a regular manner and deal with the "fallout" of the
clock switch glitch.
To deal with the "fallout", we need to reset the SoC subsystems
excluding PLLs.
We implement the following state machine for the North HBM PLL:
                   -------
      ----------->/ init  \
      |           \ done ?/
      |            -------
      |        no /       \ yes
      |          /         \
      |     ------         -------
      |    / do   \<---   / reset \
      |    \ init /   |   \ done ?/
      |     ------    |    -------
      |       |        \ no /   \ yes
      |       |         ----     \
      |    --------            -------
      |   / update \          / clear \
      |   \ reset  /          \ reset /
      |    --------            -------
      |        |                  |
      |     -------            -------
      |____/ reset \          / cont. \
           \  soc  /          \ boot  /
            -------            -------

This way we do both reconfigure the PLL, so we boot in a known state,
and clear the possible fallout from the clock switch glitch.
