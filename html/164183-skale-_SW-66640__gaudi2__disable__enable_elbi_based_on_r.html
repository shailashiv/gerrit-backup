Commit Message

[SW-66640] gaudi2: disable, enable elbi based on reset type

The sequence for disabling and enabling ELBI depends on the
reset type. For FLR and warm reset, ELBI can be enable/disable by
configuring CRS however this method is not allowed for SW_ALL
and FW RST for which ELBI is enabled/disabled using RR. This
patch add support to check reset type and disable/enable ELBI
accordingly.
