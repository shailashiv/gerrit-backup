Commit Message

[SW-21905] module: pci: added pcie link status monitoring

Pcie link status is being monitored while preboot is waiting for
commands, if link status is changed a message is emitted to console.

We assume in preboot phase pcie link should be already up, so the
default values of the internal variables are set accordingly, in
order to avoid a redundant print in the beginning.

In addition, when pcie link is going up, a HW workaround is executed
for devices where it's required.
