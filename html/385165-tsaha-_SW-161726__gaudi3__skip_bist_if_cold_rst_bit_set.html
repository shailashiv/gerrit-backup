Commit Message

[SW-161726] gaudi3: skip bist if cold rst bit set

This patch adds support to skip sram bist for 96MB cache
if cold rst bit (bist_skip_enable) is set or reset type
is FW_ALL.

FW issues hard reset after running bist. So to avoid rerun
of bist operation preboot sets bist_skip_enable bit in COLD
RESET register. Preboot checks this bit and ignores running
bist if it is set.

Ppboot skips bist operation if reset type is FW_ALL.
