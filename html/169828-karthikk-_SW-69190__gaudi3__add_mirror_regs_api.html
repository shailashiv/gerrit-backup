Commit Message

[SW-69190] gaudi3: add mirror regs api

Add read and write apis for mirror registers. The write apis are
enabled only for projects which support mirror register configuration
(currently gaudi3). This is done using HL_MIRROR_CFG_BASE macro.

As all memory access functions are defined in common arcboot.h, these
apis are defined there to maintain uniformity, while the compile time
check for HL_MIRROR_CFG_BASE is to maintain compatibility.
