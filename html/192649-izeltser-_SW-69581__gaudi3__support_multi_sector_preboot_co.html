Commit Message

[SW-69581] gaudi3: support multi sector preboot copy

Preboot application can occupy multiple sectors of flash (up to 3
for gaudi3).
This patch adds support for copying the binary from multiple sectors
of flash. The provided implementation is temporary and lacking crc
verification.
Once the Arcboot binary is finalized, this implementation should
be replaced with the dma_copy_image_v2() function from Arcboot rom.
At the moment using this function is problematic because arcboot code
is not part of Onix nor PLDM images.

Opened Jira ticket SW-80466 for replacing the implementation once
arcboot rom is finalized.
