Commit Message

[SW-140588] fwupd: fix run noret for I2C commands

module_fwupd_run_noret is used for the I2C commands
is not correct since the state variable is different
for I2C and PCIE. This can lead to abnormal behavior
if a reset command is send from I2C. This patch fixes
this by using module_i2c_fwupd_run_noret for I2c commands.

This change is taken from preboot_rtos
https://gerrit.habana-labs.com/#/c/299893/
