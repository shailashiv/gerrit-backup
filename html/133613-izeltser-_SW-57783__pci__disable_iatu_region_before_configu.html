Commit Message

[SW-57783] pci: disable iatu region before configuring

iATU regions might be reconfigured multiple times on runtime.
If a transaction is being translated by an iATU region while it is
being reconfigured, the destination address is undefined, and an
innocent transaction might become harmful to the system.
To avoid that undefined behaviour, we disable each iATU region prior
to changing its configuration.
