[SW-60588] gaudi2: monitor PCI RR occurrence

This patch monitors lbw and hbw error interrupt bit
of PCIE_IC_SEI_INTR_IND register and writes scratch pad
register 19 with pattern 0xABBA.

These error interrupt bits are set for lbw/hbw razwi
occurrence.

This is temporary patch for power on and needs
to be reverted once testing is done
