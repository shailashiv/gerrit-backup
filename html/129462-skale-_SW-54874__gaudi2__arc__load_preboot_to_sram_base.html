Commit Message

[SW-54874] gaudi2: arc: load preboot to sram base

Currently, for secureboot flow preboot is loaded at 0x4000 keeping
is similar to btl flow. However in secureboot flow, ppboot is loaded
in FW SRAM instead of SRAM which keeps first 16KB SRAM unused. This
patch add changes to load and execute preboot to SRAM base.
