Commit Message

[SW-21856] module_pci: add en/disable callbacks

Add enable()/disable() callbacks to PCIe handling module.
This should prevent FLR request from racing other modules (e.g. I2C)
which take significant time to execute in regard to the FLR request
timeout.
Implement the callbacks for Gaudi.
