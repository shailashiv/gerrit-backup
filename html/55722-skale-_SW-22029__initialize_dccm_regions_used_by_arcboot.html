Commit Message

[SW-22029] initialize dccm regions used by arcboot

Currently on goya2 ASIC, it is observed that ARC throws DCCM memory
exception (Internal Memory Error on Data Access) while attempt is made
to read un-initialized DCCM memory in stack section of arcboot which is
mapped on DCCM.

This issue is seen in synopsys key validation api's which make use of
prefetch instruction causing un-initialized read on stack. Also the
fake ECC can also be generated if attempt is made to perform byte
write on DCCM memory which in-turn gets converted to
read-modify-write causing ECC error.

The recommendation from synopsys to avoid above ECC error is to
initialize DCCM memory before start of arcboot code. This patch add
changes to initialize DCCM memory to zeros which is used by arcboot for
its operations which includes stack and heap areas. bss and data
sections mapped on DCCM are already initialized as part of arcboot init
code.
