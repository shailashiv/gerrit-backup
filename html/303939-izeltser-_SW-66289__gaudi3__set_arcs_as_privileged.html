Commit Message

[SW-66289] gaudi3: set arcs as privileged

PSOC ARCs and PIF ARC are set as privileged early in the ppboot flow,
same as in a previous platform, to avoid the scenario of an arc failing
to access a privileged register during the boot flow.

Since it's a time critical section, and we don't have d2d link yet,
only master die ARCs privilege level is being set. The rest will
be configured as part of the security driver functionality.

configuration is performed according to embedded PRM section 13

+#define AXPROT_PERM_BITS	3
+#define AXPROT_PERM_GROUPS	2	/* read and write */
+#define AXPROT_PERM_GRP_SZ	0x10
+
+/* AxPROT values to set privileged permission level */
+#define AXPROT_PRIV_OVRD	0x11	/* AxPROT bit 0 */
+#define AXPROT_SECURE_OVRD	0x01	/* AxPROT bit 1 */
+#define AXPROT_RSVD_OVRD	0x01	/* AxPROT bit 2 */
+
+static const u32 axprot_perm_priv_val[AXPROT_PERM_BITS] = { AXPROT_PRIV_OVRD, AXPROT_SECURE_OVRD,
+							    AXPROT_RSVD_OVRD };
+
+static void hl_set_mstr_if_axprot_to_priv(u32 axprot_base)
+{
+	uint32_t addr;
+	unsigned int protbit, grp;
+
+	for (grp = 0; grp < AXPROT_PERM_GROUPS; grp++) {
+		addr = axprot_base + grp * AXPROT_PERM_GRP_SZ;
+		for (protbit = 0; protbit < AXPROT_PERM_BITS; protbit++) {
+			regmap_writel(axprot_perm_priv_val[protbit], addr);
+			addr += sizeof(uint32_t);
+		}
+	}
+}
+
+void ppboot_secure_arc(void)
+{
