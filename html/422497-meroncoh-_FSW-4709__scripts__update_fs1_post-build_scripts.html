Commit Message

[FSW-4709] scripts: update fs1 post-build scripts

1. The regexp used in hl_create_zephyr_bins_config relies on the macros
defined in fs1_mem_addr_dt.h. In FS1, contrary to Gaudi3, both
ARC_MGMT_IO_ICCM_ and ARC_MGMT_ICCM_ macros are defined. This causes
value duplication strings assigned to off and sz variables. For example:
sz = "0x100 0x100" instead of "0x100".
2. The arcpid implementation isn't ready yet, so there was a need to
comment out temporarily more lines related to it for the script to pass.
