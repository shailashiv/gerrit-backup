[SW-0] add provision to set recovery gpio

Automated Recovery process during secure boot
will involve the CPLD starting the watchdog. Hence
CPLD has to be notified about the presence of a
valid firmware, in a two step process.
1. (ROM): Assert GPIO[index]
2. (PREBOOT): De-Assert GPIO[index].

This patch implements the first step as needed
in the boot rom - wherein, as soon as the ROM
detects that it is not GPIO2 recovery, the GPIO[62]
is asserted.

+/*
+ * Request CPLD to start the watchdog, by asserting
+ * a GPIO.
+ */
+#define GAUDI2_CPLD_WDOG_GPIO_INDEX	62
+void arcboot_rom_request_cpld_wdog(void)
+{
+	uint32_t index = GAUDI2_CPLD_WDOG_GPIO_INDEX % 16;
+	uint32_t val, mask = BIT(index);
+
+	/* configure GPIO in output mode */
+	val = regmap_readl(mmPSOC_GPIO3_OUTENSET);
+	val = val | mask;
+	regmap_writel(val, mmPSOC_GPIO3_OUTENSET);
+
+	/* gpio is active low */
+	val = regmap_readl(mmPSOC_GPIO3_DATAOUT);
+	val &= ~mask;
+	regmap_writel(val, mmPSOC_GPIO3_DATAOUT);
