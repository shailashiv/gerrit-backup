Commit Message

[SW-0] greco: zero out dccm before using in ppboot

This patch zero out dccm before using it in ppboot.
This is used for stack,bss and data sections.
Undefined behaviour and exception was seen in ppboot
during pdu power cycle in arcboot flow. This resolve
that issue.
Also it change's size of dccm to be used to 7K.
