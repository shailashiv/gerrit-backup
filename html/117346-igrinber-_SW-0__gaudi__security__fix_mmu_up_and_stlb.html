Commits:
3ead641 ("[SW-47071] gaudi: sec: protecting mmu_up block regs")
885c713 ("[SW-47071] gaudi: sec: protecting stlb block regs")

Have attempted to restrict access to MMU_UP and STLB blocks using
privilege protection bits, but mistakenly used bitwise OR instead of
bitwise AND. This led to keeping all registers in the protection area
unprotected.
Fix this problem by changing the bitwise OR with AND.
