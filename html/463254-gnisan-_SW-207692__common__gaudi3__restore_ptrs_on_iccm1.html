Commit Message

[SW-207692] common: gaudi3: restore ptrs on iccm1

In case that arcboot ran with the following cold straps:
1. boot_info_set_done=0
2. validation_pass=1

Then ICCM1 no longer holds the boot ptrs data. This is due to
the fact that bootROM copies boot info manifest into it.
In that case, restore PTRs data by copying it from flash.
