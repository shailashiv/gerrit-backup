Commit Message

[SW-43829] lkd: preserve boot_info in handler

Recently, we added preserving boot_info as part of
handling of wfe and reset, but erroneously it was added
only in lkd legacy protocol handler, and therefore
when using COMMS, boot_info is not preserved.
This patch fix it by calling the preserving inside the
actual handlers of wfe and reset.
