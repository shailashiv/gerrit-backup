[SW-189578] gaudi3: tpm: fix wrong gaudi3_pcr.bin gen

The boot fit hash file used to generate the PCR
binary was moved during a folder restructuring.
This relocation was not reflected in the PCR
binary generation logic, causing incorrect PCR
binary generation.

This patch updates the path in the PCR binary
generation logic to ensure the correct file is
used.
