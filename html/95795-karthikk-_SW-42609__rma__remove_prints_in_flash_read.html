Commit Message

[SW-42609] rma: remove prints in flash read

In case of an active rma multiple prints are seen as each flash_read
read results in 3 prints and each active rma consists of 4 flash_read
calls (1 for boot pointers, 3 for descriptor read).

This leads to a lot of repetitive prints which do not contain any
debug data.

Hence for rma info read from flash these strings has been removed.
