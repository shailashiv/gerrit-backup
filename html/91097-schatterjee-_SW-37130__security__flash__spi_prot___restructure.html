Commit Message

[SW-37130] security: flash: spi_prot() restructure

spi_prot() function is recently moved before pci is enabled.
But this added some delay before pci link is UP.
For device like goya, this delay would add further to the
already high time for the link to come up during cold boot
(eg. PRSTn).

So the spi_prot() is changed to be device specific. For
goya, the relevant function(spi_prot_late()) is called in
early preboot. For other devices(gaudi, greco), the relevant function
(spi_prot_early()) is kept before pcie link enablement in ppboot.
