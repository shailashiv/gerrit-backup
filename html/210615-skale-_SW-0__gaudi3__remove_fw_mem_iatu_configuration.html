Commit Message

[SW-0] gaudi3: remove fw mem iatu configuration

In recovery mode, secured FW upgrade will be done using SRAM
which will come up in mode 0. Currently FW memory is also configured
to map to bar 4/5. Since FW memory wont be used for secured FW upgrade,
this patch remove FW memory iatu configuration.
