[FSW-2704] fs1: prefetch ppboot image

This patch adds functionality to prefetch ppboot image
from manifest before manifest validation starts. Basic
manifest checks and crc needs to be correct for image
to be prefetched. Only manifest validation flag can
be ignored for prefetch.

+{
+	/* start the prefetch of ppboot or recovery images
+	 * In either case there can be multiple dmas involved
+	 * Maintain a state machine to do multiple dmas
+	 * It needs to decide which manifest it needs to do prefetch
+	 * from. If manifest crc or validation is invalid then it
+	 * needs to make sure to fetch image from other manifest.
+	 * Once the dma starts with one manifest, another function will
+	 * be implemented to complete it based on state machine.
+	 * return the manifest index from which it has started prefetch.
+	 */
+
+	return BOOT_ROM_SUCCESS;
