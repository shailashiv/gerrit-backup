Commit Message

[SW-73084] greco: mask i2c2 comb irq in early init

On enabling I2C2 slave during preboot, interrupt is generated
to ARC0 which is trying to initialize PCIE link during cold
reset. This creates exception in ARC0 flow as it is running
bare metal code which cannot handle irqs. To avoid exception
in ARC0 this change masks I2C 2 comb irq (0x47).
