Commit Message

[SW-36216] gaudi2: sec: add dcore rtr for pcie

In gaudi2, apart from the pcie mstr if, pcie traffic is also routed
through dcore0 rtr0 if. Hence configuring pcie mstr if range
registers alone is not enough to block/allow pcie traffic.

This patch couples the dcore0 rtr0 if along with pcie rr
configuration such that the common is reused.
