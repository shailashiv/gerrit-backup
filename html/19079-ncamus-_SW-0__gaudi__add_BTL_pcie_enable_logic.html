[SW-0] gaudi: add BTL pcie enable logic

This logic copied from BTL PCIe section (#4)
In BTL it is called when DIP switch for PCIe enable is set
Now we wish to do this logic also here as a measure of security
It means that in new PCB's version by default PCIe won't be enabled
So without proper FW device won't be accessible through PCIe
Hence device is more secured

Note: we assume new PCB will include Metal Fix hence no need for calling
init_pll_pci logic

+static void preboot_pcie_enable(void)
+{
+	u32 boot_strap = regmap_readl(mmPSOC_GLOBAL_CONF_BOOT_STRAP_PINS);
+	u32 reset_cause;
+
+	/* Check if already done by BTL */
+	if (boot_strap & 0x2)
+		return;
+
+	/* During hard reset triggered by LKD keep PCIe intact */
+	reset_cause = regmap_readl(mmPREBOOT_PCIE_EN);
+	regmap_writel(0, mmPREBOOT_PCIE_EN);
+	if (reset_cause == LKD_HARD_RESET_MAGIC)
+		return;
+
+	preboot_init_pcie();
+}
