[SW-27979] i2c indirect: add memcpy op

Add support for memcpy op. To be used by hl-fw-loader OOB.
This allows the BMC to read and write memory section out of SRAM without
the need of PCI link which does not exist for BMC.

The memcpy op consists of 2 different opcodes:
- memcpy control
- memcpy data

The memcpy ctrl op is the sequence initiator, with this commnad the
master start to read/write (according to opcode field).
Following this command, the master is expected to request memcpy data
opcode as many times as needed. Each memcpy data request will read/write
256 bytes max. The next memcpy data request will set the offset to the
next 256 bytes. This is true even if the memcpy data call was partial.
The last request size may be lower than 256 bytes as it's the leftover.
