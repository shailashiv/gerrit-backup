Commit Message

[SW-30453] i2c indirect: fix rdata crc for trivial

When reading outside for opcode bound, a trivial value of 0 is returned.
This value needs to be digested in CRC.
In addition, CRC must come after RSDL as opposed to after the readable
data (struct).
