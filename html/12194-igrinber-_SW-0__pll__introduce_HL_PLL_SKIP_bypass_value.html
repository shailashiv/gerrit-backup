[SW-0] pll: introduce HL_PLL_SKIP bypass value

The HL_PLL_SKIP is used to specify the PLL outputs that should be
skipped. That is, should be not touched during the PLLs initialization.
This will be used by the Gaudi IF/MESH W/A LBW code.
