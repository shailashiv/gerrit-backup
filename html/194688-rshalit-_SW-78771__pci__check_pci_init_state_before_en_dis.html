[SW-78771] pci: check pci init state before en/dis

Accessing PCIe registers such as FLR, must be done only
when PCIe module is out of reset.
During PRSTN assertion, PCIe blocks cannot be accessed.

Before accessing any of the pcie blocks we wait for ARC0
to complete PCIe code execution (reach HALT state),
which indicates that the PCIe initialization sequence
is complete and PCIe link is up.
Then we can be sure the PRSTN is de-asserted and all PCIe
blocks are operational.

Checking if PCIe initialized is done inside PCIE check
routine, but it was missing in enable, disable and teardown
routines, which are actually called in state machine
whenever another module enters run or run_fast state.
The missing protection, resulted in an exception
observed in HLS2 machines, OAM0.
This patch adds a checking as required.
