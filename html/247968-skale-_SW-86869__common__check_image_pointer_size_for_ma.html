Commit Message

[SW-86869] common: check image pointer size for max value

Currently we read image pointer (manifest) size from 0x60000 SPI offset
for SPI manifest and 0x0 offset for EROM manifest and performs the DMA
of the manifest image. The minimum size of manifest image is checked inside
DMA function but not the maximum size. This patch adds max image
size check for manifest image which is 64KB.
