[FSW-2704] fs1: redefine address ranges for io die0

This patch redefines all macros used for io die 0
address ranges. This will allow to validate loadaddr
and dma destination addr in image descriptor.
As scratchpad sram read/write is not happenning
in bootrom, this functionality is removed from
mem_io.h.
