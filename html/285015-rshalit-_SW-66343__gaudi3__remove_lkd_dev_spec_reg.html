Commit Message

[SW-66343] gaudi3: remove lkd_dev_spec_reg

lkd_dev_spec_regs is a weak function used for updating
cpu_dyn_regs, which are passed to host as part of COMMs
protocol in preboot.
In gaudi3 this function is implemented in preboot-rtos,
and not relevant in legacy preboot. Hence, function removed.
