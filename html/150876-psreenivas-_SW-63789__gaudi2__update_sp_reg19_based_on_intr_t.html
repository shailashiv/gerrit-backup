[SW-63789] gaudi2: update sp reg19 based on intr type

In order for validation to identify RAZWI, HBW and
LBW pcie rr interrupt, a unique pattern is written
to scratchpad register 19.
RAZWI- pattern 0xABBA
HBW - pattern 0xDEAF
LBW - pattern 0xACDC

NOTE: This is a revert me patch and the logic will be removed
post Gaudi2 PO validation.
