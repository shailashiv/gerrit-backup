Commit Message

[FSW-2071] fs1: add auto image loading sequence

Images can be loaded automatically from flash by using data from the
image manifest. To enable that some additional parameters were added
to the manifest, such as memory address & size, cpu details, and
image flags.

Images are loaded by iterating the descriptors in the flash manifest
until action is required (based on flags and reset cause)
1. if not current CPU, prepare the CPU by release of CPU reset
2. if mem init required, init memory
3. if mem load required, copy the image to memory and validate sha
4. if cpu execution required, and not current CPU, set reset vector and
   run CPU.
   if cpu execution required, and current CPU, return address

Based on that sequence, the image that is running on the same CPU and
replacing the Ppboot must be positioned last in the manifest, after all
the other loadables.

+	struct desc_flags flags;
