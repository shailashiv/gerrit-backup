[SW-0]: fit: copy keys in images folder

Currently, keys are stored in common folder and the path with key name
is set in token KEY_DTB using sed command. In order to avoid setting
complete path for key, this patch copies required keys to images folder,
set KEY_DTB to key name and pass images folder location in mkimage
command to sign images.
