Commit Message

[SW-137121] gaudi3: erom build: erom start offset

In gaudi3, pif arc binaries are copied to arc1 iccm base
address at zero offset and then copied to pif arc iccm/dccm.
So, Erom pcie code can't start at arc1 iccm base address, we have
added start offset of 0x1000 (4Kb).

dev_ext_rom is directly included in .S instead of adding it in
common.h

erom text length is changed to 64Kb, which is good enough to support
erom recovery (size is 40Kb).
