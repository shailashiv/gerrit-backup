[SW-112281] board: hl: add post-image-fit-script

Currently several memory addresses are defined both in
post-image-fit.sh (as variables in axi view) and in
dtsi (in arc view), which creates duplication.
In order to remove this duplication, this patch adds
post-image-fit-script in dtsi, which include the
absolute values in format of string which contains
"variable=value".
Therefore, by simply running eval with this string
as an argument, the variables will also be defined in
the bash post build script.

+	for dts_file in *; do
+	echo $dts_file

+			if [ "$(grep -c $2 $dts_file)" -ne 0 ]; then

+					script_str=`echo $line | cut -d '"' -f2`
