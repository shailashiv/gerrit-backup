Commit Message

[SW-35518] gaudi: security: protect indirect msi

It was found that the indirect MSI mechanism is not working well in
various scenarios (e.g. during the card reset, or in the abnormal
interrupt storm situations, or host VM shutdown)
Protect the PCIe MSI region with RR so it can't be used as a security
threat.
