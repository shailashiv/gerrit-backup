Commit Message

[SW-56687] gaudi2: add api for returning offset

Currently, the offset which is sent to LKD as part of response to
PREP_DESC message is set as descriptor base. The offset is
sent to LKD after applying mask of 0x3FFFFFF. This logic works for
all platforms expect for gaudi2 where incorrect offset is send to
LKD (for eg. In arc flow the offset sent is 0x1200000 instead of
0x200000).

This patch adds platform specific function to set offset.
