[SW-204735] packages: zephyr: target for zephyr size report

This patch adds additional targets  for  Zephyr modules to produce dumps
to view and analyse RAM  and  ROM usage in generated images. It uses the
final image  and  give information about  size of symbols and code being
used in both RAM and ROM. New targets are:
  <modulename>-size-report-ram
  <modulename>-size-report-rom
  <modulename>-size-report
