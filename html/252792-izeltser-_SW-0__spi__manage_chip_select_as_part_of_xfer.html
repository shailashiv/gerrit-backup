Commit Message

[SW-0] spi: manage chip select as part of xfer

The spi driver was taken from u-boot but it was changed so the
bus claim/release functionality in not managed by spi_xfer()
and the SPI_XFER_BEGIN SPI_XFER_END flags are ignored.
This creates a bug in the TPM implementation (also taken from uboot),
in a scenario of a long packet that is being split into several
shorter packets, the bus is released in the middle of the
transaction.
This patch is fixing this bug by using the same method as UBOOT:
managing the bus claim/release from spi_xfer().
