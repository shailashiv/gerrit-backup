Commit Message

[SW-65065] gaudi2: secureboot: remove btl version

In secureboot flow there is no btl version. Version
string that preboot stores in SRAM also need not
have btl version as it causes mismatch with secureboot
version in fw image fit. This patch makes sure
btl version is written to version string only in
case of legacy flow.
