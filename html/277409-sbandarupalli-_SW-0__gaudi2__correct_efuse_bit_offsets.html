[SW-0] gaudi2: correct efuse bit offsets

arcbootrom writes the value of efuse offset 0x3A at a different
location in SPSRAM (192). So if SPSRAM is read to get efuse value
then SECURITY_EFUSE_SYS_CFG_OFFSET should be used instead of
efuse offset 0x3A
