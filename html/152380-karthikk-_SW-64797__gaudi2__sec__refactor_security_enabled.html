[SW-64797] gaudi2: sec: refactor security enabled

Currently pcie dev id is hardcoded for gaudi2. In order to support a
dedicated pcie dev id for a secured device, we require to read the
sec_en bit from efuse.

The code to initialize the pcie dev id is also compiled as a part of
erom binaries (recovery and pcie). This creates an chain of dependency
of erom compilation to security.c. Hence the code is refactored such
that these functions which are a part of erom, ppboot and preboot
compilation are moved to the common.c file.

This is in preparation to support dedicated pcie dev id for secured
devices.
