[FSW-7256] fs1: define recovery prot bits context

With this patch declared a group specific
protection bits structures, which has various
members to avoid fixed size arrays to configure
pb depends upon requirement. Group specific
structures are used to form a page specific
structure to configure each pb page. Based
on requirement, multiple pages can be grouped,
For example in this patch recovery required
pages are defined.
