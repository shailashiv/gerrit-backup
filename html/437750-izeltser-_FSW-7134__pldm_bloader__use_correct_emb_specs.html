Commit Message

[FSW-7134] pldm_bloader: use correct emb specs

pldm_bloader application was including headers from EMB specs folder.
But for fs1 it should take the headers from emb specs/fs folder.
To achieve that, the hardcoded path is removed from the makefile,
and the platform specific makefile (that holds the correct path) is
included.

In a addition, pif_ts module is excluded from the build as it's not
relevant for the pldm_bloader nor for FS1.
