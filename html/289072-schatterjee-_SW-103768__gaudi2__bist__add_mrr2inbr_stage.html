[SW-103768] gaudi2: bist: add mrr2inbr stage

This patch add mrr2inbr stage before bira.
This stage shifts the repair data from the efuse
to the repair registers inside the memory. This enables
us to execute accumulative repair, add repair data without
overriding the fuse repair data
