Commit Message

[SW-123737] gaudi2: ext_rom: set privileged mode to ARCs

This patch adds support to set ARCs to privileged mode as
part of erom init. However till that point ARCs mode is
changed to user mode due to reset and if it tries to
access registers which are set to privilege/secure mode
and not been reset as part of reset the arc gets stuck.
